### 1.1 동작 시험 결과 (2026-11-09, 로컬)

- **도구:** Foundry 1.9.0(Homebrew), solc 0.8.24(forge가 처음 빌드할 때 내려받음). 사용자 승인(총괄 PM 전달)으로 설치했다.
- **실행 범위:** 로컬 EVM에서만 돌렸다. 공개 체인, RPC, 키는 쓰지 않았다.
- **외부 라이브러리:** 쓰지 않았다(forge-std, OpenZeppelin 없음). 필요한 cheatcode 인터페이스만 `test/Mocks.sol`에 직접 두었다.
- **결과: 19개 통과, 0개 실패.**

| 결함 | 시험 |
|---|---|
| C1 | 준비금 안에서는 발행 성공 / 초과 발행 거부 / 값 0·음수 거부 / 자릿수 18 거부 / 끝나지 않은 라운드 거부 / 퍼징: 준비금을 넘는 발행은 한 번도 성공하지 않음 |

| C3 | 개인 키 주소(EOA)를 소유자로 쓰면 거부 / 2단계 이전(수락 전에는 바뀌지 않음, 다른 주소는 수락 불가) / EOA로 이전 거부 / 소유자가 아니면 이전 거부 |
| C4 | 2일 1초 전에는 적용 거부, 정확히 2일에 적용 / 2+7일이 지나면 만료 / 취소하면 적용 불가 / 소유자가 아니면 예약 거부 |

| 기타 | 일시 정지 중 전송·발행·소각 거부 / 퍼징: 총공급은 잔액의 합 |

C7(명세)과 C8(배포 도구)은 문서·도구 결함이라 pytest로 검사한다.

**린트 경고(`forge lint`) 판단:** 모두 고치지 않아도 된다.
- 0 주소 검사 누락 2건: `_requireMultisig`가 검사하는데, 린터가 내부 함수 안을 보지 못했다.
- 반환값 미사용 1건: `startedAt`은 일부러 쓰지 않는다.
- 형 변환 1건: `answer > 0`을 확인한 뒤에만 변환한다.
- `block.timestamp` 비교 4건: 기준이 1일·2일·7일이라, 검증자가 몇 초를 조정해도 영향이 없다.
