# AIADCoin 토큰 계약 초안: 결함 목록과 상태

- **대상:**
  - 계약: `agent_market/ad_coin/v2/contracts/AIADCoin.sol`
  - 명세: `aiac_token_spec.json`
  - 도구: `scripts/deploy_token_testnet.py`
- **상태:** **감사 전 초안이다. 어떤 네트워크에도 배포하지 않았다.**
  - 테스트넷·메인넷 배포와 외부 감사 의뢰(지출)는 승인 대기다(운영 헌장, 총괄 PM 11-09).
  - 실제 가치로 쓰는 것은 법률 의견을 받은 뒤다.

## 1. 11-09에 고친 결함

| # | 결함 | 위험 | 조치 |
|---|---|---|---|
| C1 | 준비금 검사가 실패 시 열림: 오라클이 없거나(주소 0) 답이 0 이하면 검사를 건너뛰었다 | 준비금 없이 무제한 발행 | `currentReserves()`가 아래 경우 모두 되돌린다(fail closed): 오라클 없음, 소수 자릿수가 6이 아님, 답이 0 이하, 갱신 시각이 0이거나 미래이거나 1일보다 오래됨, 라운드 불일치. 새 총공급이 준비금보다 크면 거부한다 |
| C2 | 오라클 값의 시각을 보지 않음(`latestTimestamp` 미사용) | 오래된 준비금으로 발행 | Chainlink 방식 `latestRoundData()`의 `updatedAt`을 검사한다(`MAX_RESERVE_AGE` 1일) |
| C3 | 소유자가 배포한 개인 키(EOA) 하나이고, 이전할 수 없음 | 키를 잃거나 유출되면 영구적으로 되돌릴 수 없음 | 생성자가 소유자를 받는다. 소유자는 **배포된 계약(다중서명)**이어야 한다(`code.length` 검사). 2단계 이전: `transferOwnership` 다음 `acceptOwnership` |
| C4 | 발행자·오라클을 즉시 바꿀 수 있고, 0 주소 검사도 없음 | 소유자 키를 탈취하면 바로 무단 발행 | `setBridgeMinter`·`setReserveOracleFeed`를 없앴다. `scheduleChange`를 한 뒤 2일(`CHANGE_DELAY`)이 지나야 `applyChange`할 수 있고, 7일(`CHANGE_GRACE`)이 지나면 만료된다. 취소할 수 있다. 0 주소는 거부한다 |
| C5 | 소유자도 발행할 수 있었음 | 권한 분리가 없음 | 발행은 브리지 발행자만 할 수 있다 |
| C6 | 0 주소로 발행할 수 있었음 | 공급이 사라짐 | `mint`·`approve`·전송에서 0 주소를 거부한다 |
| C7 | 명세가 ERC-2612(permit)를 주장했지만 구현은 없음 | 문서와 코드가 어긋남 | 명세에서 뺐고, 상태를 `draft_not_audited_not_deployed`로 표시했다 |
| C8 | 배포 도구의 "실제 배포" 경로가 실제로는 배포하지 않고, 가짜 거래 해시로 `deployed_live` 기록을 썼음. 배포 기록 파일도 시뮬레이션 값이었음 | 배포하지 않은 계약을 배포한 것처럼 보이는 기록 | 도구는 시뮬레이션 계획만 화면에 출력하고, `--execute`는 거부한다. 개인 키와 web3를 쓰지 않는다. 가짜 기록 `testnet_deployment.json`은 지웠다 |

시험: `tests/test_ad_coin_v2_token_contract.py`(7개, 소스 규칙 검사).

## 2. 남은 일(배포 전 필수)

1. **컴파일과 동작 시험:**
   - 이 맥에는 Solidity 컴파일러(solc, Foundry)가 없다. 설치하려면 내려받아야 하므로 승인이 필요하다.
   - 설치한 뒤 시험할 것:
     - 준비금 경계값
     - 오래된 값, 미래 값
     - 소수 자릿수 불일치
     - 지연 변경: 이른 적용, 만료, 취소
     - 2단계 소유권
     - 일시 정지
     - 불변식(총공급은 잔액의 합): 퍼징으로
2. **결정할 것:**
   - 일시 정지 중 소각(상환)을 막을지 열어 둘지. 지금은 막는다.
   - 일시 정지에도 지연을 둘지, 별도 일시 정지 권한을 둘지. 지금은 다중서명이 즉시 정지한다.
   - 지원 체인. 명세에는 4개 체인이 있지만 정해진 것은 없다.
3. **외부 감사:** 메인넷 전 필수. 의뢰와 비용은 승인 사항이다.
4. **법률 의견:** 발행·수탁 주체, 담보 적격성, 관할(`reports/AI-AD-Coin-v2-현황과-법률검토자료-2026-11-09.md` 3절).
