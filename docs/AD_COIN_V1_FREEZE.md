# AI AD Coin v1 동결 (시험 전용)

- **결정:** 2026-11-09, 사용자 결정. 소스 분석 보고서(`reports/AI-AD-Coin-소스분석-2026-11-09.md`) 개선사항 6번에 대한 답이다.
- **내용:** v1(`agent_market/ad_coin/`, `adc` 표, `/api/ad-coin/v1`)은 **시험 전용 원장으로 동결**한다.
  - 실제 가치(실제 돈, 결제, 상환, 토큰)는 v2(`agent_market/ad_coin/v2/`, `adc2_` 표)에서만 다룬다.

## 규칙

1. **시험 모드는 끌 수 없다.**
   - v1의 설정(`Settings`), 서비스(`AdCoinService`), 영수증 서명기(`Signer`)는 `test_mode`가 `True`가 아니면 시작하지 않는다(`SettingsError`).
   - 검사는 `config.require_test_mode()`가 하고, 시험은 `tests/test_ad_coin_v1_frozen.py`다.
   - 환경 변수로도 바꿀 수 없다.
2. **v1에는 보안·정합성 수정만 넣는다.** 새 기능, 새 화면, 새 표, 새 API 경로는 v2에 만든다.
3. **v1 자산을 v2 자산으로 바꾸거나 옮기지 않는다**(v2 설계 DEC-02와 같다). v1 잔액과 영수증은 가상 금액이며 현금 가치가 없다.
4. **v1 데이터 보존 규칙은 그대로다.** 원장·영수증 기록은 최소 5년 보존하고, 견적은 30일 뒤 삭제한다(`docs/AD_COIN_SALES_POLICY.md` 9절).
5. **v1 화면 규칙도 그대로다.**
   - 광고주 콘솔과 사람용 화면: 영어, 디자인 체계
   - 운영 화면 `/ad-coin/admin`: 한국어

## 이 결정으로 달라지는 개선 항목

- 보고서 8·10번(v1 큰 함수 분리, 화면 정적 파일 분리)은 **보류**한다. 동결된 코드는 크게 고치지 않는다. 보안 수정 때 필요한 부분만 손댄다.
- 보고서 9번 커버리지 보강은 v2 모듈에 집중한다.
- v1에 남는 일은 보안 항목뿐이다.
  - 4번: 공개 경로 경계 제한
  - 5번: 공유 속도 제한
  - 11번: 백그라운드 작업 중복
  - 15번: 기능을 켤 때의 운영 동적 점검
