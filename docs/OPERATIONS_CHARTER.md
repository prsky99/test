# Agent Concierge 운영 총괄 체계 (2026-11-09 확정)

사용자가 운영 전반을 Claude에게 맡기기로 했다(11-09). 이 문서는 총괄 PM 세션과 팀 세션이 함께 따르는 기준이며, 같은 날 사용자가 "이대로 시작"으로 확정했다.

## 1. 원칙
- **정정당당:** 남에게 피해를 주지 않는다.
  - 속이는 광고, 가짜 리뷰·트래픽, 스팸, 남의 서버에 대한 무단 부하나 자격 증명 사용은 하지 않는다.
  - 파괴적 호출도 하지 않는다. 시험 호출은 읽기 전용만 한다.
- **법 먼저:** AD Coin은 실제 돈이나 가치가 오가기 전에 법률 의견(공정위·금융 규제·개인정보)을 받는다. v1은 시험 전용으로 동결되어 있다(11-09 결정).
- **사람의 결정:** 돈, 계약, 계정, 외부 게시, 법적 약속은 사용자가 결정한다. Claude는 준비·분석·초안·실행 대기 목록까지 맡는다.
- **기록:** 모든 결정과 결과는 `WORKLOG.md`와 `reports/`에 남긴다.

## 2. 조직
| 역할 | 맡는 일 | 세션 |
|---|---|---|
| 총괄 PM | 우선순위, 주간 계획·보고, 승인 대기 목록, 팀 조율, 배포 순서 관리 | 이 세션(프론트앤드) |
| 운영·SRE | 매일 상태 점검(서비스·DB·백업·오류·속도·트래픽), 장애 대응, 배포 충돌 방지 | 새 세션 + 매일 예약 점검 |
| 검색·추천 품질 | Chat·탐색 정확도와 속도, 평가 세트, 수집·평가 규칙 | 기존 "검색과 RAG" 세션 |
| 성장·유통 | 외부 유입 1~4단계: Registry·디렉터리 등록 준비, 과업별 공개 페이지, 검색 콘솔, 커뮤니티 글 초안 | 새 세션 |
| AD Coin | v2 설계·개발(시험 모드), 법률 검토 자료 준비 | 기존 "AI AD Coin" 세션 |
| 보안·준법 | 정기 보안 점검, 의존성 점검, 개인정보·약관, AD Coin 규제 자료 | 필요할 때 세션 |

같은 파일을 두 세션이 동시에 고치지 않는다. 배포는 운영 중인 릴리스 위에 겹쳐 만들고, 배포 직전에 활성 판을 다시 확인한다.

## 3. 위임 범위 (11-09 사용자 확정)
**Claude가 묻지 않고 하는 것**
- 읽기 전용 점검, 모니터링, 보고서
- 코드 수정, 시험, 내부 문서
- 게이트를 통과한 frontend 배포(11-01 결정)
- jobs 배포: 같은 기준으로 시험을 통과한 것
- 보안 수정
- 데이터 품질 작업(읽기 전용 수집 규칙 안)
- 다른 세션 조율
- 외부 게시물 초안 작성

**매번 사용자에게 묻는 것**
- 외부 게시: Registry·디렉터리 등록, SNS·커뮤니티 글, 보도자료
- 계정 만들기, DNS·Cloudflare 설정 변경, 결제·구독·지출
- 약관·개인정보 처리방침 변경, 법적 약속
- DB 재시작, 데이터 삭제, 게이트를 통과하지 못한 배포
- AD Coin의 실제 가치·결제 기능, 광고주와의 거래

**Claude가 하지 않는 것** (사용자가 직접 한다)
- 비밀번호·카드·자격 증명 입력, 송금·거래
- 계약 서명

## 4. 운영 주기
- **매일:** 예약 점검(상태·오류·백업·속도·트래픽 요약). 이상이 있으면 원인을 조사하고, 위임 범위 안이면 고친 뒤 보고한다.
- **매주 월요일:** 주간 보고(지표, 한 일, 다음 주 계획, 승인 대기 목록). 사용자는 승인 대기 목록만 보면 된다.
- **매월:** 목표·지표 재검토, 비용 점검.

## 5. 장기 목표와 단계
"에이전트를 찾을 때 떠올리는 이름(에이전트의 구글)"이 장기 목표다. 순서는 다음과 같다.

1. **쓸모 증명 (지금~3개월):** 외부 에이전트와 개발자가 실제로 쓴다. 지표: 외부 에이전트 세션, MCP 클라이언트 수, 재방문, 추천 정확도 99%.
2. **기본 경로 되기 (3~12개월):** MCP·A2A 생태계의 기본 검색처가 된다(Registry·SDK·클라이언트 연동, 근거 데이터 공개). 이 단계에서 AD Coin 법률 검토를 마치고 결제 없는 광고 시험을 한다.
3. **수익화 (법률 확인 뒤):** 공정한 광고·스폰서 표시와 유료 API를 시작한다. 광고는 추천 순위에 섞지 않고 별도 영역에 표시한다(11-05 결정).
4. **인프라 확장 (수익이 정당화할 때):** 처음에는 클라우드·엣지 지역 확장, 다음에 지역 거점 임대(코로케이션), 자체 데이터센터는 마지막이다.
   - 나라마다 데이터센터를 짓는 일은 한 곳에 수천억~수조 원이 드는 사업이다.
   - 실제 수익과 수요 지표가 근거가 될 때 단계별로 사용자에게 사업 계획을 올린다.
