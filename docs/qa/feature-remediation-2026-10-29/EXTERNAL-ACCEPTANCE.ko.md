# 별도 수용 검증이 필요한 항목

2026-10-29. 미실행 항목을 자동 시험 점수로 대신하지 않습니다.

## AP2 및 A2A x402 실제 결제

현재 검사 전용 경로를 실제 정산 지원으로 선언하지 않습니다. A2A x402 v0.2는 확인 가능한 결제·정산 흐름이 필요합니다. [공식 규격](https://github.com/google-agentic-commerce/a2a-x402/blob/main/spec/v0.2/spec.md)을 기준으로 다음 순서로 준비합니다.

1. 실제 판매자·지원 네트워크·정산 자산·facilitator·계약 주체를 결정합니다. 사용자의 지출 한도와 승인·취소·기한을 별도 권한으로 받습니다. 저장된 제공자 인증은 결제 승인으로 재사용하지 않습니다.
2. AP2 mandate를 채택한다면 공개 키/서명 체인, 범위·금액·수신자·만료를 검증하는 실제 어댑터를 구현합니다. 로컬 HMAC 샌드박스를 AP2 호환이라고 광고하지 않습니다.
3. 상태는 승인 대기→검증됨→정산 중→정산 확인/거절/결과 불명으로 분리합니다. 영속적인 Idempotency-Key와 요청 지문을 결합하고, 정산 결과 불명 상태에서는 재청구보다 조회·조정을 먼저 수행합니다.
4. 실패 코드는 만료, 사용자 거부, 정책 거부, 증빙 불일치, 이미 처리됨, 정산 미확인 등으로 구분합니다. 공개 응답에 키·서명 원문·지갑 비밀을 노출하지 않습니다.
5. 격리 네트워크에서 정상·중복·만료·재생·금액/수신자 변경·facilitator 지연을 검증하고 실제 제공자와 승인된 최소 금액의 종단 시험을 합니다. 사용자의 실제 지출 승인과 판매자 설정이 확보되기 전에는 송금하지 않습니다.
6. 해당 시험을 통과한 배포에만 정확한 확장 URI·버전을 Agent Card에 선언합니다. 지출을 일으키는 도구는 읽기 전용으로 표시하지 않습니다. 현재 사용자 Chat의 상업 정보 비노출 정책은 유지합니다.

## 실제 사람 5명 × 6과업

모집·실행·일정은 아직 잡지 않았습니다. 대상: 서비스 처음 사용하는 사람 3명, 에이전트 도구 사용자 2명. 데스크톱과 모바일을 나눠 동일한 데이터 상태에서 진행합니다. 관찰 중 직접 정답을 유도하지 않습니다.

- 과업 1: 홈에서 실제로 확인된 수치와 확인 시각을 찾고 상태 화면으로 이동합니다.
- 과업 2: Explore에서 GitHub issues 또는 문서 번역을 찾고 필터·자동완성·오타 제안을 사용합니다. Grid/List 전환 후 원하는 결과를 엽니다.
- 과업 3: Chat에 자연어로 요청하고 두 번째 추천과 `it`을 이어 묻습니다. 선정 근거와 제공자 설명을 구별하고 중단·재시도를 합니다.
- 과업 4: 추천 두 개를 비교하고 공개 공유 링크를 다른 세션에서 엽니다. 대화나 식별 정보가 공유되지 않았는지 확인합니다.
- 과업 5: Test에서 예제를 실행하고 실제 실행/캐시, 원본 조회 시각, 게이트웨이 시간을 구분해 설명합니다.
- 과업 6: OAuth 로그인 후 템플릿을 선택하고 검증용 워크플로우를 저장·실행합니다. 실행은 시험 계정과 승인된 크레딧을 사용하고 기존 자료를 수정하지 않습니다.

각 과업에 참가자 가명, 장치·화면 폭, 시작/완료 시각, 성공/도움 후 성공/실패, 도움 횟수, 사용자가 말한 기대와 실제 동작, 불편도 1~7, 전후 캡처 파일명, 결함 번호와 수정 후 재시험 결과를 기록합니다. 개인 대화·메일·토큰은 증적에서 가립니다. 주요 과업에서 중대 실패가 하나라도 있으면 출시 수용을 보류하고 재시험합니다. 성공률과 시간은 실제 관측값으로만 집계합니다.

## 실제 스크린리더 사용자 1~2명

VoiceOver/Safari 또는 NVDA/Chrome 사용자와 키보드만으로 같은 여섯 과업을 진행합니다. 포커스 순서·쿠키 배너 가림·추천 알림 중복·결과 내부 스크롤 진입/이탈·비교 표의 행/열 제목·중단 후 포커스 복귀·오류 안내를 확인합니다. 자동 axe 결과와 실제 보조기술의 사용 성공을 별도로 기록합니다. 참가자 시험은 자동화 통과만으로 대체하지 않습니다.

수용 후 분기별 재시험이 적절하지만 이번 작업에서 일정이나 자동 알림을 임의로 만들지는 않았습니다.
