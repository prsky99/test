- **UI/UX 종합:** 70 → **71점(B)**

  - 접근성 78 → 75
- **크게 좋아진 것:**
  - **화면 밀림(CLS):** 최대 0.64 → **0.104**. 0.1을 넘는 화면은 모바일 Workflows 하나입니다.

  - **날씨 분류:** `weather` 상위가 모두 "Travel, Maps & Weather"입니다. Agent Weather도 날씨로 옮겨졌습니다.
  - **오타:** `translte`가 0건에서 결과가 나옵니다(Transel, DePunks TRANSLATOR).
  - **Explore `github` 검색:** GitHub 관련 서비스만 나옵니다(GITHUB-AUDIT, github-analyzer, github-dev-intel).
  - **에이전트 API:** `readOnlyHint`(search·find_agents·whats_new), 목록 API `ETag`/캐시, robots.txt 캐시 헤더, 모르는 방문 토큰 알림이 생겼습니다.
  - **카탈로그 수:** llms.txt와 Status가 같은 일일 스냅샷 숫자를 씁니다(196,335 등).
  - **x402 122024·108808:** 둘 다 `403 POLICY_DENIED`로 정리됐습니다(이전 503 / v1).
- **새 문제:**
  - **모바일 가로 넘침:** 홈과 Chat에서 390px은 176px, 320px은 246px만큼 가로로 넘칩니다. 원인은 `select#chatProtocol`의 폭이 533px로 고정된 것입니다.
  - **Test 예제:** 4개 중 2개(Country Profile, GitHub Issues)가 비활성이고, 나머지 2개(Technology News, Research Papers)와 Package Metadata는 실행하면 `502`로 실패합니다(`execution_succeeded: false`).
  - **Chat 추천이 다시 흔들립니다.** 서울 날씨 → com.get4agent/marketplace, 영어 문서 번역·한국어 계약서 번역 → Sats4AI(비트코인 AI 도구)
- **GitHub 이슈(이번에 판정 포함):**
  - Explore `github` 검색은 좋아졌습니다.
  - Chat·MCP의 "Search GitHub issues…" 1위는 여전히 io.github.UnityNodes/canton-ccpedia입니다. GitHub 이슈 도구(`github-api.listRepoIssues`, `search_github_issues`)를 가진 서비스는 2·3위에 있습니다.

## 남은 작업 (우선순위 순)
1. **모바일 가로 넘침:** `select#chatProtocol`에 `width: 100%; max-width: 100%`(또는 `min-width: 0`)를 줍니다. 고치면 접근성 +3점, 모바일 +1.6점입니다.
2. **Test 예제:** 실행 가능한 예제 3개가 모두 502이고 2개는 비활성입니다. 예제 대상 서비스(사이트 자체 소유 데이터 에이전트)의 상태를 확인합니다. 실패하면 화면에 "예제 서비스 점검 중"을 보여 줍니다.
3. **Chat 추천 안정성:**
   - 날씨 → marketplace, 번역 → Sats4AI처럼 6차보다 나빠진 항목이 있습니다.

   - Explore의 개선된 분류·검색을 Chat 후보 선택에도 같이 씁니다.
4. **x402 첫 402 응답에도 `inspection_only`와 `provider_url`을 넣고**, 403 문구를 "이 항목은 정책상 게이트웨이 실행이 막혀 있습니다"처럼 바꿉니다.
