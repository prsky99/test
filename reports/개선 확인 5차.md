## 요약
- **UI/UX 종합 점수:** 64 → **68점(C)**
  - 사람 62 → 64
  - 에이전트 62 → 68
  - **접근성 69 → 74(B)**
- **크게 좋아진 것:**
  - **속도:** 정적 파일 캐시가 생겼습니다. 첫 화면은 DOMContentLoaded 0.79초, 전송량 47KB입니다. LCP p75는 0.62초, TTFB 중앙값은 0.37초입니다.
  - **색 대비:** 위반 231곳에서 0곳이 됐습니다.
  - **포커스:** 다른 요소에 가린 포커스가 0건입니다.
  - **오류 형식:** REST 깨진 JSON은 400, `limit` 오류는 읽기 쉬운 문장으로 나옵니다.
  - **요청 한도 헤더:** 목록 API에 `RateLimit-Policy`가 붙고, CORS 노출 헤더에 `Retry-After`가 들어갔습니다.
  - **목록 API 커서:** `next_cursor`가 생겼습니다.
  - **MCP 서버 카드:** `/.well-known/mcp/server.json`이 생겼습니다.
  - **결제 실패 이유:** `reason: invalid_payload`, `invalid_x402_version`처럼 나옵니다.
  - **크레딧 없는 `call`:** 필요한 조건을 순서대로 안내합니다.
- **새 문제:**
  - **화면 밀림(CLS)이 거의 모든 화면으로 번졌습니다.** 데스크톱 0.15~0.25, 모바일 0.27~0.47, 320px 0.49~0.64입니다.
  - **게이트웨이가 결제를 받지 않게 바뀌었습니다.** x402 게이트웨이는 결제 헤더에 `501 PAYMENT_EXECUTION_DISABLED`("This public gateway inspects x402 listings but does not accept or forward payments")를 줍니다. 그런데 결제 요구 응답(402)은 그대로 내보내, 결제해도 소용없는 결제를 요구하는 모양이 됐습니다.
