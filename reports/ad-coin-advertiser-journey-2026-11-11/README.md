# 처음 온 광고주 여정 점검 (2026-11-11)

- **요청:** 총괄 PM. 사용자 지시 "광고주 만족도 100%"를 확인하기 위해, 화면 측정값이 아니라 처음 온 광고주가 끝까지 해낼 수 있는지를 본다.
- **방법(두 갈래)**
  - **운영 공개 주소:** 로그인하지 않은 첫 방문만 본다. 데스크톱과 폰에서 읽기만 했다.
    - 로그인과 계정 만들기는 직접 할 수 없다.
    - 운영 DB에 시험 기록을 남기지 않는다(PM 결정).
  - **로컬 시험 서버:** 운영과 같은 v2 코드를 따로 띄운 시험 PostgreSQL에서 돌렸다. 로그인은 시험용 사이트 세션이다. 내장 브라우저로 처음부터 끝까지 진행했다.
    - 운영에 아직 없는 운영자 단계(운영자 지정, 첫 발행 1만, 활성화 스위치)는 시험 서버에서만 켰다.
    - 결제 스위치도 시험 서버에서만 켰다(받는 주소는 가짜, Base RPC는 읽기만).
- **결과 요약**
  - 신청 → 승인 → 캠페인 → 심사 → 예산 승인·켜기 → 예약(코인) → USDC 결제 안내까지는 끝까지 간다.
  - 다만 다음 두 가지가 비어 있어서, 광고주가 "결과를 확인"하는 단계는 지금 불가능하다.
    - **노출될 곳**: 메인 Explore와 Chat에 Sponsored 영역이 없다.
    - **결과 보고서**: P1 보고서는 발행하는 코드가 없었다(ffb5b2a2로 고침). Sponsored 보고서는 아예 없다.

## 1. 단계별 기록 (로컬, 데스크톱 기준. 폰은 측정 시험 20회로 확인)

| 단계 | 클릭(대략) | 막힌 곳·불분명한 곳 | 조치 |
|---|---|---|---|
| 상품 이해 | 0~2 | `/ad-coin/v2`가 광고 보는 사람용 Rewards로 열린다. 광고주에게 무엇을 사는지(노출 위치, 가격, 도달)를 설명하는 머리말이 없다. 메인 사이트에서 이 페이지로 오는 링크도 없다 | **정책:** 광고주 소개 페이지·링크(아래 3절) |
| 로그인 | 1 | 처음 온 사람에게 "Sign in again to continue"가 뜨고, 로그인 버튼이 없다 | **고침:** "Sign in to continue…" 문구와 Sign in 버튼 |
| 신청 | 5 | 확인 카드가 페이지 맨 아래(약관 아래)에 떠서 멀다. 머리말이 "Review before you allow"(광고 보는 사람 문구)다. 결과 문구가 보이지 않는 위치에 나온다 | **고침:** "Review before you confirm", 결과 문구를 화면 가운데로 스크롤 |
| 승인 대기 | — | 신청하자마자 "Advertising account 1"이 열린 것처럼 보인다. "No campaigns yet. Create a draft"가 바로 만들 수 있는 것처럼 안내한다. 승인을 어떻게 알게 되는지 없다 | **고침:** "· application under review" 표시, 캠페인 버튼 누르면 심사 중 안내. **정책:** 승인 알림(메일 등) |
| 캠페인 만들기 | 8 | 기간 기본값이 하루(예약 가능일 30일과 안 맞음). 분류·지역이 알파벳 첫 값(commerce, DE)으로 미리 골라짐. 예산 단위가 "test credits"와 "coins"로 섞임 | **고침:** 기본 31일, 분류·지역은 직접 고르게, 단위 "coins"로 통일 |
| 심사 | 1 + 대기 | 카드 상태가 "in review · unapproved" 같은 내부 상태어 | **고침:** "In review · we check the ad before it can run" 등 다음 할 일 문장 |
| 예산 승인·켜기 | 3 | Review budget과 Activate가 따로 있다. Sponsored만 사려는 광고주도 보기 보상 광고의 예산과 보기당 보상을 채워야 한다(두 상품이 섞임) | **정책:** Sponsored 전용 간단 캠페인(아래 2절) |
| 예약(코인) | 5 | 날짜가 브라우저 언어(한국어)로 표시됨 | **고침:** 영어·UTC 표기로 통일 |
| 예약(USDC) | 4 | 존재하지 않는 거래 해시에도 "Payment found"라고 함. 유료 예약이 예약 목록에 안 보임 | **고침:** "Waiting for this transaction to be confirmed…", 목록에 USDC 예약과 상태 표시 |
| 결과 확인 | 2 | 켜진 캠페인인데 "after a campaign is activated"라고 안내. 보고서가 실제로 안 나옴 | **고침:** 문구. 보고서 발행(ffb5b2a2). **설계 승인됨:** Sponsored 하루·칸별 노출 수 보고서 |
| 머리글(폰) | — | Account 버튼이 "Accou / nt"로 쪼개짐(운영에서 확인) | **고침:** 폰에서는 아이콘만(이름은 aria-label 유지). 측정에 "쪼개진 한 단어" 검사 추가 |

- **고친 것 밖의 결함:** 결제 스위치를 켜면 v2 조립이 실패하던 import 오류를 ffb5b2a2로 고쳤다.
- **측정한 시간(로컬, 버튼 처리 시간만):** 열기와 신청 2.5초, 캠페인 만들기와 심사 요청 2.4초, 예산 승인과 켜기 3.3초, 예약 1.5초. 사람이 입력하는 시간과 운영자를 기다리는 시간은 빠져 있다.

| 단계 | Google Ads | Meta | Carbon/EthicalAds (개발자 광고) | 우리 | 판단 |

## 3. PM 결정이 필요한 것

1. **노출 위치:** 메인 Explore 또는 Chat에 Sponsored 영역 붙이기. 사용자 결정 대기(PM).
2. **광고주 소개 랜딩과 메인 링크:** "Advertise" 링크와 짧은 소개를 둔다. 소개 내용: 노출 위치, 가격(하루 1칸 5 USDC 또는 50 coins), 심사 기준. 메인 화면 변경이다.
3. **승인 알림:** 신청 결과를 메일로 알릴지. contact@ 발신이고 무료 경로.
4. **Sponsored 전용 간단 캠페인:** 보기 보상 예산 없이 "문구 + 분류·지역"만으로 예약할 수 있게 한다. 상품 분리라 설계 결정이 필요하다.
