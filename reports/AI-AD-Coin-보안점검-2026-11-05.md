# AI AD Coin 시큐어코딩·동적 보안 취약점 점검 (2026-11-05)

- **대상:** `agent_market/ad_coin/`(19개 모듈, 약 5,300줄), AD Coin 운영 스크립트, 세 화면(광고주 콘솔, 사람용 `/ad-coin`, 운영 `/ad-coin/admin`)
- **기준:** OWASP ASVS 5.0, OWASP API Security Top 10, 프로젝트 규칙(AGENTS.md, GEMINI.md, CLAUDE.md, `docs/AD_COIN_TARGETS.md` 보안 관문)
- **원자료:** `reports/ad-coin-security-2026-11-05/bandit.json`, `dynamic-security.json`
- **재실행 명령:**
  ```bash
  nice -n 10 .venv-tests/bin/python -m scripts.ad_coin_dynamic_security --out reports/<폴더>
  ```

- 동적 점검 **219개 모두 통과**했다.

### 2.2 오탐 판정 근거

- **B608 (18건): 오탐**
  - 끼워 넣는 것은 세 가지뿐이다: 자리표시자 묶음(`?,?,…`), 코드에 고정된 열·조건, 허용 목록의 표 이름(`lock_rows`는 `ad_coin_campaigns`만, 이전 도구는 스키마에서 뽑은 이름).
  - 값은 모두 매개변수로 넘긴다.
  - 게다가 모든 문장이 등록 SQL 검사(174개 모양)를 통과해야 DB에 닿는다.
- **B110 (예외 무시 3건):** 연결 닫기 같은 정리 작업이다.
- **B311 (`random` 1건):** 합계 줄(16줄) 중 하나를 고르는 데 쓴다. 보안 난수가 필요한 곳이 아니다.
- **B404·B603 (2건):** 등록 목록 생성 도구가 고정 인자로 시험을 실행한다.

### 2.4 이상 없음으로 확인한 항목

- **외부 요청:** AD Coin 코드는 외부 주소로 요청을 보내지 않는다(SSRF 없음).
- **XSS:** 화면에 `innerHTML`, `document.write`, `eval`, `new Function`을 쓰지 않는다. 데이터는 모두 `textContent`로만 넣는다.
- **CSP:** 같은 출처 스크립트·스타일만 허용하고, 다른 사이트의 화면 안에 끼워 넣는 것(framing)을 막는다.
- **비밀값:** 관리자 토큰, CSRF 값, 오퍼 토큰은 상수 시간 비교(`hmac.compare_digest`)를 쓴다. 에이전트 키는 해시로 저장한다.
- **위험 함수:** pickle, marshal, exec, `yaml.load`, `shell=True`를 쓰지 않는다.
- **입력 크기:** 요청 본문은 32KiB까지, 묶음 단계는 20줄까지다. 금액은 정수, 10원 단위, 범위 검사를 한다.
- **로그:** 보안 이벤트에 토큰, 키, 사람 식별자, 본문을 남기지 않는다(시험으로 확인).
- **의존 패키지:** 같은 날 다른 세션이 의존성 감사를 마쳤다. 운영·시험 의존성에 알려진 취약점이 없다.

## 4. 한계와 남은 일

- **범위:** 점검은 AD Coin 코드와 그 경로다. 고객 로그인 자체(세션 발급, OAuth)는 공용 고객 워크스페이스의 몫이라 시험용 로그인 대역으로 대신했다.
- **공개 경로 속도 제한:** 인증 없이 열린 공개 경로(`/status`, `/offer-feed`, `/account`)에는 AD Coin 자체 속도 제한이 없다.
  - 대신 `/status`는 O(1) 점검으로 바꿨고, 오퍼 피드는 Web Bot Auth가 없으면 빈 응답을 바로 돌려준다.
  - 요청 폭주는 운영 경계(Cloudflare·Caddy)에서 막는다. 기능을 켤 때 경계 설정을 확인해야 한다.
- **기능을 켠 뒤:** 운영 환경에서 시험 계정으로 동적 점검을 다시 한다.
  - 대상: 실제 고객 로그인, Cloudflare 경계, 실제 Web Bot Auth 서명
  - 명령은 같고, 대상만 운영 주소로 바꾼다.
- **이번 점검 시점의 운영 상태:** AD Coin 기능이 꺼져 있어 운영 주소의 AD Coin 경로는 404다.
