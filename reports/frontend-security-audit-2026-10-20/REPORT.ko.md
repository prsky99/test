## 메뉴·기능별 검토

### 홈·현황·배우기·소개·공통 화면

공개 데이터만 부트스트랩하는지, HTML 문맥을 벗어나는 문자열이 실행되지 않는지, 페이지·오류 응답에서 CSP/클릭재킹 방지/nosniff/no-referrer/no-store가 유지되는지 확인했습니다. 43개 페이지마다 nonce가 새로 발급되고, 모든 script 태그에 해당 응답 nonce가 적용됩니다. 공개 HTTPS 홈·탐색·로그인·조직 화면은 HTTP 200, JavaScript 예외 0, CSP 차단 콘솔 메시지 0이었습니다.

### 탐색·에이전트 상세·보고서

검색 메타문자와 SQL 삽입 문자열, FTS 입력, 필터 경계를 검사했습니다. SQL 값은 바인딩되며 정적 조건과 내부 식별자만 조합합니다. 보고서의 주체/에이전트/프로토콜이 일치해야 공개되고, 내부 헤더·개인정보·진단·방문자 토큰이 마스킹되는 경계를 검사했습니다. 에이전트 이름·설명·보고서 Markdown은 출력 이스케이프를 거칩니다.

### 테스트·에이전트 등록

허용한 등록 에이전트·도구·스키마만 호출하는지, 임의 목적지/인증 정보/요청 필드/타임아웃/과대 본문이 거절되는지 확인했습니다. 외부 호출은 공인 IP 검사와 연결 시 IP 고정, TLS 검증, 환경 프록시 무시, 리다이렉트 금지, 시간·응답 크기·동시성 제한을 적용합니다. DNS 재바인딩, 루프백·사설·메타데이터 주소, 축약/우회 IP를 격리된 모의 전송에서 검사했습니다.

### 워크플로우·다운로드·SDK

공개된 정의와 해시, 실행 capability, 결과 조회/취소 권한, 출처 및 재사용 제한을 검사했습니다. 상태 불명 응답은 자동 재실행하지 않고, 복구/권한 변경 후 오래된 티켓이 실행되지 않는 경계를 확인했습니다. 다운로드 앱의 문자열 스크립트 탈출, 연결 원본 제한, 비밀 권한 비노출, BFF 응답 크기/중복 키/비유한 수/깊이 제한을 검사했습니다. 참고용 ZIP에도 절대 경로·상위 경로·키·환경 설정·DB 파일이 없습니다.

### 채팅

추천·상세·입력·오류에서 방문자 토큰·원시 JSON·내부 진단·결제 정보를 노출하지 않는지 확인했습니다. 공격 문자열이 HTML로 실행되지 않으며, 실패 응답의 내부 오류는 화면에 표시되지 않습니다. 오류 후 사용자의 질문이 보존되고 전송 버튼이 정상 복원되는지도 검증했습니다.

### 푸터·문의·개인정보·선택 알림

문의/개인정보 요청의 입력 검증, 저장 XSS/SQL 삽입, 권한 없는 어드민 조회, 요청 한도, 허위 성공 영수증 방지를 검사했습니다. 알림은 목적별 동의, 목적지 확인, 광고 동의 분리/철회, 보류 요청 삭제 경계를 검증했습니다. 브라우저 알림은 실제 Chromium 서비스 워커 경로에서 모의 PushSubscription/OS 알림을 사용해 클릭 증명과 확인·거절·취소 상태를 검사합니다. 실제 푸시 서비스나 개인 주소로 발송한 검사는 아닙니다.

### 로그인·조직·워크스페이스

Google/GitHub 흐름의 state/PKCE/nonce/issuer/서명/클레임/만료/일회성 콜백을 합성 계정과 모의 제공자로 검사했습니다. 세션 쿠키는 Secure·HttpOnly·SameSite 및 host-only 접두사를 적용합니다. CSRF/교차 출처·세션 철회·계정 간 ID 혼합·비회원 접근·소유자/편집자/조회자 역할·초대·소유권 이전·복구 권한을 검사했습니다. 서버 키나 방문자 토큰이 개별 워크스페이스 사용자 권한을 대신하지 못합니다.

### AI 제안·자동화 권한

공개된 목적과 승인 후보만 모델 입력으로 제공하는 경계를 검사했습니다. 모델 응답이 새 도구/URL/명령/소스/권한을 주입하거나 별도 검토 없이 저장·실행·공개되지 못하도록 검사했습니다. 압축 응답/과대 본문/깊은 JSON/타임아웃/권한 변경 시 제안을 거부합니다. 실제 운영 모델의 모든 가능한 응답에 대한 증명은 아닙니다.

### PostgreSQL 18 + pgvector

대부분의 API·브라우저 회귀는 격리 SQLite에서 실행했습니다. 추가로 전용 임시 PostgreSQL 18 + pgvector 클러스터에서 대형 검색 데이터와 악성 필터 값의 바인딩, 미등록 SQL 거절, 다른 스레드의 실패가 정상 트랜잭션에 전파되지 않는 경계를 2개 통합 회귀로 확인했습니다. 모든 1,243개 사례를 PostgreSQL로 다시 실행한 것은 아닙니다.

## 정적 경고 판정

세부 파일·행·규칙별 판정은 `static-warning-review.json`에 있습니다. SQL 경고는 고정 내부 식별자/조건/바인딩 값 또는 HTML 안의 SQL 유사 단어였습니다. 그 외는 OAuth URL·프로토콜 문자열을 비밀번호로 판단한 경고, 테스트 캐시 네임스페이스의 임시 경로 확인, 사설 주소 비교, 선택적 탐지·정리 실패 처리, 오프라인 아카이브 subprocess import입니다. 검토 문맥에서 취약점으로 확인되지 않았으며, 운영 코드를 약화시키거나 경고를 일괄 무시하는 설정을 추가하지 않았습니다.
