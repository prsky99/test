## 새 문제
1. **에이전트 상세 API 500**(위)
2. **Chat 요청 한도에 걸렸을 때 안내가 일반 문구입니다.**
   - 33개 질문을 질문마다 5~10초 간격(새 브라우저)으로 보냈는데, 마지막 3개가 429였습니다.
   - 화면에는 "The request could not be completed. Your question is kept; try again when ready."만 나옵니다.
   - 그 직후 단일 요청도 429(`Retry-After: 60`)였습니다. 정책(`q=60;w=60`, 1분 60회)보다 실제 한도가 훨씬 빡빡해 보입니다.
   - 개선:
     - 화면에 "잠시 후(60초) 다시 시도"처럼 `Retry-After`를 보여 줍니다.
     - 실제 한도와 `RateLimit-Policy` 값을 맞춥니다.
3. **x402 추천 이름이 "Recommended agent"로 나옵니다.** "x402 paid API for stock quotes under one cent" 질문의 1위 카드 이름이 실제 이름 대신 "Recommended agent"입니다(`/api/gateway/x402/177749`).
