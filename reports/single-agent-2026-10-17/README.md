# 무료 단일 에이전트 추천 적용 기록

질문별 추천을 기본 3개·단골 5개에서 **1개**로 바꾸었다. 질문에 적합한 정상 후보를 남긴 뒤 품질 등급, 최신 성공 테스트 보고서 등록 시각, 최근 성공 활성 확인 시각을 우선한다. 이후 실제 성공 근거, 세부 평가 점수, 성공률, 관측 지연시간과 관련성으로 동점을 해소한다. 미평가 후보는 평가된 후보보다 뒤에 두며, F등급·현재 장애·격리·최신 실패 근거가 해소되지 않은 후보는 제외한다.

단골·방문 횟수, 가격, 인기·결제자 수, 인증·프로토콜 선호 조건은 순위에서 제거했다. 실제 작업의 관련성과 호출 가능성을 확인하는 안전 조건은 유지한다. 근거가 없으면 `no_match`를 반환한다. 모든 질문에 관계없는 에이전트나 주소를 만들어 넣는 방식은 사용하지 않는다.

## 구현

- `agent_market/concierge/selection.py`: 단일 선정기. 로컬 FTS로 후보 메타데이터만 읽고, 품질 근거 순으로 정렬한 뒤 상위 근거 그룹부터 작업 관련성을 확인한다. 동일한 근거 그룹 전체를 비교해 관련성과 고정 ID로 동점을 해소한다. 후보 개수 제한이나 응답 캐시가 없어 새 보고서와 장애 정보가 즉시 반영된다.
- `agent_market/concierge/fast_chat.py`: LLM·임베딩·RAG·실시간 외부 확인을 사용하지 않는 기본 대화 엔진. 추천·상세·대체 후보는 최대 1개, 응답 문장은 연결에 필요한 사실만 담는다.
- `front.py`, `extracted_html.txt`: 공통 REST/A2A/MCP 연결과 단일 카드 UI. 등급·보고서·활성 시각과 호출 도구를 표시한다. 방문 토큰은 전송 객체에만 담고 입력 마스킹·CSP·이스케이프는 유지한다.
- `gateway/store.py`: ID/URL별 보고서 조회 인덱스를 추가했다. 새 실제 호출 기록에 검증 시각이 없으면 저장 시각을 함께 기록한다. 기존 보고서의 숫자·ISO 날짜를 모두 정규화해 비교한다.
- `gateway/server.py`: 기본 대화용 모델 초기화를 제거했다. 다른 RAG·수집·관리 기능은 기존 경로를 사용한다.
- `AGENT_FRONT.md`, `/llms.txt`, 페이지 메타데이터와 운영 점검 스크립트를 새 응답 계약에 맞추었다.

기존 연락처 등록·인증·알림 중단 및 명시적인 도구 호출 기능은 유지한다. 외부 제공자의 x402 요금·인증은 호출 사실로 표시하며 무료 추천 서비스와 구분한다.

## 검증

`tests/test_fast_single_recommendation.py`는 등급 우선, 보고서·활성 시각 동점 해소, 최신 실패 제외, URL 연결 보고서, 날짜 형식 혼합, 즉시 재선정, 단골·가격·프로토콜 무관, 모델 미호출, 관련 없는 후보 제외, 512개를 넘는 후보 처리와 대표 도구 선정을 검증한다. 기존 다중 추천·모델 생성 기대값은 새 계약으로 바꾸고 토큰·관리자 기록·알림·도구 호출 검증을 유지했다.

`tests/test_single_agent_chat_browser.py`는 실제 Chromium과 운영 CSP 헤더를 사용해 한국어 질문 전송, 카드 1개, 검증 정보 표시, 호출 상세 열기와 구형 다중 응답의 단일 표시를 확인한다. 기존 공개 메뉴 XSS·CSP 브라우저 검사도 실행한다.

전체 회귀 **728개 통과**(182.23초), 이후 최종 브라우저·API 검사 **58개 통과**. 마지막 스키마 정규화 변경은 단일 추천·MCP 호출 테스트 **33개**, 보고서 성공·실패 표시는 단일 추천·브라우저 테스트 **27개**로 별도 재검증했다. [full-suite.xml](full-suite.xml)에 전체 실행 결과를 저장했다. 기존 OpenAPI의 중복 Operation ID 경고 1건은 남아 있다.

## 로컬 성능

[benchmark.json](benchmark.json): 실제 카탈로그 **102,633개**, 보고서 **371개**를 담은 임시 파일 DB에서 10종 질의 × 8회, 총 **80회**를 순차 측정했다. 80회 모두 후보 1개를 반환했다. HTTP TestClient 포함 중앙값 **63.50ms**, P95 **254.57ms**; 엔진만 중앙값 **62.12ms**, P95 **252.86ms**였다. 보고서·ID 조회 인덱스와 FTS를 먼저 읽는 쿼리 계획을 적용했다.

원본 DB는 읽기 전용으로 연결했다. 측정에는 실제 검색 색인·검증 메타데이터를 사용했으며 대용량 가이드·응답 본문은 복제하지 않았다. 운영 호출량 제한은 유지하고 측정용 임시 앱에서만 제한을 우회했다. 실제 인터넷 지연, 동시 부하, 외부 에이전트 실행 시간에 대한 수치는 아니다. 공용 운영 사이트에 테스트 질문을 보내거나 외부 에이전트를 호출하지 않았다.

재현:

```sh
PYTHONPATH=. .venv/bin/python reports/single-agent-2026-10-17/benchmark.py \
  --catalog gateway-data/collector.sqlite3 \
  --output /tmp/single-agent-benchmark.json
.venv/bin/pytest -q --tb=short
```

## 적용 범위

현재 작업 디렉터리의 소스와 테스트에 적용했다. 운영 서버 배포·재시작은 실행하지 않았다. 새 코드로 서버를 시작하면 인덱스 생성과 새 대화 경로가 적용된다. 한국어 주요 기능어는 로컬 사전으로 처리하며, 모든 언어와 복잡한 문장 전체에 대한 의미 해석을 보장하지는 않는다. 평가·헬스체크 스케줄러가 멈추어 24시간을 넘기면 오래된 후보를 정상으로 가장하지 않고 추천을 보류한다.
