# 운영자 제공 워크플로우 템플릿 추가 결과

완료: 2026-10-25T08:37:16+09:00

프론트엔드 공개 Workflows → Browse templates에 운영자 제공 템플릿 5개를 추가해 기존 3개에서 총 8개로 확장했습니다. 새 항목은 고객이 만든 워크플로우가 아니라 운영자가 관리하는 공용 템플릿입니다. 저장된 고객 워크플로우·크레딧·스케줄·기존 템플릿과 실행 기록을 변경하지 않았습니다. 서버 재시작 없이 DB에 검증된 정의를 추가해 현재 서비스에 반영했습니다.

## 추가 항목

- **Country Development Snapshot** (ID 44, 에이전트 단계 4개): 미국 국가 프로필 → GDP → 인구 → 기대수명. World Bank의 최신 이용 가능한 연간 관측치와 기준 연도를 표시합니다. 실제 공개 실행 6.795초, 전체 단계 성공.
- **Two-Country Economic Comparison** (ID 45, 에이전트 단계 4개): 미국 프로필·GDP와 한국 프로필·GDP를 차례로 수집합니다. 동일 통화의 기록을 제공하며 기준 연도 비교가 필요합니다. 실제 공개 실행 6.598초, 전체 단계 성공.
- **Two-Package Security Comparison** (ID 46, 에이전트 단계 4개): Express 최신 버전·해당 버전 OSV 권고, Lodash 최신 버전·해당 버전 OSV 권고를 연결합니다. 실제 공개 실행 2.501초, 전체 단계 성공.
- **Package Upgrade Advisory Check** (ID 47, 에이전트 단계 3개): Express 현재 버전을 확인한 다음 예시 설치 버전 4.17.1과 현재 릴리스의 공개 보안 권고를 각각 조회합니다. 실제 패키지 설치나 업그레이드는 하지 않습니다. 실제 공개 실행 4.762초, 전체 단계 성공.
- **AI Research Reading List** (ID 48, 에이전트 단계 2개): RAG 및 AI 에이전트 평가 주제의 Crossref 서지 레코드를 별도 읽기 목록으로 수집하고 DOI 링크를 유지합니다. 실제 공개 실행 6.443초, 전체 단계 성공.

모든 새 템플릿은 수동 실행·읽기 전용입니다. 버전이나 국가 코드 등 다음 단계의 입력은 선언된 이전 노드 출력에서 전달됩니다. 동의 없는 메시지 발송·계정 조작·유료 호출·코드 실행은 포함하지 않습니다. 보안 권고 결과가 비어 있어도 안전을 보장한다고 표현하지 않습니다.

## 공개 전후 검증

1. 공개 전 격리 SQLite 실행 환경에서 실제 MCP 핸들러와 실제 World Bank·npm·OSV·Crossref 원천 데이터를 사용해 각 후보를 2회 실행했습니다. 10개 워크플로우 실행이 모두 성공했습니다. 두 번째 실행은 정상 소스 캐시를 사용할 수 있어 첫 실행과 별도로 기록했습니다.
2. 원본 그래프, 각 에이전트 단계 성공, 시도 횟수, 실제 스키마 해시와 최신 검증 시각을 확인했습니다. 실패·미완료·변경·24시간 경과 증적은 공개 자격을 부여하지 않습니다.
3. 운영 카탈로그의 고정 first-party 키·출처·URL·전체/요약 스키마와 실행 제어를 재확인한 후 5개를 하나의 트랜잭션에서 추가했습니다. 이름이 같은 사용자 작업을 덮어쓰지 않습니다.
4. 공개 HTTPS `/api/workflows/run`을 통해 신규 5개를 다시 실행했습니다. 모두 succeeded이며 에이전트 단계 17개가 정상 완료됐습니다. 실행 키 없는 결과 조회는 모두 HTTP 404였습니다. 실행 키는 메모리에서만 사용하고 보고서에 저장하지 않았습니다.
5. 신규 5개의 웹앱 ZIP 다운로드가 모두 HTTP 200이고 ZIP 무결성 검사가 통과했습니다. ZIP을 외부 다른 호스트에 배포하는 작업은 하지 않았습니다.
6. 실제 Chromium 1440px·390px에서 8개 카드 노출, 새 5개의 선택과 캔버스 단계 수, 실행 버튼 활성화, 진주 단계 표시를 확인했습니다. 가로 넘침 0px·JavaScript 오류 0건이었습니다. 데스크톱 화면에서 Country Development Snapshot을 추가로 실행해 성공 결과를 확인했습니다.
7. 같은 설치 명령을 다시 적용해도 새 템플릿이 추가되지 않는 것을 실제 운영 DB에서도 확인했습니다. 기존 공개 ID 38·39·40은 그대로 유지됩니다.

## 회귀 및 보안

영향 범위 회귀 45개가 통과했습니다. 실행 증적의 그래프·스키마 위조, 실패·미완료·만료, 연결 중지, 설치 중 실패의 전체 롤백, 재적용 중복 방지, 기존 작업 보존, 공개 요청의 임의 그래프 주입 차단, 결과 조회 키 격리, ZIP 다운로드를 포함합니다. 새 3개 파일의 정적 검사가 통과했으며 공개 콘텐츠 263개 파일에서 정책 위반이 없었습니다.

템플릿은 검증 당시 성공한 실제 소스를 사용합니다. 외부 원천의 향후 장애까지 보장하는 것은 아닙니다. 기존 실행 제어·스키마 고정·타임아웃·소스 캐시·실패 처리를 유지했고 가짜 결과나 무조건 성공 처리는 추가하지 않았습니다. 이번 항목은 공개 Workflows 허브용이며, 별도 서명·대체 경로 검증을 요구하는 워크스페이스 protected-product 목록을 확대하거나 그 보호 조건을 낮추지 않았습니다.

별도 UX 관찰: 모바일에서 긴 허브의 아래쪽 템플릿을 선택하면 기존 스크롤 위치가 유지될 수 있습니다. 선택·구성·실행에는 문제가 없으나 선택 화면으로 자동 스크롤하는 동작은 후속 UI 개선 항목입니다. `country-snapshot-mobile-selected.png`는 선택된 화면으로 스크롤한 뒤 캡처한 전체 화면입니다. 새 AI Research Reading List는 All Categories와 이름 검색으로 찾을 수 있으며, 현행 허브에 Docs Knowledge 전용 필터 버튼은 없습니다.
