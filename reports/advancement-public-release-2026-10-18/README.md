## Implemented behavior

[Contract, APIs and limits](../../docs/WORKFLOW_PUBLIC_CONNECTIONS.md). A highest administrator selects one approved stateless MCP news source and one documentation recipient, reviews the fixed query/window/settings and a bounded future-title rule, then separately permits sharing and one live canonical test. The server creates a new signed audience/definition; an earlier private connected or pair test does not authorize it. A certain successful canonical test is followed by a separate publication review and explicit independently revocable grant.

A public visitor reviews exact news inputs, recipient aliases and fixed documentation settings, plus the rule that the first checked news title becomes the documentation query. **The future title is not known before the source call.** It is not represented as an actual title already reviewed. Fresh unchecked sharing and one-run declarations bind a short signed ticket. Runtime admission, dispatch and recovery recheck purpose, nonce, current grant/owner/pins/controls/expiry. Actual derived arguments and signed retained-source provenance are rechecked immediately before docs dispatch; changing a checkpoint while keeping its title does not reuse the captured old provenance.

The 25-second deadline, two tool dispatches, durable certainty/lease/fence/checkpoint rules and conservative unknown quarantine remain. There is no fallback, credential, extended-budget, automatic provider/start retry, schedule/event, result delivery or marketing inheritance. Bounded transient status GET retries remain read-only. A public nonce replay returns the same scoped run/capability while still authorized. New scopes store no legacy public access hash, so old status/cancel routes cannot bypass publication expiry or withdrawal. Status/cancel metadata access remains separate from current provider readiness and proof retention for accepted failures/unknowns. The page visibly marks unknown outcomes and locks another start within the visit; Resume only polls that capability.

The optional Workflows listing displays only active eligible releases. A separate modern English page uses local Lucide icons, native focus, themes/reduced motion, nonce CSP, privacy/TOS links and text-only semantic results. Existing default templates and public SDK 1.0/admin1.1/literal1.2 downloads remain independent. Their8 builder/asset sources are byte-identical to the turn baseline. Private pair publication and connected SDK export/automation remain unavailable through old routes.
