# 백업 복원 연습: 맥미니 사본 (2026-11-10, 운영·SRE)

사용자 지시: "꼭 진행해줘". 맥미니로 옮겨진 백업이 매일 새로 도착하는지 본다. 그 파일로 일회용 PostgreSQL에 복원되고 운영 버전의 앱이 붙는지도 확인한다. 운영 DB에는 연결하지 않았다.

## 결론
- **매일 도착한다.** `/Volumes/kingstone/agentconcierge-backups`(맥미니 SMB 공유, 이 맥에 마운트돼 있음)에 11-04~11-10 스냅샷 7개가 있다. 매일 04:49~04:54에 도착했다. 운영 백업은 04:30에 시작한다.
- **맥미니 사본은 온전하다.**
  - `database.dump`(3.49GB)의 sha256이 manifest와 같다.
  - `pg_restore --data-only -f /dev/null`로 모든 표의 데이터를 끝까지 풀어 읽었고, 오류 없이 48초 걸렸다.
- **복원하면 앱이 붙는다.**
  - 스키마 전체와 큰 표 16개를 뺀 데이터를 일회용 클러스터에 복원했다(2.5초).
  - 지금 운영 중인 frontend `quote-keep-frontend-20261110-r1`과 jobs `backfill-quote-jobs-20261110-r3`로 다음을 확인했다. 모두 통과했다.
    - 앱 연결(스키마 프로필과 트리거 불변 검사)
    - 쓰기 트랜잭션
    - 탐색
- **남은 것: 전체 데이터 복원.** 낮에 맥미니 공유에서 바로, I/O 최저 등급(`taskpolicy -b`)으로 돌렸더니 1시간 제한을 넘겨 중단됐다. 일회용 클러스터는 자동으로 정리됐다. 다음 방법 중 하나로 다시 한다.
  - 새벽(02~04시)에 덤프를 로컬로 먼저 복사(3.5GB)한 뒤 일반 nice로 전체 복원
  - 다른 기계에서 복원(사용자 결정)

## 실행
```bash
# 1) 데이터 전체 읽기 검사
pg_restore --data-only -f /dev/null "/Volumes/kingstone/agentconcierge-backups/snapshot-20261110-043005/database.dump"
# 2) 복원 연습(sha 확인 → 일회용 PG 복원 → 운영 버전 attach)
.venv/bin/python -m scripts.db_change_rehearsal drill --backup "/Volumes/kingstone/agentconcierge-backups/snapshot-20261110-043005" --data minimal
```
- 결과 JSON: `logs/ops/db-rehearsal/drill-macmini-20261110.json`(git 제외)
- 최소 복원 기준 행 수(작은 표만): workflow_runs 141. resources 같은 큰 표는 데이터를 넣지 않았다. 백업 시점 카탈로그는 307,860이다(manifest).
