# AI AD Coin v6.2 상세 설계 검증

2026-11-08 한국 시간 · [상세 설계서](../../docs/AD_COIN_V6_2_DETAILED_DESIGN.md)

공통 권한·명령, 저장 제약·트랜잭션, API 29개, 작업자·외부 연동, UI·운영·검수·migration을 문서화했다. 기존 38개 정책·WP 12개·GROW 28개·DES 10개·v5 검수 43개를 유지하고 DTL 20개 제품 인수 시나리오를 추가했다. 실행용 DDL이나 운영 기능 구현을 완료했다는 뜻은 아니다.

`build_catalog.py`로 상세 카탈로그를 생성하고 `validate_design.py`로 API/권한/원자 경계 매핑·문서 링크·기존 v6.2 OpenAPI/명세 보존·기계 카탈로그 재현성을 확인한다. 결과·해시는 [validation.json](validation.json)에 보관한다. 과거 문서 검증 기록은 덮어쓰지 않는다.

이 검증은 실제 제품 시험이 아니며 DB·인증·노출·PG 경쟁·JWS·체인·실재원·법적 적합성·성능을 검증하지 않는다. 제품 개발 증거는 별도 개발 기록에 남긴다. 상세 설계 완료 후 사용자가 승인한 R0 개발을 WP-01의 사람/에이전트 권한 경계부터 진행한다. 실제 자금·메인넷·운영 배포는 해당 출시 관문을 충족한 별도 범위다.
