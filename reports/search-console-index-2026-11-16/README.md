## 원인 세 갈래
### (가) 옛 사이트맵에 남은 noindex 페이지: 설계상 정상
- 84eea65e(11-14 02:39, 검색 결정 B)부터 아래 에이전트 페이지는 noindex, follow이고 사이트맵에서 빠졌다. 페이지는 계속 열린다.
- 11-16 기준 5,369개:

|---|---|
| x402(수집 중지, 등급 B 상한) | 5,264 |

- 함께 noindex인 페이지: x402 프로토콜 랭킹 20개, x402가 낀 비교 203개
- 그 전 사이트맵은 주소가 약 1만 개였다. Google이 그때 읽은 사이트맵을 다시 읽기 전까지는 이 페이지들이 ①로 보고된다(추정. Search Console을 볼 수 없어 확정하지 못했다).
- ②(링크로 발견했지만 noindex)는 의도한 결과다. 이 페이지들은 사람과 에이전트가 쓰도록 열어 두고, 검색에는 내지 않는다.

### (나) 엣지가 noindex 사본을 사이트맵보다 오래 줌: 5187e7f8로 고침
- 스냅샷은 하루 한 번 바뀐다. 어제 noindex였던 에이전트가 오늘 색인 대상이 되면 이렇게 된다.
  - 사이트맵은 엣지 600초에 최대 3600초 더 지나면 그 주소를 올린다.
  - 그런데 페이지는 엣지가 noindex 사본을 6시간, 최대 하루 더 줬다.
- 고친 뒤: X-Robots-Tag noindex인 성장 페이지는 엣지에 사이트맵과 같은 시간만 남는다. 브라우저 캐시는 300초다. 색인 페이지는 지금처럼 6시간이다.
- 캐시는 비우지 않는다(PM 결정). 이미 엣지에 있는 사본은 저절로 바뀐다.

### (다) 매일 바뀌는 비교 쌍의 404: 74fe37f8로 줄어듦
- Googlebot이 랭킹·비교 주소에서 받은 404 건수(traffic bot_errors):

- 원인: 비교 쌍이 매일 바뀌어, 어제 사이트맵에 있던 쌍이 오늘 없어진다.
- 74fe37f8(11-16 낮 배포)이 둘 중 남아 있는 에이전트 페이지로 302한다. 두 에이전트가 모두 빠진 쌍만 404로 남는다.
- 에이전트 페이지 404는 하루 1~3건이다. 비활성이 된 목록이다.
