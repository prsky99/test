## 3. 목표 용량
- **검증 진주 200개(11-28)**
  - 통과율 40%를 가정하면 후보 약 500개를 두 번씩 시험해야 합니다. 그러면 새 후보만 하루 약 70건이 필요합니다.

  - 조치: 하루 120건(새 80, 재시험 40)으로 올렸습니다. 거절률이 5%를 넘으면 60건으로 되돌립니다. 역할은 11-21까지 30개로 늘립니다(검색과 RAG). 비용은 0이고, 남의 서버 부하는 공용 장부로 막습니다.
- **목걸이 5개(11-28)**
  - 실행기가 아직 없고, 관문은 4시간 간격 2회차가 필요하며, 자체 대체가 필요한 자리가 있습니다.

- **홍보 공백**
  - 홍보 단위는 목걸이인데 첫 공개가 11-21입니다.
  - 성장·유통은 그 전까지 공개 준비(페이지, 도구 설명, 외부 게시 초안)와 브랜드 기준선 측정을 합니다. 외부 게시는 사용자 승인이 필요합니다.
