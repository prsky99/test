# 브랜드 전략 — 에이전트 밸류 게이트웨이 (2026-11-14, 성장·유통, PM 06:4x·07:1x)

사용자 지시
- 브랜드 표기만 고르지 말고 **브랜드 전략**을 세운다.
- 논문·SNS·뉴스를 조사하고, 최신 글로벌 흐름과 AI 트렌드를 반영한 미래 지향 전략으로 만든다.

이 문서가 끝나면 PM이 검토하고 사용자에게 이름 결정을 받는다. **그 전에는 화면을 바꾸지 않는다.**
- 조사는 하위 에이전트 넷이 병렬로 했다. 원자료와 모든 출처(링크·날짜, 근거 수준 표시)는 `research/` 아래에 있다.
  - A: AI 시대 브랜드 트렌드
  - B: AI 플랫폼 이름 사례
  - C: 신뢰 브랜드와 이름 충돌
  - D: 이름 후보와 상표 DB
- 상표 판단은 법률 의견이 아니다. 무료 공개 DB를 계정 없이 검색한 결과다. 법률 자문은 수익이 커진 뒤로 미룬다는 사용자 결정을 따른다.

## 0. 한 장 요약

1. **지금 이름도, 사용자가 고른 이름도 충돌한다.**
   - "Agent Concierge"는 같은 일을 하는 경쟁 서비스(agentconcierge.io)가 있다. 미국에는 같은 이름의 AI 에이전트 분야(42류) 상표 출원(99797306, Snagabiz LLC, 2026-04-30 출원, 최초 사용 주장 2026-02-01)도 있다.
   - "Agentcon"은 AI 에이전트 개발자 행사 시리즈 AgentCon(Global AI Community, 66~67개 도시, 서울 포함)과 겹친다.
   - 둘 다 등록 상표가 막고 있는 것은 아니다. 그러나 같은 분야의 먼저 쓴 사용자가 있다.
2. **에이전트 시대의 이름은 "사람이 기억하는 고유 이름 + 에이전트가 이해하는 기능 설명"의 두 겹이다.**
   - 에이전트는 질의와 이름·설명의 의미가 맞는 도구를 고른다(ICLR 2026 BiasBusters).
   - 사람과 상표는 고유한 이름이 필요하다(설명형 이름은 등록이 안 되고 검색에서 일반어로 묻힌다).
3. **권장 이름: "Pearlstring — Agent Value Gateway"**
   - 상표 DB 4곳 0건, 같은 분야 웹 충돌 없음
   - 진주를 실에 꿴다는 뜻이 진주→목걸이 전략과 디자인 시스템에 그대로 맞음
   - 차선: "Nacrelink — Agent Value Gateway"
   - 사용자 후보 "AgentValCon"은 중간 위험이고, "Agentcon"은 높은 위험이다.
4. **브랜드의 힘은 이름보다 증거에서 나온다.**
   - 목걸이마다 "단일 대비 Δ, 완주율, 마지막 재시험"을 공개한다. 신뢰받는 평가자의 조건(방법 공개, 이해관계 공개, "verified"의 범위 명시)을 그대로 따른다.
5. **도메인은 당분간 agentconcierge.biz를 유지한다(지출 0).**
   - 에이전트가 읽는 식별자(MCP Registry 이름 `biz.agentconcierge/agent-concierge`, 연결 키 `agent-concierge`)도 그대로 두고, 화면·카드의 표시 이름만 바꾼다.

## 1. 조사: 무엇이 바뀌었나 (2025~2026)

### 1-1. 에이전트가 고객인 시대 (B2A)
- Forrester(2026-06-16)는 "business-to-agent marketing"을 말한다.
  - 권고 셋: 모든 채널의 메시지를 같게 하기, 업계 용어로 정보 구조를 명확히 하기, 사실을 검증하기 쉽게 하기
  - [Forrester](https://www.forrester.com/blogs/ai-agents-are-your-new-customer-but-can-you-target-and-grow-their-trust-in-your-brand/)
- BCG(2026-10-30)는 "에이전트가 띄우지 않는 브랜드는 사실상 찾을 수 없다"고 썼다.
  - 처방은 GEO, 자체 에이전트, 생태계 연동이고, GEO만 하면 범용품이 된다고 경고한다.
  - [BCG](https://www.bcg.com/publications/2026/how-cpg-companies-win-agentic-commerce)
- 쇼핑 에이전트 실험(ACES, arXiv 2508.02630)에서는 위치 편향이 컸다. 모델 버전이 바뀌면 선호도 바뀌었고, "sponsored" 표시는 불리했다.
  - 우리 Sponsored 칸은 표시를 유지하되, 목걸이 노출과 섞지 않는다.
  - [arXiv 2508.02630](https://arxiv.org/abs/2508.02630)

### 1-2. AI 검색에서 브랜드가 인용되는 방식 (GEO·AEO)
- GEO 원 논문(KDD 2024)은 가시성을 최대 40%까지 높일 수 있다고 보고했다. [arXiv 2311.09735](https://arxiv.org/abs/2311.09735)
- AI 검색은 제3자 권위 매체(earned media)에 크게 기운다(Chen 외 2025-09).
- Ahrefs 7.5만 브랜드 연구(2025-05, 업체 자체 발표): AI Overviews 노출과 가장 크게 상관한 것은 **브랜드 웹 언급**(0.664)이었다. 링크 지표는 약했다. [Ahrefs](https://ahrefs.com/blog/ai-overview-brand-correlation/)
- 신선도도 작용한다. 인용된 페이지의 75%가 최근 1년 안에 갱신됐다(Seer 2026-07). LLM 재정렬기도 최근 날짜를 선호했다.
- JSON-LD를 넣어도 뚜렷한 인용 효과는 없었다. llms.txt는 97%가 요청 0건이었고, 주 독자는 코딩 에이전트다. **이 둘은 위생 수준으로 유지하고, 주 무기로 삼지 않는다.**
- 엔진마다 인용 출처가 다르다(ChatGPT는 Wikipedia, Perplexity·AI Overviews는 Reddit). 그 비중도 한 달 사이에 크게 바뀐다(Semrush 2025-11).

### 1-3. 에이전트가 서비스를 고르는 기준
- 가장 강한 요인은 **질의와 이름·설명의 의미 일치**다. 앞에 나열된 것과 사전학습에서 자주 본 공급자를 고르는 편향도 있다(BiasBusters, ICLR 2026).
- 이름과 설명만 고쳐 선택률을 약 20%에서 81%로 올린 공격(ToolTweak, [arXiv 2510.02554](https://arxiv.org/abs/2510.02554))이 있다. 조작형 문구는 탐지·방어 대상이 되므로 쓰지 않는다.
- MCP 도구 설명의 97.1%에 결함이 있었다([arXiv 2602.14878](https://arxiv.org/abs/2602.14878)). Anthropic은 서비스 접두사 이름과 "새 동료에게 설명하듯" 쓴 설명을 권한다.
  - 11-14 Glama 정리(a588f8aa)와 목걸이 도구 `necklace_<slug>`가 이 방향이다.

### 1-4. AI 플랫폼 이름 (B, 22곳·개명 17건)
- **오래 가는 회사명은 지어낸 말이나 넓은 은유다.** 예: Anthropic, Glean, Sierra, Arcade, n8n, Gumloop.
  - 하위 제품은 "브랜드 + 일반명사"로 붙인다. 예: Zapier MCP/Agents, Glama MCP Gateway, LangGraph/LangSmith.
- gateway, registry, hub, studio는 2025~2026년에 거의 모두가 제품 설명에 쓰는 말이다. **회사 이름으로는 구별이 안 되고, 범주 설명으로만 유효하다.**
- 이름에 "Agent"를 넣었다가 바꾼 사례가 있다.
  - AgentHub는 Gumloop로 바꿨다(2024-05). 말로 하면 잘못 들리고, "Agent"가 오히려 오해를 불렀다.
  - Agent.ai는 지금 다른 도메인으로 영구 이동한다.
- 남의 상표에 기댄 이름은 결국 바뀌었다.
  - GPT Engineer→Lovable, OpenDevin→OpenHands, Roo Cline→Roo Code
  - Clawdbot→Moltbot→OpenClaw: Anthropic 상표 제기 뒤 2026-01에 바꿨고, 개명 순간 옛 X 핸들을 탈취당했다.
- 개명 뒤 검색량 수치를 공개한 곳은 없다. 보고된 대응은 옛 주소 이동, 옛 도메인 유지, 옛 패키지·마켓 ID 유지다.

### 1-5. 신뢰·검증 브랜드 (C)
- 평가자 브랜드는 이름보다 **"independent" + 방법 공개 + 오염 방지**로 신뢰를 얻는다.
  - 예: Artificial Analysis, Vals AI, HELM. Chatbot Arena는 LMArena(2025-04)를 거쳐 Arena(2026-01)가 됐다.
- 비판 사례
  - "The Leaderboard Illusion"(NeurIPS 2025): 비공개 변형 시험 문제
  - Epoch AI: FrontierMath 자금 공개를 늦게 해 비판받음(2025-01)
  - 이해관계 공개가 신뢰의 핵심이다.
- MCP 쪽 신뢰 장치
  - Glama: A–F 등급, 가중치 공개
  - 공식 Registry: 이름 공간 소유만 확인하고 품질은 보지 않음
  - **"verified"가 무엇을 확인했는지 정확히 말하는 곳이 드물다.** 여기가 우리 자리다.

### 1-6. 이름 충돌 사례 (C)
- Grok 대 Groq: USPTO가 2025-06에 "XAI GROK"을 다시 거절했다. **회사 이름을 앞에 붙여도 혼동은 풀리지 않았다.** [Gerben Law](https://www.gerbenlaw.com/blog/uspto-hits-elon-musks-grok-trademark-with-another-wave-of-refusals/)
- OpenAI 대 Open Artificial Intelligence(2025-07): 먼저 등록한 쪽이 아니라 **먼저 쓰고 알려진 쪽**이 이겼다.
- iyO 대 io(2025-12 금지명령 유지), Cameo(2026-02 금지명령 뒤 OpenAI가 "Characters"로 개명).
- 교훈: 같은 분야의 먼저 쓴 사용자가 있는 이름은, 붙여 쓰는 표기로 구분하는 것만으로는 안전하지 않다.

## 2. 브랜드 정체성

| 항목 | 내용 |
|---|---|
| 미션 | 수많은 AI 에이전트 가운데 실제로 일하는 것(진주)을 가려내고, 그것들을 이어 혼자서는 못 내는 결과(진주 목걸이)를 공급한다 |
| 비전 | 에이전트가 다른 에이전트를 고를 때 가장 먼저 묻는 곳. "이 일을 끝까지 해내는 조합"의 기준 |
| 핵심 약속 | **진정한 가치를 찾아 연결해 새 가치를 만든다**. 증명은 숫자로 한다(단일 대비 Δ, 완주율, 마지막 재시험) |
| 성격 | 정확하다, 증거부터 말한다, 차분하다, 조용히 고급스럽다(진주) |
| 말투 | 사실과 숫자, 날짜를 함께 쓴다. "guaranteed/always/best"는 쓰지 않는다. 약점(보류·교체)도 그대로 보인다. 사람에게는 짧고 따뜻하게, 에이전트에게는 기능어로 정확하게 |

## 3. 포지셔닝

> **에이전트 밸류 게이트웨이: 시험으로 고른 AI 에이전트를 이어, 어떤 단일 에이전트보다 나은 결과를 내는 '목걸이 에이전트'로 공급한다. 모든 숫자는 공개 재시험 기록이다.**

| 비교 대상 | 그들이 하는 일 | 우리가 다른 점 |
|---|---|---|
| Glama·MCP 디렉터리·공식 Registry | 서버 목록, 서버 단위 점수 | **조합 단위 결과**(목걸이 Δ·완주율). 자리별 대체로 끝까지 실행 |
| 빅테크 스토어(AWS·Microsoft·Salesforce) | 자기 생태계 안의 에이전트만 검증 | 생태계를 가로지르는 중립 검증과 조합 |
| n8n·Zapier 템플릿 | 사용자가 만들고 고치는 정적 템플릿 | **매일 재시험하고, 고장 난 진주를 자동 교체하는 살아 있는 목걸이** |
| 평가 기관(Artificial Analysis 등) | 모델·제품 순위 | 순위에서 끝나지 않고 실행까지 공급(게이트웨이) |

- **권장은 E**다.
  - 사용자가 고른 Agentcon(A)의 뜻("Agent" + 연결)을 살리려면 B가 가장 가깝다. 다만 "con" 인상과 VALCON 유사성이 남는다.

### 5-2. 무료로 직접 확인하는 방법
- **USPTO Trademark Search**(`tmsearch.uspto.gov`): 계정 없이 검색창에 이름을 넣는다. 결과 목록의 상태(LIVE/DEAD)와 류(9·35·42)를 본다. 출원 상세는 `tsdr.uspto.gov`에서 번호로 연다.

## 6. 시각 정체성
- 상징 셋: **진주** = 시험을 통과한 에이전트, **실** = 검증된 연결(계약·대체 순서), **목걸이** = 워크플로우가 만든 새 에이전트.
  - 이름 Pearlstring(E)은 셋째 상징 자체다.
- Pearl Connection 디자인 시스템(색·간격 토큰, 진주 그림, 워크스페이스 틀)을 그대로 쓴다.
  - 홈 첫 화면의 목걸이 그림과 About의 목걸이는 같은 그림이다(11-13 결정).
  - 목걸이 페이지에는 진주 수만큼 진주를 그린다. 대체가 쓰인 자리는 다른 진주(외부)나 표시된 진주(Agentcon 대체)로 보인다.
- 로고 글자만 새 이름으로 바꾼다. 로고 마크(진주 셋)는 유지한다.
