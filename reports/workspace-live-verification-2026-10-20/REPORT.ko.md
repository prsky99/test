# 실제 고객 워크스페이스 검증

검증일: 2026-10-20 KST. 대상: 실제 Chrome의 기존 Google 계정으로 접근한 `Workspace QA Review 2026-10-19` 조직. 이 보고서는 앞서 수행한 격리 보안 감사와 구분되는 실제 서비스 점검이다.

## 실제로 확인한 동작

- Google 정식 로그인, 소유자 조직 개요, 멤버·초대 목록, 플랜·크레딧, 계정, 조직 설정, 고급 개별 초안과 단일 작업, 워크플로우 생성·검토·저장·테스트·다운로드, 라이브러리 검색과 선택, 실행 이력, 푸터 문서·문의 화면을 열어 확인했다.
- 기존 연구 워크플로우 1개와 승인된 신규 QA 워크플로우 1개를 각각 한 번 실행했다. 총 네 단계 모두 성공했고 DOI 출처가 표시됐다. 이는 실제 서비스 실행 결과이며 모든 공급자의 모든 에이전트가 정상임을 의미하지 않는다. 검색 데이터의 캐시 사용 가능성은 배제하지 않았다.
- 신규 항목 `QA Live Verification 2026-10-20 - Battery Research`를 정확히 한 개 저장했다. 저장 항목은 31개에서 32개, 잔액은 99984에서 99983으로 바뀌었다. 기존 항목을 수정하지 않았다.
- 해당 성공 버전으로 승인된 한 시간 릴리스를 생성했다. UI 만료 시각은 2026-10-20 23:35:47 KST였다. 앱 권한은 승인된 `https://agentconcierge.biz` 출처, 한 시간, 분당 최대 5회·하루 최대 20회로 제한했다.
- 다운로드 버튼은 한 번 클릭했다. 브라우저 자동화의 download 이벤트는 시간초과였지만 실제 Downloads 폴더에서 10351바이트 ZIP을 확인했다. 증적 폴더에 `qa-reviewed-web-app.zip`으로 보존했다. 파일 8개, ZIP 무결성, bff.py 문법, manifest의 정확한 허용 출처와 토큰 필드 부재를 확인했다. ZIP 파일을 설치하거나 별도 서비스로 실행하지 않았다.
- 로그아웃 후 로그인 제공자 화면으로 이동했고 Account 재접근 시 사적 정보가 숨겨지며 로그인을 요구하는 것을 확인했다. 이어 Google로 다시 로그인하여 같은 소유자 워크스페이스로 복귀했다. `57-signout-success.png`, `58-signed-out-access-blocked.png`, `59-google-relogin-success.png`에 보존했다.
- 멤버 제거, 계정 삭제, 조직 탈퇴·아카이브는 확인 대화상자까지 열고 취소했다. 실제 삭제·초대 발송·권한 변경·결제를 하지 않았다.

## 발견하여 수정한 문제

1. 고급 단일 작업에서 빈 그래프인 기존 스냅샷에도 준비 버튼이 활성화돼 모호한 오류로 끝났다. 스냅샷의 서버 가용성 결과를 로딩 시 조회하여 실행 불가 이유를 표시하고 준비·실행 버튼을 차단했다. 선택 변경 시 가용성과 이력을 다시 읽으며 실제 준비 직전에도 서버 결과를 재확인한다. 서버의 권한·계약 검증은 유지했다. 수정 전 `35-single-task-before.png`, 오류 `36-single-task-prepare-failure.png`, 격리 수정 검증 `45-single-task-fixed-isolated.png`, 재시작 후 운영 수정 검증 `54-single-task-fixed-live.png`.
2. 워크스페이스 푸터의 약관·개인정보·접근성·문의 링크가 디자인 미리보기로 연결됐다. 특히 문의는 아무것도 보내지 않는 예시 폼이었다. 공통 푸터를 기존 운영 문서/문의 대화상자 경로로 연결했다. 수정 전 `41`~`44` 스크린샷, 수정 반영 `52-footer-fixed-live.png`, 실제 약관 클릭 결과 `53-footer-terms-fixed-live.png`. 운영 목적지의 개인정보·접근성·문의 화면도 별도로 확인했다. 문의는 발송하지 않았다.

사용자가 직접 서버를 재시작한 뒤 두 수정사항을 운영 화면에서 확인했다. 재시작 직전의 Cloudflare 502는 재시작 후 사라졌으며 저장된 QA 항목과 잔액이 유지됐다.

## 자동 검증

- 기능 수정 회귀: 13개 통과. 실제 핸들러를 사용하는 격리 고객 데이터 및 네트워크 차단 Chromium. 지원되는 단일 작업의 검토·실행·릴리스·다운로드, 세션 만료, 지원되지 않는 스냅샷, 선택 복구 및 공통 푸터 포함.
- 보안/출력 회귀: 41개 통과. `test_workspace_execution_api.py`, `test_front_content_policy_browser.py`. CSRF·접근 제한 및 공개 UI 출력 등의 관련 기존 경계를 확인했다.
- 공개 콘텐츠 검사: 237개 파일, 위반 0개.
- 수정한 Python 뷰 2개 Bandit 검사: 경고 1개 수동 검토. B608이 HTML/JavaScript 문자열을 SQL 구성으로 오인했다. 해당 뷰에는 SQL 실행이 없고 workspace 식별자는 검증·JSON 인코딩된다. 확인된 취약점은 없으며 경고를 억제하지 않았다. 원본 결과와 검토는 `scoped-bandit.json`, `security-review.json`에 보존했다.
- 격리 Chromium 390px 반응형 검사는 통과했다. 실제 Chrome에서 390px override를 시도했으나 DOM은 1920px로 보고했다. 따라서 `55-single-task-mobile-live.png`는 운영 모바일 검증의 성공 증적이 아니다.

## 남은 검증 범위와 품질 개선

- 승인된 A2A 연결이 없어 실제 장기 A2A 전송은 실행하지 않았다. 연결 없음 안내와 실행 차단만 확인했다.
- 내려받은 앱을 승인 출처에 별도로 호스팅하여 그 앱 자체에서 실행하는 과정은 미검증이다. 워크스페이스에서의 실제 에이전트 실행과 ZIP 다운로드 성공을 이와 혼동하면 안 된다.
- Google 기존 계정은 검증했지만 GitHub의 별도 계정 가입·로그인은 실행하지 않았다. 다른 고객/역할의 실계정 접근과 초대 수락은 격리 회귀 범위다.
- 실제 모바일 기기, 스크린리더 전체 흐름, 모든 외부 공급자에 대한 실행을 완료한 것은 아니다.
- QA 흐름의 두 번째 단계는 첫 결과의 제목으로 재검색하여 같은 자료를 반환했다. 단계 연결은 성공했으나 독립적 근거가 추가된 것은 아니다. 제안 품질 개선에는 후속 검색 의도 구분과 중복 출처 안내가 필요하다.

엑셀 체크리스트는 실제 수행한 기능 단위의 결과와 클릭 전·후·수정 증적 파일명을 기록한다. PASS/FIXED/LIMITED/NOT RUN을 구분하며, 미수행 기능을 성공으로 집계하지 않는다. 원본 화면 관찰은 `checkpoints.json`, 각 `.txt` DOM 스냅샷과 `screenshots/`에 보존했다.
