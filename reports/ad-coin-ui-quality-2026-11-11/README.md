# AD Coin 화면 품질 감사 결과 (0.5단계, 2026-11-11)

- **기준:** PM이 전한 사용자 지시
  - 오류 0
  - 간격은 토큰만 사용
  - 정렬 오차 1px 이내
  - WCAG AA
  - 누를 수 있는 영역 44px 이상
  - 흐름을 끝까지 갈 수 있음
  - 메인 프론트엔드와 비교
- **방법:** `scripts/ui_quality_audit.py`와 `scripts/ui_audit.js`. Chromium에서 4가지 조건으로 측정했다.
  - 데스크톱 1280×800, 모바일 375×812
  - 밝은 모드, 어두운 모드
- **AD Coin 측정 범위:** 화면 상태 5개 × 조건 4개 = 20회
  - Rewards
  - Your choices
  - Advertising: 신청 카드 포함
  - 예약·USDC 결제 카드
  - 한국어 운영 화면 `/ad-coin/v2/admin`
- **메인 프론트엔드:** 운영 `https://agentconcierge.biz/`를 같은 스크립트로 4회 측정했다(읽기 전용).
- **시험으로 고정:** `tests/test_ad_coin_v2_ui_quality.py`. 공용 디자인 체계 항목을 뺀 모든 항목이 0이어야 통과한다.
- **간격 토큰:** Pearl Connection에는 간격 변수가 따로 없다. 그래서 공용 스타일 파일(`/new/en/assets/*.css`)에 선언된 margin, padding, gap 값의 집합을 토큰으로 보고, 화면에서 계산된 값이 그 집합 밖에 있으면 위반으로 센다.

- **수정 전 숫자에는 측정 보정 전 값이 섞여 있다.** 그라데이션 버튼의 대비, 1px 건너뛰기 링크, 장식 점, auto 여백이 잘못 셌던 부분이다. 보정한 측정으로 다시 잰 실제 결함은 다음과 같았다.
  - 작은 버튼(38px)
  - 표시 없는 날짜 입력 포커스
  - fieldset 기본 안쪽 여백 5.6px
  - 같은 줄의 제목·이름표와 버튼 정렬
  - 링크 크기(17~25px)
- **메인과 비교:** AD Coin은 모든 항목에서 메인과 같거나 낮다(좋다).
- **공용 디자인 체계 요소(56):** AD Coin 마크업으로는 고칠 수 없다. 메인도 같은 부품을 쓴다.
  - 머리글의 브랜드 링크(높이 30px)
  - 테마 전환 버튼(44×30)
  - 체크박스 이름표(`label.check`, 높이 24px)
  - 크기가 공용 CSS에서 정해지므로, 공용 CSS 담당에 `min-height:44px`를 넘겼다.

## 2. 고친 것 (페이지 전용 스타일 없음, 공용 클래스만)

- 작은 버튼(`btn small`, 38px)을 `btn`(44~46px)으로 바꿨다. 대상: 잔액 새로고침, Use points, 금액·주소 복사, 머리글 Account
- 링크를 `btn` 링크로 바꿨다: "Back to discovery", "Review my choices", 바닥글 링크 2개
- 광고 설정 양식: fieldset을 `card`로 바꿔 브라우저 기본 여백(5.6px)을 없앴다. 버튼 줄은 카드 안으로 옮겨 왼쪽 정렬을 맞췄다.
- "Sponsored bookings" 제목과 버튼의 세로 중심을 맞췄다.
- 운영 화면 USDC 칸: 이름표 붙은 입력과 버튼을 같은 줄에서 떼어 각자 줄에 뒀다.
- 예약 날짜: 포커스 표시가 없던 날짜 입력을 "내일부터 30일" 목록(select)으로 바꿨다. 고를 수 없는 날을 고르는 오류도 함께 사라진다.

## 3. 사용 흐름 (처음 온 광고주)

- 신청 → 승인 대기 안내("Application received. We will review it…") → 캠페인 → 예약(코인 또는 5 USDC) → 결제 확인 상태(확인 중, 확정, 검토 중) → 예약 목록
- 단계마다 다음 할 일과 오류 복구 문구가 있다. 결제 오류 문구는 7가지다: 다른 네트워크·토큰·금액, 실패 거래, 이미 쓴 거래, 만료, 해시 형식, 칸 없음, 결제 꺼짐.
- 실제 Chromium 여정 시험(`tests/test_ad_coin_v2_workspace_browser.py`, 9개)이 바뀐 마크업에서도 통과한다.
- 로딩은 영역별로 하고, 버튼을 누를 때 불러온다(화면 정책).

## 5. 아직 측정하지 못한 것

- 광고주 만족도 100%: 실제 광고주가 생기면 과제 완료 여부와 짧은 선택 응답(개인정보 없음)으로 잰다. 그 전에는 위 자동 기준을 대리 지표로 쓴다.
- 그라데이션 배경 위 글자 대비(주 버튼): 계산할 수 없어서 스크린샷으로 확인한다. 측정 결과에 `contrast_unmeasured`로 따로 센다.
