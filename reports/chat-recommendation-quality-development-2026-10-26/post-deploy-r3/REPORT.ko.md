# R3 운영 최종 확인

2026-10-26. **`frontend-chat-task-quality-20261026-r3` 운영 반영과 이번 수정 범위의 공개 동작 검증을 완료했다.** 이 점검에서 추가 운영 교체가 필요한 오류는 발견하지 않았다.

## 확인 결과

- 활성 프론트엔드 b에서 R3 준비 상태 통과. 공개 JavaScript가 릴리스 파일과 해시 일치. Chat 페이지 HTTP 200·CSP·no-store, 비공개 준비 상태 URL 공개 접근 404.
- 실제 공개 합성 검색 **10/10 HTTP 200**, 5xx 0건. 표본 응답은 1,542.4~3,869.3ms이며, 작은 표본이므로 전체 p95로 일반화하지 않는다.
- 이전에 503이 재현됐던 긴 요청: **2,262.7ms·HTTP 200**. 요청 뒤쪽의 API 키 제외 조건이 유지됐고, 결과가 없는 상태에서 다음 DOI 조건을 붙여도 `no_api_key`와 `doi`가 모두 보존됐다. 후속 상태는 `refine`이다.
- 논문 검색과 DOI 후속 요청은 각각 계약이 있는 에이전트 1개를 반환했다. 추천의 공개 호출 스키마가 비어 있지 않음을 확인했다.
- MCP를 명시 선택한 일본어 새 요청이 이전 날씨 작업으로 대체되지 않고 영어 정규화 후 새 검색으로 처리됐다. 이어진 새 논문 요청에는 이전의 인증·DOI 조건이 무단으로 이어지지 않았다.
- 실제 공개 Chromium **4개 여정 통과**, 스크립트 오류 0건. 논문 검색·상세 열기·DOI 후속 조건·빈 결과·긴 요청·모바일 가로 넘침·전송 버튼·로딩 상태 복구를 확인했다. 결과가 1개여서 공개 표본에서 대안 펼치기는 나오지 않았으며, 해당 제어는 앞선 격리 회귀로 검증했다.

## 남은 범위

점검한 날씨·기술 뉴스 MCP 요청은 적격 후보를 반환하지 않았다. 검색 오류와 구분되는 결과이며, 전체 카탈로그에 해당 능력이 없다는 증명은 아니다. 후보 보강과 대표 품질 평가가 남아 있다. 이번 결과를 전체 추천 정확도 목표 달성이나 모든 기능의 외부 실행 성공으로 보고하지 않는다.

운영 서버 재시작·프로세스 교체는 점검 과정에서 하지 않았다. 제공자 에이전트 업무 실행·워크스페이스 변경·결제·크레딧 사용도 0건이다. 합성 공개 Chat 요청의 정상 대화 기록은 생성될 수 있으며 QA User-Agent로 구분했다. 방문자 토큰은 요청 헤더에만 사용하고 증적에 저장하지 않았다.

## 증적

- `live-api.json`: 10개 공개 검색 결과와 준비 상태·자산 해시 검사.
- `browser.json`: 4개 공개 브라우저 여정.
- `papers.png`, `doi-followup.png`, `no-match.png`, `long-request.png`: 실제 공개 화면 캡처.
- `verification-summary.json`: 이번 운영 확인 집계.

R3 적용 전 회귀 411개와 메모리 한도 원인·수정 내용은 이전 `post-deploy-r2/` 보고서에 별도로 보존했다. 이번 점검에서는 애플리케이션 소스를 추가 변경하지 않았다.
