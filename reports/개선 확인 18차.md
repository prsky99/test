## 세션 확인 추가 관찰
- 고객 로그인 세션은 **활동과 상관없이 로그인 1시간 뒤 끝납니다**(`customer_identity.py`: `expires = min(now + 3600, claims['exp'])`, 연장 없음).
- 측정 도중 워크스페이스가 로그인 화면으로 바뀌었습니다. 작업 중인 사용자는 저장하지 않은 제안을 잃을 수 있습니다.
- 개선 방안
  - 활동 중에는 만료를 연장합니다(예: 1시간 유휴, 최대 12시간).
  - 만료 5분 전에 알립니다.
  - 만료 뒤 다시 로그인하면 원래 화면과 입력(과제 문장)을 되살립니다.

### 새로 찾은 문제 (사용자)
1. **[높음] 워크플로 50개 한도가 안내되지 않음**
   - 워크스페이스당 저장 워크플로는 50개입니다(`workspace_typed_flows.LIMITS['flows'] = 50`). 이번 측정에서 50개에 닿았습니다.
   - 저장하면 확인 창은 "uses 1 credit"이라고 안내한 뒤, 저장은 "The saved state, credit quote or execution outcome changed. Read current history…"로 실패합니다. 크레딧은 빠지지 않았습니다.
   - 개선: 목록에 "50/50 workflows"를 표시하고, 한도에 닿으면 저장 버튼을 막은 채 이유와 정리 방법(오래된 워크플로 보관·삭제)을 안내합니다. 서버도 409 대신 한도 전용 오류 코드를 줘야 합니다.
2. **[높음] 실행 한 번이 불확실(409·unknown)로 끝나면 생성 기능 전체가 잠김**
   - 측정 스크립트끼리 겹쳐 실행이 "AUTHORITY_OR_OUTCOME_UNCONFIRMED"로 끝나자, 이후 모든 AI 생성 버튼이 "Review the last request before trying again."으로 막혔습니다.
   - 화면 안에서 푸는 방법이 없어 새로고침해야 풀렸습니다.
   - 개선: "기록 확인" 버튼을 두어 상태를 다시 읽고 잠김을 풉니다. 새 과제 생성은 이전 실행의 불확실 상태와 분리합니다.
3. **[중간] 로그인 1시간 고정 만료**(B 아래 "세션 확인 추가 관찰" 참고): 측정 중 실제로 로그인 화면으로 바뀌었습니다.
4. **[낮음] 검색어 꼬리**: "Find research papers about large language model agents in two connected steps." → 검색어가 "research papers large language model agents **in**"으로 "in"이 남습니다.
