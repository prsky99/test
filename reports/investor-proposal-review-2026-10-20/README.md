# Agent Concierge 투자 제안서 평가와 개선 방안

작성: 2026-10-20
대상: `output/investor-proposal-separated-terms-2026-10-19` (본편 26장, 투자 조건 4장, 재무 부록 3장 · 한글/영문)
관점: 미국 빅테크 전략투자(CVC)와 AI 전문 VC(시드~프리시드) 심사역

---

## 1. 결론

**현재 제안서로는 미국 빅테크·AI 전문 투자자의 투자 결정을 끌어내기 어렵습니다.** 첫 미팅은 성사될 수 있지만, 파트너 미팅(투자 위원회 전 단계)을 통과할 가능성은 낮다고 판단합니다.

이유는 디자인이나 성실성이 아니라 **투자 논리의 핵심 세 가지가 비어 있기 때문**입니다.

1. **"왜 크게 될 수 있는가"(벤처 규모 결과)가 보이지 않습니다.** 2031년 매출 목표가 680만 달러입니다. 시드 투자자는 10억 달러 이상 기업이 될 가능성을 보는데, 제안서 스스로 상한을 낮게 그었습니다.
2. **검증된 수요(트랙션)가 없습니다.** 매출·유료 고객·LOI(구매 의향서)·디자인 파트너가 0이고, 모든 지표가 "목표"와 "가정"입니다.
3. **팀과 법인 구조가 미국 투자 기준에 맞지 않습니다.** 창업자 1인, 아직 전업 전환 준비 단계이며, 원화 표시 한국 법인 기준 조건입니다.

반대로 **진짜 자산도 있습니다.**
- 약 12만 개 에이전트 카탈로그와 연결·실행 검증 데이터
- 실제로 작동하는 공개 서비스
- A2A·MCP·x402 세 프로토콜을 모두 다루는 드문 위치
- 매우 정직한 고지와 단계별 자금 집행 계획

문제는 이 자산을 **"AI 에이전트 래퍼 사업"**(15장의 자기 표현)으로 포장했다는 점입니다. 같은 자산을 **"AI 에이전트 경제의 신뢰·검증 인프라"**로 다시 설명하면 투자 논리가 완전히 달라집니다.

## 4. 투자할 수밖에 없게 만드는 개선 방안

### 4.1 포지셔닝을 바꿉니다: "래퍼"에서 "에이전트 경제의 신뢰 계층"으로

**현재:** 에이전트를 찾아 워크플로로 만들어 주는 도구 (n8n·Zapier와 경쟁)

**제안:** **"The trust and routing layer for the agent economy"**
AI 에이전트가 다른 에이전트를 고용할 때 *누구를 믿고 부를지* 결정하는 검증·평판·라우팅 인프라입니다.

- **비유:** 에이전트 세계의 *Google 검색 + 신용평가(Moody's) + 결제 라우터*
- **근거 자산:** 12만 개 카탈로그, 헬스체크·실행 검증 기록, A2A/MCP/x402 다중 프로토콜 지원, 에이전트 전용 진입점(A2A·MCP 엔드포인트)
- **효과:**
  - 사람용 워크플로 앱(경쟁 과밀)에서 에이전트 간 거래 인프라(초기·고성장)로 시장이 바뀝니다.
  - 빅테크에는 경쟁자가 아니라 **보완재**가 됩니다. 각 플랫폼의 에이전트가 플랫폼 밖 에이전트를 안전하게 부를 때 필요한 중립 계층이기 때문입니다.

### 4.2 투자 전에 만들 "증거" 5가지 (가장 중요)

제안서를 고치기 전에 아래 증거를 먼저 확보하면 투자 가능성이 크게 달라집니다. 4~8주 안에 가능한 수준으로 골랐습니다.

| 증거 | 목표 | 데크 반영 위치 |
|---|---|---|
| ① 제품 신뢰성 | 공개 Chat·워크플로가 실제로 작동(현재 Chat 실패 해결), 데모 영상 2분 | 제품 장 |
| ② 에이전트 트래픽 | 우리 A2A/MCP 엔드포인트를 호출한 외부 에이전트 수·호출 수 주간 추이 | 트랙션 장 (가장 강력한 신호) |
| ③ 데이터 해자 수치 | 누적 헬스체크 수, 실행 검증 수, 검증 데이터로 걸러 낸 "죽은 에이전트" 비율 (예: "등록 에이전트 중 실제로 일하는 것은 N%") | 인사이트 장 |
| ④ 고객 의향 | 미국 AI 대행사·에이전트 개발사 LOI 3~5건 또는 유료 파일럿 1~2건 | 트랙션 장 |
| ⑤ 생태계 연결 | 프로토콜 주체(Coinbase x402, A2A, MCP 레지스트리 등)와의 공식 등재·협업·통합 1건 이상 | 파트너 장 |

> 특히 ③은 지금 데이터로 바로 만들 수 있습니다. "AI 에이전트 레지스트리의 X%는 실제로 작동하지 않는다"는 독자 데이터는 투자자와 언론 모두에게 강한 "인사이트 장"이 됩니다.

### 4.3 시장 규모를 벤처 규모로 다시 계산합니다

- **삭제:** "10,000팀 × 85달러 = 1,020만 달러 ARR" 예시
- **추가:** 하향식 + 상향식 두 가지 TAM/SAM/SOM
  - 하향식: 에이전트 간 거래·API 호출 시장 × 수수료율(take rate)
  - 상향식: 에이전트를 만드는 개발사 수 × 검증·라우팅 이용료, 기업 내부 에이전트 수 × 거버넌스 이용료
- 숫자는 반드시 출처를 붙입니다(공신력 있는 리서치·공식 발표). 근거 없는 큰 숫자는 오히려 신뢰를 깎습니다.
- 재무 계획은 "보수적 기본안"과 함께 "성공 시 경로"(예: 7년 차 연매출 1억 달러 이상의 조건)를 보여 줍니다. 2029년 흑자 강조보다 성장률을 앞세웁니다.

### 4.4 경쟁 장을 정직하고 날카롭게 다시 씁니다

- **포함할 범주:**
  - 에이전트·MCP 디렉터리와 레지스트리
  - 프로토콜 공식 레지스트리
  - 빅테크 에이전트 마켓플레이스와 에이전트 플랫폼
  - 워크플로 도구(n8n·Zapier·Dify)
- **2×2 축 예시:** 가로 "단일 플랫폼 ↔ 프로토콜 중립", 세로 "목록 제공 ↔ 실행 검증 데이터". 우리는 오른쪽 위(중립 + 검증)에 위치합니다.
- **"빅테크가 하면?"에 대한 답을 한 줄로 넣습니다.**
  > "각 빅테크는 자기 생태계 에이전트만 검증합니다. 플랫폼 간 중립 검증은 플랫폼 소유자가 하기 어렵고, 그래서 신용평가·결제망처럼 독립 계층이 생깁니다."

### 4.5 팀 리스크를 정면으로 줄입니다

- 전업 전환 날짜를 명시하고, 투자 조건과 연동합니다(예: 클로징과 동시 전업).
- **미국 측 공동창업자 또는 GTM 리드 확보**가 시드 성공의 가장 큰 단일 변수입니다. 최소한 이름 있는 자문단 2~3명(에이전트 프로토콜·개발자 생태계·엔터프라이즈 판매)을 데크에 넣습니다.
- 창업자 장에는 "1주일 만에 첫 제품" 대신 **"1인이 N주 만에 12만 개 에이전트를 수집·검증하는 시스템을 만들었다"**처럼 실행 속도를 구체적 결과로 보여 줍니다.

### 4.7 빅테크 전략투자(CVC)를 겨냥한 별도 1장

빅테크·전략투자자는 재무 수익보다 **자기 플랫폼에 주는 이익**으로 판단합니다. 투자자별로 한 장씩 맞춤 슬라이드를 준비합니다.

| 대상 유형 | 그들의 관심 | 우리가 주는 것 |
|---|---|---|
| 결제·크립토 계열 (x402 관련) | x402 거래량 증가 | x402 API 검증·발견 → 거래량 유입 지표 |
| 클라우드 사업자 | 자사 클라우드 에이전트 사용 증가 | 마켓플레이스 연동, 검증 데이터 제공 |
| 모델·에이전트 플랫폼 | 에이전트가 외부 도구를 안전하게 쓰는 것 | MCP/A2A 신뢰 점수 API |

### 4.8 데크 구조를 12~15장으로 줄입니다

미국 VC 첫 연락용 표준 흐름입니다(세부 데이터는 부록·데이터룸으로).

1. **표지** — 한 문장 정의: "The trust layer for the agent economy"
2. **문제** — 에이전트는 폭증하지만 대부분 믿고 부를 수 없다 (자체 데이터: 작동률·실패율)
3. **Why now** — A2A·MCP·x402 표준화, 에이전트 간 거래의 시작
4. **해결책** — 검증 → 추천 → 실행 → 증거 (실제 작동하는 화면, 데모 영상 QR)
5. **인사이트** — 우리만 가진 데이터에서 나온 놀라운 사실 3가지
6. **트랙션** — 에이전트 트래픽 추이, 카탈로그·검증 성장, LOI/파일럿
7. **비즈니스 모델** — 하나에 집중(예: 검증·라우팅 API 사용량 과금 + 기업 거버넌스), 나머지는 확장 옵션
8. **시장** — 출처 있는 TAM/SAM/SOM
9. **경쟁** — 2×2 + "빅테크가 하면?" 답변
10. **해자** — 데이터 네트워크 효과(사용될수록 검증 데이터가 쌓여 추천이 좋아짐)
11. **GTM** — 첫 고객군 1개와 첫 채널 1개
12. **팀** — 창업자 + 미국 GTM/자문단
13. **재무 요약** — 성장 경로 1장
14. **The Ask** — 금액, 18~24개월 마일스톤, 다음 라운드 기준
15. **비전** — 10년 뒤 모습
