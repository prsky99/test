Six final logout/context cases, plus actual ordinary ZIP/rehost/provider/revoke behavior, verify the correction. Earlier fixture-import/request-observer failures are separately retained and are not described as reproduced exploits. SDK1.2/1.3 guards and package assets remain intact.

Exploratory automation browser failures were harness assumptions: an interval that could not fit in the fixture publication, a process importing the pre-enum core, existing administrator storage incorrectly assumed empty, wrappers not attached to the bound onclick handler, logout routing observed before the held callback, and a reopen helper expecting fresh eligibility after an actual provider timeout. [Earlier combined XML](browser-final.xml) is preserved. No automation permission bypass was reproduced by those harness failures.
