## 사용자 흐름

1. 실행 화면에서 현재 워크플로우를 유지하면서 작업·주제·에이전트 키워드를 검색합니다. 또는 Browse templates로 라이브러리를 엽니다.
2. 검색, 카테고리, 기록된 실행 가능 조건, 정렬을 조합해 후보를 좁힙니다. 데스크톱은 카테고리 사이드바, 모바일은 접을 수 있는 분류 패널을 사용합니다. 큰 템플릿 셀렉트는 없습니다. 정렬 3종과 워크스페이스 카테고리 등 작은 고정 목록은 유지합니다.
3. 카드에서 목적·실제 에이전트 수·진주 연결·에이전트 이름을 비교합니다. Preview workflow에서 각 에이전트의 공개 입력까지 확인합니다. 미리보기는 현재 워크플로우나 실행 결과를 바꾸지 않습니다.
4. 명시적으로 Use this workflow를 선택한 뒤 실행 화면에서 검토·실행합니다. 같은 템플릿을 다시 고르면 수정 중인 캔버스를 덮어쓰지 않습니다. 실행 중에는 다른 템플릿으로 바꾸지 못합니다.

한 페이지에 데스크톱 8개·모바일 4개만 렌더링합니다. 이전/다음뿐 아니라 직접 페이지 이동을 제공합니다. 검색·분류·정렬 변경 시 첫 페이지로 돌아갑니다. 검색 실패, 빈 결과, 필터 초기화에서 복구할 수 있습니다. 모바일 버튼 글자가 잘리거나 필터 표시가 실제 선택과 어긋나던 부분도 캡처 후 수정했습니다.

미리보기는 긴 콘텐츠만 안쪽에서 스크롤합니다. 닫기·선택·다운로드 버튼은 항상 보이며 Tab/Shift+Tab·Escape·닫은 후 포커스 복귀를 지원합니다. 기존 Download Web App은 미리보기에서 계속 제공합니다. 선택·검색·미리보기는 자동 실행하지 않습니다.

워크스페이스는 공개 허브와 같은 원본 목록을 유지합니다. 카드에 실제 에이전트 수만큼 진주를 표시하고, 데스크톱 2열·모바일 1열로 정돈했습니다. 기존 계정·권한·동의·저장·크레딧·실행·다운로드 조건은 바꾸지 않았습니다. SQL·DB 구조 변경은 없습니다.
