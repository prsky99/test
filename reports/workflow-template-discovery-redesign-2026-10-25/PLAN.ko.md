# 작업 순서 중심의 템플릿 선택 UX 재설계

문제: 카드 수와 페이지 높이를 줄이는 것만 확인하고, 1,000개 중 목적에 맞는 항목을 찾고 비교하는 과정을 검증하지 못했습니다. 큰 기본 셀렉트는 제거합니다.

실행 화면에는 현재 선택한 워크플로우의 제목·설명·에이전트·실행 버튼을 유지합니다. 다른 템플릿이 필요할 때 작업 키워드를 바로 검색합니다. 선택 화면은 검색 입력을 중심으로 카테고리, 기록된 실행 가능 조건, 정렬, 일관된 결과 카드, 직접 페이지 이동을 제공합니다.

카드는 사용 목적과 연결된 에이전트 수·진주 시각화를 먼저 보여줍니다. 미리보기는 공개 입력과 에이전트 구성을 확인하는 용도이며 기존 작업을 바꾸거나 실행하지 않습니다. 선택은 별도 명시적 동작입니다. 현재 항목 재선택은 수정 중인 캔버스를 유지합니다. 취소·Escape는 검색 상태와 현재 작업을 유지합니다.

검증은 작은 높이와 카드 수에만 한정하지 않습니다. 1,000개에서 이름을 모르는 작업 검색, 분류 조합, 정렬, 직접 마지막 페이지 이동, 미리보기 후 취소/선택, 키보드·모바일·다크 테마, 검색 실패/빈 결과 복구, 악성 문자열 이스케이프, 실행 없이 탐색하기를 확인합니다. 워크스페이스의 공통 목록·권한·저장·실행·크레딧 동의 조건도 유지합니다.
