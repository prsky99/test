The current turn first applies the separately reported [public gateway follow-up](../gateway-projection-followup-2026-10-18/), then adds the private **Inspect connected test** evidence viewer. ## Implemented scope

The new `workflow_resolved_evidence.py` service and two highest-admin APIs inspect one retained completed `news-title-to-docs-v1` administrator test. They verify the signed immutable definition and historical authority; the source binding/input and complete signed successful output; the safe first-title transformation; the target's actual complete recorded arguments and exact source-checkpoint provenance hash; and recorded contract/time boundaries. Current definition/approval/readiness is a separate read-only observation.

Historical principal expiry must be finite numeric nonboolean data after admission and each successful node's recorded start. It is not compared with today's time or response completion. Failed/blocked/cancelled nodes starting after expiry remain unscored. The runtime's actual dispatch authorization remains unchanged. Independent review found and corrected the initially missing historical-expiry condition before the final scoped run.

Missing/pruned source or target proof, unknown external outcome, missing certainty and unsuccessful nodes do not produce successful whole-run assessments or fabricated queries. Available but mismatched signatures, scopes, inputs, source hashes and successful outputs are refused. The response returns the verified target query only when both input proofs exist, bounded safe source metadata and opaque evidence references. It omits full URLs, credentials, raw responses, summaries/excerpts, private connection pins and authority envelopes. Additional metadata minimization masks known secret patterns, inline URL/contact strings and detected private paths.

The separate centered native dialog renders provider data as text and preserves the unsaved builder. Selection, refresh, close/Escape, authentication expiry and logout clear or invalidate memory-only state; late responses are ignored. Existing **Compare completed tests** remains a literal-input-only evaluator and still excludes all connected graphs. The inspector supplies neither pair eligibility nor factual/expert quality certification.

Inspection makes no provider/model request, source fetch, new workflow run, evidence write, grade update, candidate promotion, publication or delivery. It adds no database table and uses a consistent read-only SQLite transaction; the existing rehearsal inventory remains 27 tables. No public frontend or SDK implementation is changed by this private inspector. Public gateway changes in the same turn have their own report and verification scope.
