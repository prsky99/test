# 장애 독립성 조사와 대체 실행 검증

2026-10-24 · 사용자 요청: 남은 후보의 장애 독립성 확인 및 실제 대체 실행 테스트

## 현재 판정

**격리된 실제 TCP 통신에서 주 서버 종료 → 대체 서버 단일 호출 → 실행 성공을 확인했다. 운영 폴백은 활성화하지 않았다.** 후보 526개를 모두 대조했지만 운영 승인에 필요한 원천 서버·상위 API 독립성까지 확인된 조합은 없었다. 이 결과를 ‘독립 에이전트가 시장에 없다’로 해석하지 않는다. 공개 메타데이터·DNS·HEAD와 현재 계약 증거만으로 승인할 수 없다는 뜻이다.

현재 운영 서버에서 독립 제공자 간 실제 대체 실행을 검증하는 요청은 **미완료**다. 사용자 승인 자체가 부족한 것이 아니라, 동일 기능/계약 및 장애 독립성이라는 선행 조건이 충족되지 않았다. 이름이나 주소 차이만으로 이 조건을 통과시켜 활성화하지 않았다.

## 1. 후보 전체 조사

주소·호스트 중복을 제외한 526개 그룹의 자원 433개, 서로 다른 호스트 429개를 조사했다.

- 등록 서비스/게시자 namespace, 공개 저장소 게시자, 선언한 원격 주소, 공식 사이트를 대조했다.
- 공용 IP만 허용하는 DNS 검사와 각 등록 호스트의 HEAD 1회, TLS 검증, 리다이렉트 목적 호스트를 확인했다. 사용자 토큰·제공자 계정/키를 보내지 않았고 유료 도구를 호출하지 않았다.
- 공개 CNAME을 추가 조회했으며 33개 호스트에서 CNAME 레코드를 확인했다. 빈 결과는 별칭 없음의 증명이 아니며 CDN flattening/숨은 원천은 알 수 없다.
- **381개 그룹:** 공유 게시자/원격 등 보수적 제외 조건 또는 현재 공개·가용성 조건 때문에 적격 독립 쌍 없음.
- **145개 그룹:** 일부 다른 호스트 쌍이 남지만 원천·상위 API·인증/한도 독립성 미확인.
- **승인 가능한 독립 그룹 0개.** 같은 게시자/저장소/사이트는 초기 파일럿에서 보수적으로 제외하는 단서이며 모든 배포가 물리적으로 같은 서버라는 단정은 아니다.

최종 낮은 동시성 검사에서 429개 중 423개가 5xx 미만의 HTTP 응답을 반환했다. 401·404·405도 포함하며 **정상 MCP 실행 가능 서버 423개라는 뜻이 아니다.** 응답이 없거나 오류인 나머지도 영구 장애로 판정하지 않는다. 공유 CDN IP는 같은 원천 서버라는 증명이 아니므로 원천 미확인으로 관리한다.

초기 병렬 검사에서는 조사 작업자 8개가 공유 DNS 해석기의 4개 제한을 초과해 다수가 로컬 resolver-busy 오류를 냈다. 이 결과는 무효화해 별도 보존했고, 서버 장애로 사용하지 않았다. 보안 해석기 제한을 늘리지 않고 조사 동시성을 2개로 낮춰 재검증했다.

근거: [최종 독립성 조사](independence-audit.json), [낮은 동시성 실행](audit-run-low-concurrency.txt), [CNAME/사이트 보완](enrich-run.txt), [무효화한 초기 결과](independence-audit-invalid-concurrency.json), [진단](probe-diagnostics.json). 조사 결과 파일은 소유자 전용 권한으로 저장했다.

## 2. 실제 제공자 연결 확인

공개 입력 `battery recycling`, limit=2로 기존 두 연결을 **임시 DB**에서 확인했다. 운영 승인·핀·계약 증거는 갱신하지 않았다.

- **Paper Finder:** 운영에서 읽어온 원본 스키마와 실제 서버의 스키마가 달라 SCHEMA_CHANGED로 차단됐다. 임시 DB에서만 최신 tools/list를 재조사한 뒤 읽기 도구가 성공했고 2건을 반환했다. 결과의 출처에 **Europe PMC와 Crossref**가 함께 있었다. 이것이 기존 운영 핀의 자동 재승인을 허용하는 것은 아니다.
- **자체 Research Papers:** 실제 로컬 OwnedDispatch + 실제 Crossref 요청으로 2건을 반환했다(최종 단건 약 736ms). 격리 DB의 초기 검사에 로컬 dispatcher 바인딩이 빠져 POLICY_DENIED가 발생한 문제는 검사 harness에서 수정했다. 자체 에이전트를 원격 HTTP로 우회 실행하지 않았다.
- 두 연결은 실제 실행 API로 Crossref 의존성을 공유하므로 서로 다른 주소만으로 완전한 독립 대안으로 승인하지 않았다. Paper Finder의 공식 지원 안내도 Europe PMC/Crossref/arXiv 사용을 밝힌다. [제공자 공식 안내](https://tools.openkrill.app/support)

초기 자체 응답 집계가 data.items를 읽지 않아 0건으로 표시된 값은 검증된 빈 결과로 사용하지 않았다. 올바른 중첩 구조로 자체 연결 1건만 재검사한 [최종 자체 결과](owned-live-native.json)의 2건을 사용한다. 공개 자료의 제목이 같아도 서로 다른 DOI일 수 있으며 여기서 검색 품질 동등성을 추가로 인증하지 않았다.

근거: [기존 두 연결의 실호출](live-connections.json), [자체 로컬 실행 최종 결과](owned-live-native.json), [검사 코드](live_connections.py). 실제 네트워크 MCP handshake/메타데이터 조회와 로컬 실행 경로를 구분하며, 전체 패킷 수를 계측한 것으로 주장하지 않는다.

## 3. 런타임 차단 보완

`agent_market/fallback_independence.py`를 추가하고 R-06의 **정책 저장과 실행 시 재검증(current_pair, dispatch 경계 포함)** 양쪽에 공통 판정을 연결했다.

- 이름/등록 ID가 달라도 정규화한 주소가 같으면 거부한다.
- 같은 호스트의 다른 경로·포트·스킴·쿼리도 상호 대체를 거부한다.
- 같은 등록 namespace·저장소 게시자·선언된 원격 호스트·공식 사이트를 공유하는 경우 초기 파일럿에서 보수적으로 거부한다.
- 검토된 자체 Research Papers 및 Paper Finder의 search_papers 조합은 알려진 공통 Crossref 의존성으로 거부한다. 이름/source를 바꿔 이 사실을 우회할 수 없도록 실제 주소·도구를 기준으로 확인한다.
- 큰/잘못된 의존성 메타데이터는 검토를 요구한다. 메타데이터는 제외 근거로만 쓰고, 서로 다르다는 것을 독립성 승인으로 사용하지 않는다.

이 판정은 **부정 조건 차단**이며 독립성 증명/새 그룹 승인 기능이 아니다. DNS/CNAME 실시간 조회를 DB 트랜잭션 안에 추가하지 않았고, 조사 파일을 운영 권한으로 자동 신뢰하지 않는다. 운영 source 버전 반영 전까지 기존 프로세스에 새 차단이 적용됐다고 표시하지 않는다.

## 4. 실제 TCP 장애 전환 테스트

테스트 DB에 서로 다른 논리 호스트의 MCP HTTP 서버 두 개를 임시 loopback 포트로 구성했다. 도구 조사·실제 TCP 기반 실행/계약 검사와 shadow를 통과시킨 뒤, **격리 DB에서만** canary와 전역 제어를 켰다. 재현을 위해 테스트에서만 canary 표본 선택을 고정했고 실행별 opt-in·기존 권한·예산·단일 대체 제한은 유지했다.

주 서버 리스너를 실제 shutdown/close한 결과:

- 종료 후 주 서버의 도구 호출: **0회**.
- 대체 서버의 실제 HTTP 도구 호출: **1회**.
- 시도 상태: **failed → succeeded**.
- 결과: **succeeded**, `fallback_used=true`, 원래 자원과 실제 실행 자원을 구분.

[실제 TCP 결과](tcp-failover.json), [테스트 코드](<저장소>/tests/test_workflow_fallback_tcp.py).

이는 MockTransport만으로 만든 성공이 아니지만 **같은 시스템의 테스트 서버와 테스트용 결과**다. 외부 독립 제공자나 물리 서버/네트워크 장애 독립성을 증명하지 않으며 운영 실제 대체 실행 합격으로 바꾸어 설명하지 않는다.

## 6. 운영 반영 및 실제 활성화 조건

**이번 요청의 운영 활성화·외부 독립 제공자 간 대체 실행 검증은 아직 완료하지 않았다.** 확정된 독립 조합이 없으므로 무검증 후보를 선택하거나 전역 제어만 켜서 완료로 표시하지 않는다. 공개 제공자의 실제 원천 서버/상위 API/인증·한도 정보와 현재 스키마·계약 검증을 확보해야 한다. 미확인 145개를 장애가 없다고 보장하거나 자동으로 승인하지 않는다.

차단 보완 코드를 운영에 반영하려면 사용자 터미널에서 한 릴리스를 frontend·admin·execution에 배포한다. jobs 코드는 변경하지 않아 이번 배포 대상에 넣지 않는다. 이 명령은 **폴백 활성화 명령이 아니다.**

```bash
agentcon package fallback-independence-20261024-v1
agentcon deploy frontend fallback-independence-20261024-v1
agentcon deploy admin fallback-independence-20261024-v1
agentcon worker-deploy execution fallback-independence-20261024-v1
```

AGENTS.md의 사용자 직접 서버 실행 지침에 따라 운영 배포/재시작을 수행하지 않았다. 다음 실제 활성화에는 (1) 독립 원천이 확인된 동일 기능 주·대체 한 쌍, (2) 최신 스키마와 실제 실행/계약 증거, (3) 바인딩된 shadow·명시적 canary/입력 공유 권한이 필요하다. 현재 남은 조건을 서버 재시작만으로 해결되는 것처럼 안내하지 않는다.
