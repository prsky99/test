## 새로 찾았거나 남은 문제
### 높음
1. **실행 확인 필터 첫 화면에 성인 서비스**: `verified=true`로 검색어 없이 둘러보면 1위가 EscortFox(에스코트 디렉터리, 분류 web_search)입니다. 공개 첫 화면에 나오지 않게 하는 정책이 필요합니다.
2. **AI 워크플로 제안의 2단계가 주제를 잃음**
   - "then find supporting documentation"을 요청하면, 2단계 검색어가 "supporting research"·"supporting technical research"로만 만들어집니다.
   - 실제 실행 결과도 약학 교육 위원회 보고서(무관)였습니다.
   - 문서 검색 단계 대신 논문 검색이 다시 쓰입니다.
3. **x402 프로토콜 검색 0건**: weather·price 모두 0건입니다(Explore 세션 영역).
4. **Chat 순위**: 15차와 같습니다.
   - `summarize a PDF` → Aspicio
   - `convert USD to EUR` → JiZhiMCP·Evlek
   - `book a flight` → HotelsCasa
   - `review my github pull request` → 0건
   - `create a QR code` → Pro UPI QR
   - `get the current bitcoin price` → cryptoetf

### 중간
5. **AI 생성 이름이 연결어로 끝남**: 단어 단위로 자르니 "…, then find"처럼 끝납니다. 끝의 then/and/find 같은 연결어와 쉼표는 떼어야 합니다.
6. **A2A 같은 `contextId` 후속 요청**: "only free ones without an API key"에도 첫 답과 같은 목록을 돌려줍니다.
7. **완료 상태 문구가 모호함**: "Your reviewed action is complete."가 저장·실행 모두에 같은 문구로 나옵니다.
8. **분류 오류 예시**: UK Fitness Pro·Garden Route Specialist → travel_maps_weather, Tutors.kz → web_search, Foo Guard Library → education_culture.
