# 공개·워크스페이스 템플릿 공통화 및 화면 개선

2026-10-25. 소스 수정과 검증을 완료했고 프론트엔드 적용용 릴리스를 준비했습니다. 운영 서버는 교체하지 않았습니다.

## 적용한 동작

공개 Workflows의 실행 화면 위에 모든 템플릿을 카드로 나열하던 부분을 작은 선택기로 바꿨습니다. 전체 목록은 Browse templates에서 검색·카테고리·이전/다음 페이지로 탐색합니다. 실제 렌더링은 데스크톱 8개, 모바일 4개로 제한합니다. 검색·분류가 바뀌면 첫 페이지로 돌아가며, 현재 워크플로우를 다시 선택해도 수정 중인 캔버스가 초기화되지 않습니다. 선택만으로 실행하지 않습니다.

워크스페이스의 Templates도 공개 API가 사용하는 `published_templates`를 직접 사용합니다. 별도의 목록을 복사해 관리하지 않습니다. 공개 허브에 게시·철회되는 템플릿이 동일하게 반영되고, 공개되지 않은 개인 작업은 포함하지 않습니다. 기록된 실행 조건을 충족하지 못하는 항목은 선택을 차단합니다.

일반 공개 템플릿은 게시된 기본 입력·에이전트 구성을 유지하면서 개인 이름으로 저장하고 실행할 수 있습니다. 검증된 입력 편집·대체 실행이 있는 보호형 템플릿은 기존 기능을 유지합니다. 일반 템플릿에 대체 실행 지원을 표시하거나 허용하지 않습니다. 실행 동의에는 실제 기본 입력과 에이전트가 표시됩니다. 저장된 버전의 실행 성공 후 다운로드할 수 있으며, 다운로드 앱은 원본 정의 해시를 전송해 이후 변경된 그래프를 조용히 실행하지 않습니다.

기존의 인증, CSRF, 역할, 목적별 저장·실행 동의, 크레딧, 버전 충돌 차단, 중복 실행 차단, 실행 키 암호화 및 출력 이스케이프를 유지했습니다. 실제 고객의 작업이나 크레딧은 수정하지 않았습니다.

