# 주요 잔여 문제 수정 결과

2026-10-29. 소스 수정·격리 검증 및 **승인된 네 서비스 r4 운영 반영을 완료했습니다.** 실제 확인 결과와 검색 정렬·화면 r2 보완의 최종 적용 결과는 [운영 반영 결과](DEPLOYMENT.ko.md)를 참고하세요. 최초 기준은 네 역할의 qa7-repair 각 역할 r4였습니다. experience 각 역할 r4 반영 후, 웹 두 서비스는 검색·화면 보완을 포함한 experience-search 각 역할 r2까지 적용했습니다. 작업 서비스는 experience r4를 유지합니다.

## 수정한 동작

- **대화 보관:** 사용자 승인에 따라 메시지 90일 보관 후 자동 삭제, 최근 200개 상한 유지. 읽기에서도 만료 메시지를 제외합니다. jobs의 독립 유지관리 슬롯에서 배치 삭제하므로 장시간 수집에 밀리지 않습니다. 만료 관심사와 추천·도구 문맥도 정리하고 재방문으로 문맥이 부활하지 않도록 막았습니다. 워크스페이스, 목적별 동의와 실행 증거는 이 삭제 대상이 아닙니다.
- **Chat 사용성:** 입력창을 결과 위에 유지하고 결과 영역 내부를 스크롤하게 했습니다. 요청 중 Stop 버튼의 공간을 확보해 늦은 응답에도 배치가 변하지 않습니다. 쿠키 배너가 포커스를 가릴 때 보이도록 스크롤합니다. 최신 응답으로 이동, 정확한 추천 ID의 피드백과 선택적 사유, 제공자 설명 구분, 품질 등급 설명, 공개 ID 공유 및 2~4개 비교를 추가했습니다. 공유 링크에 질문·세션 토큰을 넣지 않습니다.
- **대화 이어가기·검색:** `it` 등 직전 항목 지시어를 지원합니다. 지역·주제와 무관한 후보를 통과시키던 Explore 변수 충돌을 수정했습니다. `current`를 `currency`로 바꾸던 잘못된 자동 교정을 막았습니다. 자동 수정은 검토된 오타에 한정하고 불확실한 유사 단어는 명시적 제안으로 유지합니다. 로컬 작업 자동완성은 키보드 combobox 패턴을 사용합니다. 후보 계산에 추가 서버 요청을 사용하지 않으며 기존 디바운스 검색은 유지합니다.
- **Test 정확성:** 문자열 안에 감싸진 JSON도 해석해 캐시 여부와 실제 원본 조회 시각을 표시합니다. 게이트웨이 지연을 외부 에이전트 실행 시간으로 표시하지 않습니다.
- **접근성:** 제공자 설명·워크플로우 상태 글자와 배경의 대비, 구형 대체 화면 링크·푸터 대비를 수정했습니다. 홈 제목 구조와 통계 보조 영역의 의미 구조를 정리했습니다. 고정 헤더가 아닌 현재 헤더를 무조건 고정 높이라고 가정하지 않고 실제 가림인 쿠키 배너를 수정했습니다.
- **HTTP:** REST 오류를 RFC 9457로 정리하며 error_code 호환 필드와 보수적인 retryable을 제공합니다. JSON-RPC·x402 고유 계약은 보존합니다. 명시적인 공개 조회에 ETag/304·짧은 공유 캐시를 적용하고 인증·쿠키·방문 토큰·서명 응답은 공유하지 않습니다. 남은 한도는 실제 Redis 또는 로컬 제한기의 단일 판정 값으로 표시합니다. HEAD와 압축·약한 ETag의 조합, 304의 Content-Length도 검증했습니다.
- **상태:** `/status.json`에 실제 관측 성공률, 관측 개수·기간, 응답 시간과 최근 실패 구간을 추가했습니다. 무관측·오래된 관측은 unknown이며 가동률 100%를 임의 생성하지 않습니다.
- **브라우저 도구·서명:** 기능 감지 방식의 WebMCP 검색·추천을 구현했습니다. Ed25519·고정 공개 키·짧은 만료·Redis nonce 재생 차단을 사용하는 선택적 Web Bot Auth를 구현했습니다. 서명으로 얻는 것은 공개 조회 한도이며 로그인·실행·결제 권한을 대체하지 않습니다. 신뢰 제공자 키는 임의로 등록하지 않았습니다.
- **보안 유지:** CSP nonce를 HTML 파서로 실제 script 태그에만 붙여 템플릿 문자열을 손상시키지 않습니다. 출력 이스케이프·토큰 마스킹·프로토콜 선택·상업 정보 비노출 경계를 유지했습니다. 기존 정적 파일 해시 캐시·압축도 유지합니다.

## 검증과 증적

- 통합 회귀 **469 passed, 1 skipped**: `regression.log`. 제외된 1개는 구형 화면에 공개 페이지 40조건 검사를 중복 적용하지 않기 위한 것이며, 구형 화면 자체의 상호작용·접근성 검사는 별도로 통과했습니다.
- 최종 304 응답 세부 수정 후 HTTP·관련 회귀 **66 passed**. 기존 통합 회귀와 중복되므로 더해서 고유 검사 수로 표시하지 않습니다.
- **공개 10화면 × 4조건 = 40조건:** 모두 HTTP 200, 가로 넘침 0, axe 위반 0. `isolated-ui-matrix.json`. 홈·Explore·Chat·Test·Workflows·Learn·Status·등록·About·로그인으로 구성했으며 로그인은 실제 로그인 라우터와 격리 인증 제공자 설정을 사용했습니다. 사람의 실제 OAuth 계정으로 로그인한 시험은 아닙니다.
- **지연 응답 Chat:** 1.1초 지연을 주고 입력창 y좌표 변화 0. 공개 화면 CLS 합은 390px에서 0.0021 미만, 1366px에서 0.0085 미만. 구형 화면도 0.0063 미만. `cls-*.json`, `chat-stable-*.png`. 이 수치는 격리 실험이며 운영 실사용 p75가 아닙니다.
- **실제 PostgreSQL 18:** 90일 삭제·재방문 문맥 초기화·상태 집계, 기존 행을 보존하는 추가형 스키마·동시 인덱스, 반복 적용을 확인했습니다. `native-postgres.json`.
- **실제 임시 Redis:** 24개 동시 요청에서 한도 16개만 허용하고 남은 한도가 원자적으로 감소함을 확인했습니다. nonce 재사용도 차단했습니다. `native-redis.json`.
- **네 동결 후보:** 각 후보의 1,328~1,334개 파일 해시와 실제 PostgreSQL 계약을 각각 검증했습니다. `frozen-candidate-verification.json`, `overlay-releases.json`. 실행 중인 역할별 활성본에서 이번 변경만 반영했으며 공유 작업 트리를 통째로 패키징하지 않았습니다.
- 공개 콘텐츠 **318파일 위반 0**, 새 코드 F/B 정적 검사 통과, 세 JS 파일 구문 검사 및 SQL 카탈로그 일치 검사 통과. 테스트 프레임워크의 기존 Starlette/httpx 사용 중단 경고 1개가 남아 있으며 제품 오류나 테스트 실패는 아닙니다.

캡처에는 격리된 가상 에이전트만 사용했습니다. 비교 화면은 `compare-published.png`·`compare-legacy.png`, 쿠키 포커스 증적은 `cookie-focus-*.png`입니다. XSS·자격 증명 노출·프로토콜 경계·멱등성 회귀는 위 통합 검사에 포함됩니다. 모든 취약점이 없다는 무제한 보증이나 신규 운영 침투시험 완료로 표현하지 않습니다.

## 운영 반영과 남은 외부 검증

**스키마 추가 → 네 역할 배포 → 실제 공개 화면·자동 작업 확인** 순서로 승인 범위의 반영을 완료했습니다. 스키마 작업은 새 빈 테이블 1개와 CONCURRENTLY 인덱스 2개만 추가하며 기존 행을 수정하지 않습니다. 네 역할은 사용자 명시적 승인으로 교체했습니다. 검색 정렬·화면 r2의 웹 교체도 추가 명시적 승인으로 완료했습니다. 구형 패키지로 되돌려도 승인된 90일 만료 삭제로 지운 메시지는 복원되지 않습니다.

[운영·적용 명령 안내](../../docs/qa/feature-remediation-2026-10-29/OPERATIONS.ko.md)에 정확한 순서를 정리했습니다. PostgreSQL·모델 서버·프록시 자체 재시작은 필요 없습니다. 네 서비스 r4는 실제 교체와 확인을 완료했으며 이후 검색 정렬 r1과 화면의 재정렬을 제거한 r2도 반영했습니다.

다음은 구현 또는 자동 시험만으로 완료를 주장할 수 없어 별도 수용 절차를 남겼습니다.

- Web Bot Auth는 실제 협력 봇의 검증된 공개 키 등록과 해당 봇의 운영 상호운용 시험이 필요합니다. 신뢰 파일이 없으면 익명 한도를 그대로 사용합니다.
- WebMCP는 Chromium 격리 모사 검증에 이어 운영 브라우저에서 실제 도구 등록·공개 검색 호출도 확인했습니다. 브라우저 자체 에이전트 제품과의 실제 사용자 흐름은 별도 확인이 필요합니다.
- 실제 AP2 mandate·A2A x402 정산은 판매자·facilitator·키·지출 승인 설정과 종단 시험이 필요합니다. 검사 전용 서비스를 정산 지원으로 선언하지 않았습니다.
- 실제 사람 5명×6과업, 스크린리더 사용자 1~2명의 시험은 아직 수행하지 않았습니다. 모집 없이 실제 사용자 점수를 만들지 않았습니다.
- 운영 LCP·TTFB p75와 실제 외부 제공자 성공률은 반영 후 측정해야 합니다. 요청별 CSP nonce가 있는 HTML을 무리한 304 캐시로 바꾸지 않았습니다.

[외부 수용 시험 절차](../../docs/qa/feature-remediation-2026-10-29/EXTERNAL-ACCEPTANCE.ko.md)에 준비 사항과 완료 기준을 정리했습니다. 기존 상태 평가의 추정 점수를 올려 새 종합 등급을 만들지 않았습니다.
