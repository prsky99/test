# AI AD Coin 광고주 플랫폼 정책 v6 개정 기록

2026-11-07 한국 시간 · 범위: 정책·사업 기획 문서

- 최종 목표: 모든 에이전트에 열린 광고주 중심의 광고·마케팅·보상·AI 서비스 플랫폼. Agent Concierge는 발견부터 결과 확인·다음 작업까지 이어지는 허브를 지향한다.
- 산출물: [정책 PLAT-01~30](../../docs/AD_COIN_PLATFORM_POLICY.md), [실행 기획·지표·GROW-01~18](../../docs/AD_COIN_PLATFORM_ROADMAP.md), 기존 개발·판매·목표·자산 정책·기술 설계·구현 순서 문서의 연결 갱신.
- 유지한 기반: 초기 공급 0, 광고주 실제 입금, 준비금 분리, 승인 노출의 독립 보상, 사용자 귀속 관리형 에이전트 지갑·이전·AI 사용·상환, 보안→품질→속도, 일반 검색과 광고의 분리.
- 확장한 사업: 전략·소재·매체 제안·집행·귀속·실험·시장 분석·대행사·외부 배포·재집행과 투명한 선택 서비스 수익. 광고비·토큰 유통·서비스 결제를 매출로 중복 합산하지 않는 기준을 추가했다.

## 검증 범위

검증 기록은 [validation.json](validation.json)에 보관한다. Python 표준 라이브러리로 정책 ID·검수 ID의 유일성/연속성, 30개 정책의 검수 추적, 변경 문서의 로컬 링크와 연결, v5 기계 명세의 유지 여부, 과거 v4 증거에 포함된 소스 해시와 현재 상태를 확인한다. 현재 파일의 SHA-256과 과거 v5 문서 해시가 달라진 경로도 기록한다. 과거 검증 결과나 날짜를 덮어쓰지 않는다.

이는 문서 정합성 확인이다. GROW 검수 18개·v5 검수 43개의 제품 통과 건수는 이번 작업에서 **0건**이다. 제품 시험·브라우저·API 보안·블록체인·실자금·법률·광고 효과·성능은 재검증하지 않았다. 공개 프런트엔드·제품 코드·운영 서버·배포·DB·플래그·실자금·체인 거래의 변경은 이번 범위에 없다.

## 조사와 한계

2026-11-07 확인한 공식 AAMP·AdCP 문서, 논문 두 편과 공개 LinkedIn 당사자 의견은 정책의 조사 절에 출처와 확인 한계를 기록했다. AAMP 의견 수렴 연장과 AdCP 실험 기능을 반영했다. SNS 의견을 검증된 시장 통계로 사용하지 않았으며 시장 규모·성과 예측 숫자를 새로 만들지 않았다.

다음 구현 작업은 v5 단계 A의 사람 승인·서버 인증 주체·자산 경계 해결과 격리 환경의 P1·광고주 업무 연결이다. 실제 사업 개방에는 각 단계에 명시한 검증과 활성화 조건을 별도로 충족해야 한다.
