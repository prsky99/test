## 1. 진행 상황

- **기준:** 설계 v6.2(`docs/AD_COIN_PLATFORM_ARCHITECTURE.md`, DEC-01~13)이고, 지금은 R0(시험 모드) 개발 단계다.
- **코드:**
  - `agent_market/ad_coin/v2/`: 44개 파일, 약 1만 줄, 웹 3개, 토큰 계약 1개
  - 표: `adc2_`, schema 5
  - **아직 git에 없다**(추적 0개). 시험 파일 14개도 추적되지 않는다.
- **연결:** 운영 서버에는 붙이지 않았다. 작업본 `front.py`에 연결 코드가 있지만 `AD_COIN_V2_ENABLED`로 꺼져 있다. 운영 DB, 자금, 체인, 배포는 바뀌지 않았다.

## 2. 남은 과제

### 지금 해야 할 것(시험 모드 안)

1. **v2 커밋:** 1만 줄과 시험 파일이 커밋되지 않았다. 작은 단위로 나눠 커밋하고, 커밋 전에 전체 시험을 통과해야 한다.
2. **토큰 계약 보안**(`v2/contracts/AIADCoin.sol`):
   - 준비금 검사가 실패 시 열린다. 오라클이 없거나 0이면 무제한 발행된다.
   - 단일 소유자이고, 소유권을 넘길 수 없고, timelock이 없다.
   - 메인넷 배포는 외부 감사 뒤로 미룬다.
3. **실험 그룹 배정의 MD5 → sha256**(`v2/advertiser_platform.py:357`)
4. **v2 화면을 사이트 디자인 체계로 옮기기**(11-05 결정): 지금은 자체 `app.css`를 쓴다.
5. **돈·키·서명 모듈 커버리지 95% 이상:** 지금 HTTP 계층은 71~84%, receipts 75%, key_vault 76%다.
6. **속도 제한을 Redis로 공유**(프로세스 메모리 → 슬롯 간 공유). 백그라운드 작업도 jobs 서비스로 옮긴다.
7. **운영 연결 전 관문:**
   - 실제 IdP 연결
   - 운영 DB 역할·RLS 적용(DB 변경이라 승인 필요)
   - 백업·재해 복구 연습
   - 다지역 부하 측정
   - 운영 설정 허용 목록에 `AD_COIN_*`·`AD_COIN_V2_ENABLED` 추가
8. **문서 정리:** AD Coin 문서 19개에 색인을 하나 둔다.

### 승인이 필요한 것(총괄 PM을 거쳐 사용자에게)

- 운영 DB에 `adc2_` 표와 역할 만들기(DB 변경)
- v2 화면을 운영 서버에 연결해 켜기
- 실제 가치 기능 전부: 결제, 이전, 상환, 토큰 발행, 체인 연결. 법률 의견을 받기 전에는 열지 않는다.
