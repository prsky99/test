# 자율형 에이전트 접속 문제 수정 결과

2026-10-27. 소스 수정과 적용 패키지 준비 완료. **운영 반영 전**이다.

## 현재 운영에서 확인한 사실

- 공개 문서 5개의 HEAD 요청이 405였다.
- 사이트맵에 들어 있던 카테고리 20개 중 5개가 404였다.
- `weather forecast for Seoul`은 현재 REST·MCP·A2A 모두 `Geocoding & Weather`를 1위로 반환했다. 해당 도구는 도시명/좌표를 받아 현재 날씨와 다일 예보를 제공한다고 명시한다. 인용된 푸에르토리코 뉴스 1위는 이번 측정에서 재현되지 않았다. 실제 외부 날씨 실행까지 성공했다는 뜻은 아니다.
- 최초 세 요청은 7.232·5.659·3.798초, REST 추가 세 요청은 8.235·3.929·4.038초였다. 추가 요청의 서버 처리 시간도 7.287·3.628·3.733초로, 네트워크만의 문제로 볼 수 없다.
- 원본 조사 보고서·76건 실행 스크립트는 이 체크아웃에 없었다. 공유된 증상을 기준으로 새 스크립트와 회귀 시험을 만들었다. 원본의 미공개 20개 항목 전체와 일대일 대조했다고 주장하지 않는다.

근거: [운영 재현](live-baseline.json), [추가 지연 측정](live-warm-latency.json).

## 수정한 내용

1. **문서 HEAD**: robots, sitemap, llms, 카드·매니페스트·진입 문서 등에 GET과 일치하는 상태·콘텐츠 유형을 반환하고 본문은 보내지 않는다. 비공개 API에 HEAD를 일괄 개방하지 않았다. SSE 미지원 MCP의 GET 405는 유지했다.
2. **사이트맵/카테고리**: 알려진 카테고리는 증거 만료로 사라지는 URL이 아닌 지속되는 안내 페이지로 제공한다. 현재 증거가 없는 경우 사실에 맞는 빈 상태를 표시한다. 앞의 몇 개만 읽고 적격 대상을 놓치는 조회를 수정했다. 게시 후보를 96개씩 최대 8회로 제한하고 최신 연결 버전·실행 증거를 다시 검사한다. 무제한 범주 검색을 하지 않는다. 미리보기의 표시 대상을 못 찾은 것이 전체 카탈로그에 대상이 없다는 보장은 아니다.
3. **MCP 행동 표시/출력**: 공개 13개 및 compact 5개 도구에 읽기·쓰기·파괴 가능성·외부 접촉 표시와 출력 스키마를 추가했다. 대화 이력을 수정하는 검색을 읽기 전용으로 표시하지 않는다. 구조화 결과에도 안내 text를 포함한다. 출력 스키마는 공통 필드 계약이며 모든 제공자 결과를 완전히 정의하는 도메인 스키마는 아니다.
4. **정확한 버전 협상**: 새 메타데이터·응답 체계를 구현하지 않은 MCP 2026-07-28 지원 표시는 제거했다. 실제 지원하는 2025-11-25 계열로 협상한다. 향후 완전한 2026 구현과 클라이언트 상호운용 시험을 거쳐 다시 추가할 수 있다.
5. **브라우저 에이전트 CORS**: 공개 `/chat`, `/mcp`, `/a2a`와 기존 루트 POST에 HTTPS 출처 허용 목록과 사전 요청 처리를 추가했다. 토큰·세션·요청 제한 헤더를 브라우저가 읽을 수 있다. 미허용 출처는 신원 생성·실행 전에 거절한다. 기본은 서비스 자체 출처이며, 추가 출처는 운영자가 `AGENT_BROWSER_ORIGINS`로 명시해야 한다. 워크스페이스·어드민·compact 권한 API를 개방하거나 쿠키 공유를 허용하지 않는다. 다운로드 워크플로우 앱의 별도 정책은 유지했다.
6. **A2A 연속 대화**: 기존 text/data part 응답을 확인했다. 정상 서버 발급 contextId의 후속 상세 요청을 검증했다. 다른 방문자 토큰과 문맥의 충돌, 추측한 다른 클라이언트 문맥, 잘못된 문맥은 새 방문자를 만들어 성공처럼 응답하지 않고 오류로 처리한다.
7. **요청 오류**: JSON 파싱 오류(-32700), 유효하지 않은 JSON-RPC 요청(-32600), 잘못된 인자(-32602)를 구분한다. 도구 인자를 배열로 보내거나 존재하지 않는 도구 목록 커서를 보내는 경우도 거절한다.
8. **세션·제한·이어서 조회**: 알려지지 않은 방문 토큰으로 새 대화를 만들면 기계용 세션 메타데이터에 reset을 명시한다. 원래 토큰은 되돌려 쓰지 않는다. compact 인증 API는 기존 401을 유지한다. 대화 요청에는 실제 제한 정책을 표시하고 제한 초과에는 Retry-After를 제공한다. 추천 추가 조회는 기존 세션과 continuation_plan/more를 사용한다. 전 도구 목록은 한 응답에 끝나므로 가짜 다음 페이지를 만들지 않는다.
9. **통계의 의미**: 문서의 수치를 ‘최대 5분 캐시된 활성·도달 가능 목록’으로 명확히 했다. 실행 검증 후보 수 및 날짜가 표시된 홈 일별 통계와 구분한다. 오래된 워크플로우 고정 개수 문구도 제거했다.
10. **검색 반복 조회 최적화**: 후보마다 보고서를 읽으면서 에이전트·실행 증거를 반복 조회하던 경로를 PostgreSQL 요청 단위 배치로 바꿨다. 보고서 대상, 현재 버전, 최신 실행 결과·만료 검증은 유지한다. 결과/적격 상태를 방문자 간 캐시하지 않는다. 격리 DB에서 보고서 2건의 검증 조회는 메타데이터 확인 포함 **18회 → 4회**였다. 배치 전후 추천 ID가 같고 새로운 실행 실패가 생기면 이전 성공 보고서를 배제하는 것을 확인했다. 이 수치는 SQL 호출 수의 개선이며 운영 응답 시간이 같은 비율로 줄어든다는 뜻은 아니다.
11. **시험 자료**: 기존 자율형 시험의 compact 도구/전체 도구 계약과 예보 기능 설명을 일치시켰다. 새 discovery-only 실행기를 추가했다. 결제, 제공자 실행, 피드백 제출, 알림 등록을 자동으로 수행하지 않는다.

논문·공식 규격·SNS 근거 및 적용 범위는 [조사 기록](RESEARCH.ko.md), 실행 방법은 [QA 가이드](../../docs/qa/autonomous-agent-scenarios.md)에 있다.

## 검증 결과

- 통합 API·추천·보안·Chromium·Python/Node·격리 PostgreSQL 검사 **376개 통과**.
- 반복 조회 최적화 후 네이티브 선택 동등성·보고서 결속·최신 실패 배제 등 **64개 통과**.
- 그 후 영향받는 문서·추천·보안 검사 **52개 통과**. 앞선 검사와 중복된다. 두 XML의 고유 시험은 **439개**이며 한 번의 단일 439개 실행을 의미하지 않는다.
- PostgreSQL 18은 임시 Unix 소켓 클러스터만 사용했다. 실제 운영 계정·외부 제공자 호출 0건, 종료 후 임시 클러스터 제거 확인.
- Chromium은 임시 실제 TLS 서버에서 허용 출처의 세션 헤더 열람과 미허용 출처의 CORS 차단을 확인했다. 루프백 접근에 필요한 별도 로컬 네트워크 권한만 시험용 출처에 부여했다.
- 공개 콘텐츠 **303개 파일, 위반 0건**. embedded HTML과 extracted_html.txt 일치. 신규 파일 및 수정 코드의 Ruff 검사 통과; 기존 파일의 단일 행 스타일 E701/E702는 제외했다.
- 소스 소유 SQL 목록 3,801개·테이블 232개 확인. 최종 목록의 실행 SQL/스키마 내용은 유지되며 소스 해시를 현행화했다.
- 최초 실패 로그도 원인 추적용으로 보존했다. 최종 통과 증적은 `verification.log`, `final.xml`, `performance-final.log`, `performance-final.xml`, `post-batch-content.log`, `native-postgres.json`이다.

## 적용

고정 패키지: `autonomous-agent-interop-20261027-r2`. 프론트엔드만 교체하면 된다.

```sh
./agentcon deploy frontend autonomous-agent-interop-20261027-r2
```

운영 교체는 AGENTS.md의 명시적 실행 지시 요구에 따라 수행하지 않았다. 패키지 1,300개 파일의 해시와 현재 소스 일치를 확인한다. 배포 후 공개 문서 HEAD, 사이트맵 카테고리, 세 프로토콜 추천·연속 대화와 실제 지연을 다시 확인해야 한다. 자체 출처 이외의 브라우저 클라이언트는 정확한 HTTPS 출처를 먼저 허용 목록에 설정해야 한다.

## 남은 검증 한계

실제 결제·실제 제공자 실행, 실제 서명을 가진 방문 에이전트, 외부 서비스 생존 보장, MCP Registry/x402 Bazaar 등재, 운영 알림 구독은 이번 live 시험의 범위가 아니다. 격리된 실행 권한·중복 방지 시험을 실제 외부 실행 성공으로 바꾸어 표현하지 않았다. 남아 있는 운영 검색 지연은 배포 후 동일 조건으로 측정해야 하며, 현재 지연 목표를 완전히 충족했다고 선언하지 않는다.
