## 2. 권장 순서

### 0단계: 계측 먼저 (반나절, 내부)
- 하루 단위 익명 집계를 만든다.
  - 입구별: `/`, Chat, MCP, A2A, discover API, llms.txt, agent-card, 사이트맵
  - 클라이언트 종류별: 브라우저, 알려진 AI 봇(GPTBot·ClaudeBot·PerplexityBot·Bingbot·Googlebot), MCP·A2A 클라이언트, 스크립트
  - IP·내용은 저장하지 않는다.
- 우리 시험은 따로 센다. 시험 도구 UA("site owner test/QA", "qa-", "AgentScenarioQA", "Headless")와 우리 서버 IP를 실사용 지표에서 뺀다.
- 관리자 화면에 주간 지표를 띄운다: 외부 에이전트 세션, 서로 다른 MCP 클라이언트 수, AI 봇 요청, 사람 방문.
- 이유: 지금은 Cloudflare 화면을 손으로 걸러야만 실사용을 볼 수 있다. 이 단계가 없으면 이후 작업의 효과를 판단할 수 없다.

### 1단계: 에이전트가 찾는 곳에 등록 (1~2일, 외부 게시는 사용자 승인 필요)
1. **공식 MCP Registry**
   - `server.json`을 만든다. remote streamable-http 주소는 `https://agentconcierge.biz/mcp`이다.
   - namespace는 도메인 확인(DNS TXT 또는 HTTP)으로 `biz.agentconcierge/*`를 쓴다.
   - 게시는 운영자 계정으로 한다.
   - Registry를 읽어 가는 클라이언트와 디렉터리가 많아, 한 번의 등록이 여러 곳으로 퍼진다.
2. **주요 MCP 디렉터리 3곳 선별 등록**: Smithery, Glama, PulseMCP 또는 mcp.so. 각 곳의 유지보수 상태와 유입을 확인한 뒤 고른다. 아무 곳에나 등록하지 않는다(11-03 설계 원칙).
3. **A2A 쪽**: 에이전트 카드를 받는 공개 디렉터리·레지스트리 가운데 실제로 유지되는 곳을 조사한 뒤 등록한다. ERC-8004 등록도 같은 방식으로 검토한다.
4. **연결 안내 한 장**
   - 클라이언트별 붙여 넣기 설정을 담는다: Claude Code(`claude mcp add --transport http agent-concierge https://agentconcierge.biz/mcp`), Claude Desktop, Cursor(설치 딥링크 버튼), VS Code, OpenAI Agents SDK.
   - llms.txt와 About에서 이 안내로 연결한다.

### 2단계: AI 검색·검색엔진 노출 (3~5일, 내부 개발 + 콘솔 등록)
1. **과업별 공개 페이지**
   - "weather forecast MCP server", "translate document agent" 같은 과업·카테고리 페이지를 서버에서 바로 그린다. 고정 HTML이라 화면 정책에도 맞다.
   - 페이지마다 근거(최근 헬스체크, 시험 호출, 품질 등급)가 있는 상위 에이전트 몇 개를 보여 준다.
   - 상위 수백~수천 쪽만 사이트맵에 올리고, 근거가 없는 리스팅은 올리지 않는다.
   - AI 검색이 인용할 수 있는 유일한 자산이 이 근거 데이터다.
2. **Bing Webmaster와 IndexNow**: Bing 색인은 ChatGPT 검색과 Copilot 노출로 이어진다. 사이트맵을 제출하고, 페이지가 바뀌면 IndexNow로 알린다.
3. **Google Search Console**: 사이트맵 제출과 색인 상태를 확인한다.
4. **마크다운 응답**: `Accept: text/markdown`이면 같은 내용을 마크다운으로 준다. Cloudflare의 같은 기능은 Pro 요금제 전용이라 우리가 직접 만든다. 지금도 HTML이 아닌 요청에는 JSON을 주고 있으니 그 연장이다.

### 3단계: 사람 개발자 유입 (작성은 내가, 게시는 사용자 계정으로)
- 공개 GitHub 저장소 README를 다듬는다: 한 줄 연결 설정, 데모 GIF, 배지.
- 런칭 글 초안을 쓴다: Show HN, Reddit r/mcp·r/LocalLLaMA, X, MCP Discord.
  - 메시지는 "25만 개 에이전트 중 실제로 동작이 확인된 것만 추천한다"이다.
  - 게시와 답글은 사용자가 직접 한다.
- 웹어워드 대비 화면 품질은 이미 갖췄다.

### 4단계: 재방문 (기존 기능 활용)
- 에이전트에게 `whats_new`와 `subscribe`를 응답에서 더 잘 보이게 한다(첫 응답 안내에 한 줄).
- Chat 고르기 결과와 "Worked / Didn't work" 피드백을 익명 지표로 모아 추천 품질 개선에 쓴다.
  - 저장 방법과 개인정보 처리는 먼저 정한다.

### 참고: 한국 접속 속도
- Cloudflare가 한국 방문자를 미국 LAX로 돌려 요청마다 0.8초 이상 걸린다.
- 주 대상이 해외 에이전트·개발자라 우선순위는 낮다.
- 무료로 바꿀 수 있는 설정은 없고, 유료 경로 최적화나 요금제 변경은 비용을 판단해야 한다.

## 4. 사용자 결정이 필요한 것
- 외부 게시: 공식 MCP Registry, 디렉터리, A2A 레지스트리 등록. 운영자 계정과 도메인 확인(DNS TXT 추가)이 필요하다.
- 검색 콘솔: Bing Webmaster·Google Search Console 등록. 사용자 계정으로 해야 한다.
- 커뮤니티 글 게시: 사용자 계정으로 한다.
- 피드백·고르기 결과를 저장할지와 보존 기간.
