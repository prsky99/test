# AgentValCon과 같거나 비슷한 서비스 비교 (2026-11-14, PM)

사용자 요청: "우리 서비스인 에이전트발콘 서비스와 동일하거나 유사한 서비스가 있는지 찾아서 비교해줘. 진정한 진주를 찾아서 새로운 가치의 진주 목걸이를 만들어서 서비스를 제공하는 것으로, 에이전트를 찾아서 에이전트를 연결한 새로운 에이전트 공급 서비스임."

- **조사 방법**
  - 하위 에이전트가 공개 웹 자료로 약 30개 서비스를 조사했습니다. 원자료와 출처 주소, 날짜는 `research.md`에 있습니다.
  - 가장 가까운 3곳은 PM이 공식 페이지에서 핵심 주장을 직접 확인했습니다. 아래 "직접 확인" 표시가 그것입니다.
  - 어디에도 가입·로그인·연락하지 않았습니다.
- **주의:** 수치 대부분은 각 회사가 스스로 밝힌 것입니다.

## 결론
- **찾기 → 시험 보고서로 검증 → 연결 → 대체 → 새 에이전트로 공급 → 매일 다시 시험**까지 전부 하는 서비스는 공개 자료에서 찾지 못했습니다.
- 두 단계를 합친 곳은 몇 곳 있지만, 세 단계를 넘게 잇는 곳은 없었습니다.
- 다만 각 단계는 다른 회사들이 빠르게 채우고 있습니다.
  - 검증은 SealKeeper·HOL·Arcade가 합니다.
  - 대체 실행은 Agoragentic이 합니다.
  - 묶어서 엔드포인트 하나로 내는 것은 n8n·MetaMCP가 합니다.
- 그래서 우리 차별점은 "전 과정을 한 곳에서 잇는 것"이고, **첫 목걸이 공개(11-21 목표)를 늦추지 않는 것**이 가장 중요합니다.

## 가장 가까운 서비스
| 서비스 | 겹치는 단계 | 우리와 다른 점 |
|---|---|---|
| **SealKeeper** (sealkeeper.run) — 가장 직접적 경쟁, 직접 확인 | 찾기, 검증, 상시 검사. 공개 에이전트(A2A·CLI)와 서비스(MCP·x402)를 스스로 찾아 검사합니다. 11-14 화면 기준 에이전트 4,805, 서비스 21,666, 오늘 검사 113,191입니다. 결과는 서명된 SEAL(bronze·silver·gold)로 냅니다. API, Python, LangChain, MCP, A2A, n8n으로 "부르기 전에 확인"하게 합니다 | 검증은 소유자가 CLI로 참여해 다른 운영자의 과제를 풀며 쌓는 평판입니다. 에이전트를 **묶어 새 에이전트로 공급하거나 대체하는 기능은 없습니다** |
| **Agoragentic** — 대체 기능이 가장 비슷함, 직접 확인 | 검증, 실행 중개, 대체. 모든 제공자를 샌드박스로 자동 검증하고, 신뢰 상태(verified·reachable·failed)를 실행 경로 선택에 씁니다. MCP·A2A·x402·REST를 쓰고, 판매자가 97%를 가져갑니다. 2026 1분기에 "Execute Router"를 냈습니다 | 단위는 "능력 하나에 제공자 하나"입니다. 여러 에이전트를 잇는 새 에이전트 공급이나, 단일 최고보다 나을 때만 공급하는 규칙(Δ>0)은 확인되지 않았습니다. 결제·정산이 중심입니다 |
| **HOL Registry Broker** (Hashgraph Online) | 찾기, 검증. 15개 레지스트리에서 약 10.4만 에이전트를 모읍니다(2026-03). 공개 신뢰 점수 HCS-25에는 가용성 확인, 정답이 있는 범용 시험, 쌍대 비교가 들어 있습니다 | 묶음·대체·공급이 없습니다 |
| **Glama** | 찾기, 등급, 헬스. MCP 약 16만 건에 TDQS 등급을 매깁니다 | 도구를 실제로 호출해 시험하지는 않습니다(방법론 문서 기준) |
| **Arcade.dev + Smithery**, 직접 확인 | 찾기, 등급. 2026-08-05에 Smithery를 인수했습니다. ToolBench로 MCP 서버 약 9만 개를 등급화합니다 | 기업용 도구 실행 런타임입니다. 제3자 에이전트를 묶어 공급하지는 않습니다 |
| **agentconcierge.io** (이름이 겹치는 곳) | 찾기, 추천. 7개 마켓의 에이전트 22,309개를 사람에게 추천합니다. "Swap Alerts"는 더 나은 에이전트가 나오면 알려 줍니다 | 사람용 추천과 유료 구독(Pro $11.11~)입니다. 점수 방법이 공개돼 있지 않고, 실행 묶음이 아닙니다 |

이 밖에 일부 단계만 겹치는 곳:
- Fetch.ai Agentverse + ASI:One: 에이전트 찾기와 대화 중개
- Virtuals ACP: 거래별 평가
- x402station·Decixa: x402 실측
- agentstatus·MCP Verified: MCP 실호출 감시
- n8n·MetaMCP: 여러 도구를 엔드포인트 하나로 묶음
- 빅테크 마켓(AWS, Google, Microsoft, Salesforce): 자기 생태계 안에서만 묶습니다

## 우리만 하는 것
1. 역할별 정답 세트로 시험하고 결과 보고서를 공개해, 역할마다 1위(최종 진주)를 뽑습니다.
2. 검증된 **제3자** 에이전트를 운영자가 직접 묶어 **새 에이전트(목걸이)로 공급**합니다.
3. 단일 최고 에이전트보다 나을 때(Δ>0)와 95% 관문을 통과했을 때만 공급합니다.
4. 자리마다 외부 대체 사슬을 두고 자체 대체까지 준비합니다. 모두 실패하면 정지·교체하고 공지합니다.
5. A2A·MCP·x402 세 가지를 약 39만 건 직접 수집하고 등급을 매깁니다.

| 분 단위 고빈도 감시 | SealKeeper, agentstatus | 목걸이 멤버는 매시간 감시합니다. 진주 전체로 넓히는 일은 공용 장부 상한 안에서 검토합니다 | 운영·SRE |

## 위험
- **Agoragentic:** 대체 실행과 정산을 이미 운영합니다. 여러 단계를 잇는 묶음을 더하면 가장 가까운 경쟁자가 됩니다. 첫 목걸이 공개가 늦어지면 차별점이 줄어듭니다.
- **SealKeeper:** 신뢰 확인을 LangChain·n8n·MCP 호스트 안으로 넣고 있습니다. 개발자가 "확인"을 SealKeeper에서 하고 우리를 거치지 않을 수 있습니다. 우리 강점은 확인이 아니라 "검증된 조합을 끝까지 실행해 주는 것"으로 알립니다.
- **이름:** agentconcierge.io가 같은 일을 하는 유료 서비스라, 도메인 이름 혼동 위험이 남습니다(브랜드 AgentValCon으로 바꾼 이유).
