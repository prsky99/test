2. **추천·검색 관련성** (Chat 1·2, Explore 3, 에이전트 접속 1)

## 개선된 작업
| 보고서 | 개선된 항목 |
|---|---|
| 사이트 전반 | **화면 전환:** 등록 → 문의 이동 시 등록 폼이 사라지고 뒤로 가기가 동작합니다. **링크:** 푸터가 `<a href>`로 바뀌었고, Terms 클릭 시 법률 문서 창이 열립니다(Terms·Privacy·Accessibility·Contact 탭). **폼:** 문의 화면의 첫 제출 버튼이 "Submit Inquiry"이고, 등록 화면에서 사설 주소를 넣으면 이유를 안내합니다. **404:** 디자인된 HTML 404입니다. **무게:** 첫 화면 요청 13건 242KB(이전 1.2MB), `pearl.webp` 18KB(이전 1,058KB), 로고 클릭 71ms(이전 4.6초 전체 새로고침). **메뉴:** 실제 링크입니다. **기타:** Workflows가 5초 안에 로드되고, 로그인 화면 콘솔 401이 없어졌고, 홈 검색이 Chat 화면으로 이동합니다. |
| 자율형 에이전트 접속 | sitemap 29개 모두 200, HEAD가 GET과 같은 상태, `call`·`adapt_rest`·`subscribe`에 위험 표시, MCP 도구 `outputSchema`, Origin 검사, 배치 요청 -32600 |
| 테스트 결과 보고서 품질 | MCP "The provider published no description" 문장 0건(표본 15), A2A 프로토콜 버전 모순 0건, `[Retired gateway reference]` 0건, 등급 표기 `A` 통일, 시험 방식 이름 정리(표본에서 4종) |
| 등록 기능 | **동의:** 서버 동의 검사(`agreed`·버전·10분 이내 시각). **등록 조건:** 에이전트가 아닌 사이트는 `PROTOCOL_NOT_CONFIRMED`로 거절하고, 조사 결과에서 지어낸 설명이 사라졌습니다. 자기 도메인은 `SELF_ENDPOINT`로 거절합니다. **허용 값:** 카테고리·음수 가격을 `allowed_values`와 함께 거절합니다. **오류 문구:** DNS 실패(`DNS_FAILED`)와 주소 속 자격 증명(`URL_CREDENTIALS`) 문구가 나뉘었습니다. **문의:** 제어 문자를 거절하고, 분류를 허용 목록으로 검사하고, 같은 문의를 하나로 묶습니다(`duplicate: true`). **개인정보:** 빈 요청을 거절합니다(422). |
| 결제 기능 | 공개 OpenAPI에서 내부 경로 제거(경로 186개 → 34개) |
| 워크스페이스 | 로그인 안 됨이 401 "Sign in to continue."로 통일, `?next=` 원래 주소 유지, "세션 만료" 문구 대신 일반 로그인 이동, 로그인 화면 콘솔 오류 없음, 공개 OpenAPI에서 고객 경로 제거 |
