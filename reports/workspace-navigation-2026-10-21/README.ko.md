# 워크스페이스 메뉴 및 로그인 피드백 수정

운영 Chrome에서 `/customer/organizations`의 Overview·Workflows 동시 활성화를 재현했습니다. 초기 두 메뉴가 같은 경로를 사용했고, 경로가 변경된 링크의 기존 활성 표시가 지워지지 않았습니다.

메뉴별 식별자를 추가하고 현재 페이지·해시를 기준으로 활성 항목 하나를 결정합니다. 모든 기존 표시를 지운 뒤 해당 메뉴에만 `aria-current="page"`를 부여합니다. 별도로 활성 표시를 추가하던 워크플로우 스크립트는 제거했습니다. Members·Account·Plan과 워크플로우 라이브러리·단일 작업 화면도 확인했습니다.

Google·GitHub 로그인 버튼은 클릭한 버튼 내부에 스피너와 진행 문구를 표시합니다. 중복 요청을 차단하며 오류 발생 시 원래 버튼으로 돌아와 재시도할 수 있습니다. 모바일·다크 테마·동작 줄이기도 검증했습니다.

브라우저 20개, 보안/API 71개로 고유 테스트 91개가 통과했습니다. Bandit 발견 0건, 공개 프론트엔드 콘텐츠 검사 237개 파일·위반 0건입니다. 추가 2회 메뉴 테스트 재실행은 증적 캡처 시 로딩 종료를 기다리도록 보완한 검증이며 고유 테스트 수에 중복 합산하지 않았습니다.
