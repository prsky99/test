# Public UX and recommendation remediation — 2026-10-20

중단 전 변경분과 `frontend-global-ux-ai-review-2026-10-20/README.md`를 PostgreSQL 전환 후 소스에 통합했다. 이번 범위는 실제 보고된 결함 수정과 격리 검증이다. 운영 서버 재시작·운영 DB 시험 데이터 삽입·공개 Workspace 링크 활성화는 하지 않았다. 새 Python 코드의 운영 반영 확인은 사용자 재시작 후 남아 있다.

## 적용 내용

- Chat: 후보의 관련성을 확인하기 전에 연결 버전을 만들던 DB 쓰기를 제거했다. PDF·송장·영수증 작업에 실제 문서 처리 설명을 요구해 JSON 단어만 있는 IAM/판매 후보를 배제한다. 기존 프로토콜·안전·실패 증거·최근 검증 우선순위를 유지한다.
- PostgreSQL: 후보 자원 조회를 바이트 제한이 있는 묶음 조회로 처리한다. Chat의 방문 기록 쓰기를 수집기와 별도의 최대 2개 세션으로 격리하고, 풀 대기는 350ms로 제한한다. 각 세션의 기존 트랜잭션·배포 권한·잠금 검사는 유지한다. 홈 지표는 기존 읽기 전용 네이티브 풀을 사용한다. SQLite용 격리 연결은 SQLite에서만 사용하며 PostgreSQL 실패 시 SQLite로 되돌아가지 않는다.
- Chat 화면: 8초 중단을 30초 단일 요청으로 변경하고 경과 시간을 표시한다. POST 자동 재시도는 하지 않으며 실패 시 질문을 보존한다. 서버의 혼잡 오류는 고정된 503 응답으로 반환하고 내부 연결 정보는 출력하지 않는다. 이는 30초 이내 성공이나 p95 5초를 보장하는 구현이 아니다.
- Test / Workflows: 원시 JSON을 기본 결과로 보여주는 대신 반환된 제목·출처 링크·게시일·조회 시각·관측값을 카드로 표시한다. 부분 결과 및 오래된 캐시 표시를 보존한다. 워크플로우는 완료 단계 수와 결과 다이제스트, 실제 경과 시간을 표시한다. 원문은 Request & response / Response details에서 계속 확인할 수 있다. 추가 모델 호출이나 생성된 사실을 사용하지 않는다.
- 화면: 모바일에서 홈 입력과 행동을 첫 화면에 배치하고 로고 간격을 수정했다. 결과·상태 배지는 라이트/다크 대비를 보완했다. 다른 메뉴 이동 시 스크롤을 초기화한다. Explore 요청은 전역 차단 화면 대신 기존 인라인 상태를 사용한다.
- 안내: AI 공시 링크와 이전 해시를 연결하고, 쿠키 거부 후 추가 확인 창을 제거했다. 시각 표시는 영어·UTC로 고정했다. 카테고리 내부 ID와 인증 구현 용어를 사용자 표현으로 바꾸고, 인증이 필요하거나 실행 연결이 없는 항목의 Test 버튼을 제한한다. 서버 측 실행 보안은 별도로 유지된다.
- 공식 연락처: 게시된 HTML에서 이메일을 edge 난독화가 치환하지 않도록 공식 mailbox 표시를 런타임에 복원한다. CSP에 Cloudflare 스크립트를 추가하거나 외부 스크립트 허용 범위를 넓히지 않았다. Cloudflare의 계정 설정은 변경하지 않았다.
- Workspace: 조직 접근 확인 후 멤버·초대·초안 조회를 병렬 처리한다. AI 제안은 명시된 뉴스·연구·제품 요구를 현재 승인 후보와 대조하며, 생성된 그래프도 다시 검사한다. 충족하지 못한 목표나 별도 요약 단계는 `needs_details`로 안내하고 검토 레코드·워크플로우를 저장하지 않는다. 사용자가 보는 안내에 크레딧이 사용되지 않았음을 명시한다. 이 검사는 명시적 작업군에 대한 보수적 검사이며 일반 자연어 의미 이해를 완성한 것은 아니다.

## 검증

- 고유 **334개 통과**, 최종 실패·skip 0. 중복 재실행은 합산하지 않았다. pytest 실행 루트 때문에 달라진 classname 접두어는 저장소의 같은 테스트 모듈로 정규화했다. 원본 XML은 보존했다.
- 동적 보안 검사 95개 포함: 공개 메뉴 CSP/XSS, 추천·토큰 경계, 게이트웨이 경계. API·브라우저는 격리 데이터와 통제된 응답을 사용했다.
- 네이티브 PostgreSQL 리허설 74개 하위 조건 통과. 2,005개 후보의 최근 검증 순위 유지, 수집기 Python 잠금이 잡힌 동안 별도 네이티브 세션 조회, 풀 한도 및 반환을 확인했다. 해당 합성 데이터의 네이티브+SQLite 조회 관측은 약 0.32초였으며 운영 응답 보장은 아니다.
- 자체 에이전트 6종과 공개 템플릿 3종의 로컬 직접 실행 회귀, Workspace 저장·크레딧·다운로드 실패 복구 회귀를 포함했다. 이번 작업에서 실제 고객의 크레딧은 사용하지 않았다.
- 공개 콘텐츠 **236개 파일, 위반 0**. embedded HTML과 `extracted_html.txt` 일치. JavaScript 구문·Ruff F/E9 통과. PostgreSQL SQL 카탈로그는 3,518개 문장·229개 테이블로 동기화하고 `--check` 통과.
- 저장소 경계 AST 점검은 278개 파일 완료, incomplete 0. 이 스캔은 정적 목록이며 모든 동적 SQL의 호환성을 증명하지 않는다.
- Bandit 경고 31개(높음 0)를 원문 보존했다. B608은 고정 SQL 조각/placeholder 조합 및 HTML 문자열, B108은 임시 경로를 구분하는 문자열 검사다. 기존 B110/B112 예외 흡수는 캐시·선택적 조회·정리 등의 실패 처리이며 이번 코드 변경으로 추가되지 않았다. 경고 0 또는 취약점이 전혀 없다고 주장하지 않는다.
- 임시 위치의 화면 캡처 검사에서 pytest 캐시 디렉터리를 만들 수 없다는 환경 경고 1건이 있었으며 기능 검사는 통과했다.
- 통합 실행에서 상태 문구 기대값 1건이 실패해 의도된 새 문구로 갱신 후 재통과했다. 앞선 중간 실행에서 발견된 메뉴 기본 경로 생성 충돌도 수정 후 9개 진입 화면을 통과했다.

## 운영 반영 및 범위

1. 사용자 터미널에서 기존 서버를 최신 코드로 한 번 재시작한다. 새 네이티브 세션 풀은 시작 시 구성되므로 브라우저 새로고침만으로 반영되지 않는다.
2. 브라우저 강력 새로고침 후 Chat의 PDF 송장/날씨/주식 질문과 Test 4개·Workflows 3개를 운영 환경에서 확인한다. 실제 응답 지연과 외부 원천 가용성은 이 단계에서 판단한다. 이번 보고서는 수정 후 운영 성공을 미리 선언하지 않는다.
3. 공개 이메일이 정상인지 edge 응답에서도 확인한다. Cloudflare Web Analytics 주입 설정은 이번에 변경하지 않았다. CSP는 유지한다.

검토 문서의 SSE, 통합 Ask/명령창, 의미 재순위, 일반 목적 계획기·새 요약 계약, 라이브러리 확장, 주간 큐레이션은 별도 제품 확장 제안이다. 현재 결함 검증의 완료 조건에 자동으로 계속 추가하지 않는다. 실제 사용 가능한 뉴스 계약이나 요약 단계를 새로 승인한 것처럼 처리하지 않았다. Workspace 공개 여부, 보류된 외부 구독 로그인/과금 기능은 변경하지 않았다.
