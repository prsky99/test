# 두 번째 재점검

이 문서는 수정 전 이력이다. 이후 소스 수정과 B2A 격리 검증을 진행했으며 최신 상태는 [수정 보고서](../../b2a-retention-remediation-2026-10-25/README.md)를 참고한다.

2026-10-25. 제품 소스와 서버 설정은 변경하지 않았다.

## 결론

**운영 반영은 정상이지만 기존 설계 결함은 해결되지 않았다.** 지난 점검 이후 추적한 소스·화면 파일의 변경이 없고, 배포된 frontend/admin의 핵심 7개 모듈도 현재 작업공간과 모두 일치한다. 서로 다른 릴리스 ID 자체를 오류로 판단하지 않았으며 이번 범위의 파일 내용을 비교했다.

- 설계 적합성 검사 재실행: **23건 중 6건 통과, 17건 실패**, 종료 코드 1. 앞선 실패 조건과 동일하다.
- 스킬 두 경로·entry·없는 리소스의 배지: 로컬과 공개 주소에서 모두 정상 200. `/skill.md` 조건부 GET은 양쪽 모두 304.
- 합성 방문자의 실제 채팅: 200, 약 **1.10초**, **A2A 3개**, 추천 주소 모두 게이트웨이.
- 인증된 resume: 200. 공개 약한 ETag를 그대로 재사용한 요청은 **동일한 본문인데도 200**으로 반환돼 앞서 확인한 조건부 응답 문제가 지속된다.
- 실제 고객 계정·제공자 호출·워크플로우 실행·결제는 사용하지 않았으며 방문자 토큰은 파일에 남기지 않았다.
- 화면·콘텐츠 파일이 동일하므로 기존 브라우저 27건·콘텐츠 267파일 검사 증거를 재사용했다. 이를 이번에 다시 실행했다고 집계하지 않는다.

남은 핵심 문제는 배지의 최신 증거 판정, 후속 추천 안전·프로토콜 필터, 계약 변경 시 ETag 무효화, 선택적 프리페치의 500 전파, 실패 복구 후보의 프로토콜·장애 독립성, 누락된 머신 응답 계약이다. 재시작보다 기존 보고서의 우선순위에 따른 소스 수정이 필요하다.
