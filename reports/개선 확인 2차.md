## 새로 생긴 문제(회귀)
1. **Chat이 영어가 아닌 질문 일부를 돌려보냅니다.**
   - 다음 3개에 "Your task is kept. Please restate it briefly in English; language normalization is unavailable."가 나왔습니다.
     - 東京の明日の天気を知りたい
     - Necesito traducir un documento al inglés
     - 주식 시세 조회할 수 있는 무료 API 있어?
   - 지난번에는 스페인어 번역 요청에 DePunks TRANSLATOR를 추천했습니다.
   - 한국어 서울 날씨·계약서 번역은 동작합니다.
   - "language normalization is unavailable"라는 문구로 보아, 번역(정규화) 기능이 꺼져 있거나 실패한 것으로 보입니다.
2. **Chat이 느려졌습니다.**
   - 화면 중앙값 4.9 → 5.7초, 최대 6.6 → 10.5초
   - 서버 응답 중앙값 2.1 → 3.2초, 최대 3.8 → 7.5초
   - 질문 처리(되묻기, 의도 나누기, 안전 검사)가 늘어난 영향으로 보입니다.
3. **Explore 체크박스 필터가 바로 재검색하지 않습니다.**
   - "Verified"와 "No auth"를 눌러도 3초 안에 요청이 0건입니다.
   - 세 번째 "Has report"를 누르자 세 조건이 한꺼번에 반영된 요청 1건이 나갔습니다.
   - 프로토콜 선택은 바로 재검색합니다. 지난번에는 체크박스도 바로 재검색했습니다.
4. **카드에 새 라벨 "Data-Analytics"가 보입니다.** 필터 목록에 없는 이름입니다(필터는 "Databases & Analytics" 계열).

  - 느린 검색어: `'; DROP TABLE agents;--` 8.0초, `weather forecast seoul` 7.3초, `주식 시세` 6.5초, `wether` 5.6초
  - 같은 검색을 다시 해도 빨라지지 않습니다(캐시 없음).
- **Chat:** 같은 질문을 2.5초 간격으로 다시 보냈더니 2회차는 모두 429였습니다. 앞선 시험 요청과 같은 분 안에 겹친 영향일 수 있습니다. 그래서 캐시 효과는 확인하지 못했습니다.
