## 높음
1. **`Recorded reports` 필터가 항상 500** (Explore)
   - `GET /api/explore?has_report=true&q=…` → 어떤 검색어든 500.
   - 원인: 보고서 필터 경로의 카드 생성(`front.py _report_filtered_explore → _card_data → public_agent`)이 연결 버전을 만들려고 `connection_agents`에 INSERT하다가 `ApplicationStoreError: statement_failed`. 다른 경로(`selection.py`)는 `create_connections=False`로 부름.
2. **`Execution checked` 필터가 실행 확인된 에이전트를 빠뜨림**
   - `weather` + `verified=true` → 0건. 그런데 같은 검색 결과에 "Execution checked" 칩이 붙은 Japan Weather Forecast MCP(`verified_callable: true`)가 있음.
   - 화면은 3초 넘게 "Finding agents…"를 보이다 0건으로 바뀜.
3. **x402 프로토콜 검색이 모두 0건**
   - `kind=x402`로 weather·price·crypto·translate·search·news 모두 0건. 빈 검색은 116,104건.
   - 반면 MCP `find_agents`(kind=x402)는 x402 후보를 돌려줌 → Explore x402 탭만 고장.
4. **x402 1순위 추천이 503** (시나리오 FAIL 2건의 원인)
   - `find_agents` "stock price quote" 1위 163013(카탈로그 healthy·active·live)이 게이트웨이에서 503 "The approved execution is unavailable".
   - 2·3위(31865, 83073)는 정상 402. 실행 불가 후보를 1위로 추천함.
5. **Chat 추천 관련성 회귀·누락**
   - `send an email` 1위 Sats4AI(도구 40개 모음), 전용 메일 서비스가 뒤로 밀림(12차 mifactory-email).
   - `summarize a PDF` → Aspicio(DXF·PDF 도면 도구). Faceabot PDF text extractor가 있음.
   - `convert USD to EUR` → JiZhiMCP, Evlek(북키프로스 부동산)이 1·2위, FXHUB는 3위.
   - `book a flight from Seoul to Tokyo` → HotelsCasa(호텔). Explore에는 Flight Search가 있음.
   - `review my github pull request` → "No currently active, relevant agent found". Explore에는 "GitHub Issues and Pull Requests"가 있음.
   - `create a QR code` → 1위 Pro UPI QR(인도 UPI 결제 QR).
   - `get the current bitcoin price` → cryptoetf·StockMap·Galaxy Mind(가격 전용 아님).
6. **Explore 검색 속도 회귀**: 중앙값 0.67 → 1.89초, 최대 10.73초(`code review`), 4초 넘는 것 `database` 4.69초, `maps` 3.9초, `wallet balance` 3.88초, `sports scores` 3.92초. 카테고리 필터 검색 4.3초.

## 중간
7. **Explore 결과 수가 화면·API마다 다름**
   - `weather`: limit 3 → total 10, limit 10 → 24, limit 45 → 47, limit 100 → 49. 화면은 "45+ matches", 더 보기 버튼은 "45 / up to 51".
   - 오타 검색 화면 제목이 교정 전 단어(`"translte" Search Results`).
8. **검색 결과 꼬리의 무관한 항목**
   - `translate` 결과에 커피 그라인더(io.brewmark), B2B 포지셔닝(impact-mcp), 대학 진학(CounselorAI), 이란 날짜(FarsiTools), 회사 검증(tolca)이 섞임.
   - `slack` → 증명사진·프로젝트 플래너, `url shortener` → OFAC 검사 1건, `dns lookup` 1위 Ops Control HQ, `vulnerability` 1위 AgentDiet, `database` 1위 "Database"(분류 communication), `blockchain explorer` 0건.
   - 검증용 조각처럼 보이는 항목이 진짜 결과로 나옴: "GitHub topic slug charset, value discarded", "arXiv id version shape", "Whether a zone name looks…"(모두 travel_maps_weather).
9. **카테고리 오분류(화면에 그대로 보임)**
   - Tarteel(Quran) → Travel/Weather, HebrewCore → Healthcare, India API → Network Ops, Pauhu EU Data → Developer Tools, agentsvc.io·AgentForge → Finance, DePunks TRANSLATOR → Other, InvoiceGuard·APIShield WAF → Public/Legal, Agent Weather → Finance.
10. **같은 이름 카드 구분 불가**: "Weather"(2개), "GitHub"/"Github", "Branch and fan-in test"(워크스페이스 2개). 호스트나 차이점이 카드에 없음.
11. **상세 창 문구**
    - "TEST Recorded report" 배지(TEST가 무엇인지 설명 없음), "source: registry" 원문 키.
    - "Connection available; current verification pending"이 두 줄에 반복, "Connection check only; no task execution verified"도 두 번.
    - QUALITY SCORE "Grade B" 아래 "Not recorded"가 같이 나옴.
    - "Translate" 상세의 보고서 도구가 `ask_pipeworx`, 도구 47개 → 이름과 실제 서버가 다름.
    - 상세를 열어도 주소(해시)가 바뀌지 않아 공유·새로고침 불가.
12. **카드가 링크가 아님**: `div role=button`이라 새 탭 열기·주소 복사가 안 됨. 카드 아래 "Recorded report"가 두 번 보임(칩+액션 줄).
13. **A2A 후속 요청이 맥락을 잃음**: 같은 `contextId`로 "only free ones without an API key"를 보내면 "What should the agent do?"로 되물음.

15. **x402 상태 코드가 들쭉날쭉**: 108808은 헤더 없이 403, 깨진 `X-PAYMENT`에는 400 "The registered agent is unavailable"(HTTP_400). 122024도 403(카탈로그 historical).
16. **Chat 안내**: `what can you do?`에 기능 소개 없이 "What should the agent do?"만. `asdfgh`에 "No currently active, relevant agent found"(입력을 이해 못 했다는 안내가 아님).
17. **크롤러용 본문**: `/new/en/*.html` 8개가 약 4,070단어로 거의 같고, 모든 페이지 첫 h1이 홈 문구("Individual strengths…"). h1이 여러 개. `explore.html`에 `Accept: text/markdown`을 보내면 HTML.

26. **요금 문구 불일치**: "New accounts receive 100 credits once"인데 잔액 99,976 credits. 출처(시험 지급 등) 설명이 없음.
27. **Provider connections 화면이 비어 있음**: 설명 문단만 있고 연결 목록·추가 버튼이 없음(소유자 계정).
28. **상태 문장**: "Your plan and credit history are current.", "Your support information is current."처럼 의미 없는 문장이 화면 위에 있음. 워크플로 카드에 마지막 실행 상태·연도·시간대가 없음.
