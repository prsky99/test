## 1. Show HN

**Title:** Show HN: Agent Concierge – find MCP servers and A2A agents that passed a recorded check

**Body:**

I built a directory that collects public A2A agents, MCP servers and x402 APIs (about 258k listings today) and keeps checking them, so you can ask for an agent by task and see why it was suggested.

Most listings in public catalogs are never checked. Here every listing gets a recorded health check; where it is safe, read-only tools get a trial call, and some get a full execution check against the published tools. Recommendations only use agents whose latest check succeeded, and each answer shows the check type and date. A check says what happened when it ran, not that the agent works now.

You can use it three ways:
- Remote MCP server: `claude mcp add --transport http agent-concierge https://agentconcierge.biz/mcp` (settings for Cursor, VS Code and the OpenAI Agents SDK: https://agentconcierge.biz/connect)
- Task pages with the evidence for each agent: https://agentconcierge.biz/agents/tasks
- Chat on the site: https://agentconcierge.biz/new/en/chat.html

Things that are not good yet: most of the 258k listings have only a reachability check, task matching is keyword-heavy for unusual tasks, and the site is served from one region, so it is slow from far away.

I would like to hear which tasks you could not find an agent for, and what evidence would make you trust a suggestion.

## 2. Reddit r/mcp

**Title:** A remote MCP server that recommends other MCP servers, with the check history behind each pick

**Body:**

Hi r/mcp — I run Agent Concierge, a catalog of public MCP servers and A2A agents that keeps a check history for each listing (health check, trial call on read-only tools, and execution checks where possible).

It is itself a remote MCP server (streamable HTTP, no sign-in for search):

```
claude mcp add --transport http agent-concierge https://agentconcierge.biz/mcp
```

Ask it something like "find an MCP server for Japanese weather forecasts" and it returns up to three candidates ranked by the latest successful check, recent activity and a quality grade, with the dates. Setup for Cursor, VS Code and the OpenAI Agents SDK: https://agentconcierge.biz/connect

Per-task pages if you just want to browse: https://agentconcierge.biz/agents/tasks

If you maintain an MCP server and your listing looks wrong or out of date, tell me and I will fix the record. Feedback on the evidence format is very welcome.

(I am the developer.)

## 4. GitHub README (공개 소개용 저장소 첫 부분)

현재 공개 저장소 이름은 `prsky99/test`라 소개용으로 쓰기 어렵다. 소개 전용 저장소(예: `agent-concierge`)를 만들지는 사용자 결정 사항이다. 아래는 그 README 첫 부분 초안이다.

```markdown
# Agent Concierge

Find AI agents by task — with the check history behind each suggestion.

Agent Concierge collects public A2A agents, MCP servers and x402 APIs and keeps checking them:
health checks for every listing, trial calls on read-only tools where safe, and execution checks
against published tools. Suggestions use only agents whose latest check succeeded, and every
answer shows which check ran and when. A check records what happened when it ran; it does not
guarantee that an agent works now.

## Connect

| Client | Setup |
|---|---|
| Claude Code | `claude mcp add --transport http agent-concierge https://agentconcierge.biz/mcp` |
| Claude Desktop / claude.ai | Settings → Connectors → Add custom connector → `https://agentconcierge.biz/mcp` |
| Cursor, VS Code, OpenAI Agents SDK | https://agentconcierge.biz/connect |
| A2A | Agent Card: https://agentconcierge.biz/.well-known/agent-card.json |
| REST | `GET https://agentconcierge.biz/api/explore?q=weather+forecast` |

## Browse

- Agents by task, with evidence: https://agentconcierge.biz/agents/tasks
- Explore the full catalog: https://agentconcierge.biz/new/en/explore.html
- Service status: https://agentconcierge.biz/status.json

## Listing your agent

Submit a public endpoint at https://agentconcierge.biz/new/en/list-agent.html. Checks are read-only.
```
