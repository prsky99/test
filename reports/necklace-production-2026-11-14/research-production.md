# 생산 공정 근거: 논문·실측 조사 (워크플로우 팀 11-14, 하위 조사 결과 정리)

표기: [심사] 학회·저널, [프리프린트] 심사 전, [블로그] 실측 글, (2차) 2차 요약으로만 확인.
전략 문서 2-5절에 이미 있는 근거(AFlow, ADAS, MaAS, AgentSquare, MASS, Self-MoA, Graph RAG-Tool Fusion, MAST, Google·MIT 2512.08296, ACL 2024, WorfBench, MCP-Bench, MCPTox)는 반복하지 않았습니다.

## 1. 정답 세트·평가
- 작은 표본에 CLT 구간을 쓰면 불확실성을 크게 과소평가합니다. Wilson·Clopper-Pearson·베이즈 구간을 씁니다. [심사, ICML 2025] https://arxiv.org/abs/2503.01747
- 두 시스템은 같은 문항으로 짝지어 비교하고(분산 감소), 시작 전에 검정력을 계산합니다. [프리프린트] https://arxiv.org/abs/2411.00640
- τ-bench pass^k: gpt-4o 성공률 50% 미만, 소매 pass^8 25% 미만. 한 번 성공은 믿을 수 없습니다. [심사, ICLR 2025] https://arxiv.org/abs/2406.12045
- 평가 설계 결함은 성능을 상대값으로 최대 100% 부풀리거나 줄입니다. 점검표를 적용하자 CVE-Bench 과대평가가 33% 줄었습니다. [프리프린트] https://arxiv.org/abs/2507.02825
- 홀드아웃이 없거나 부족하면 과적합됩니다. 정확도와 비용을 함께 보고합니다. [프리프린트] https://arxiv.org/abs/2407.01502
- LLM 심판(GPT-4)과 사람의 일치율은 80% 이상입니다. 위치·장황함·자기 선호 편향이 있습니다. [심사, NeurIPS 2023] https://arxiv.org/abs/2306.05685
- 운영 중 회귀 시험: 고정 횟수로 10% 회귀를 잡으려면 약 100회가 듭니다. 순차검정을 쓰면 시행이 78% 줄어듭니다. [프리프린트, 저자 1인] https://arxiv.org/abs/2603.02601

## 2. 믿기 어려운 외부 도구
- 레지스트리에서 무작위로 고른 MCP 서버 400개 중 48.8%만 handshake를 마쳤습니다(손으로 고른 표본은 66.7%). 안전 주석이 빠진 도구는 58.8%였습니다. [프리프린트] https://arxiv.org/abs/2609.10962
- 6개 마켓 17,630개 항목 중 절반 넘게가 무효이거나 가치가 낮았습니다. [프리프린트] https://arxiv.org/abs/2509.25292
- 도구 계약은 36시간 안에 4.4%가 입력 스키마를 바꿨고, 14일 동안에는 엔드포인트 기준 39.2%가 바뀌었습니다. [블로그] https://dev.to/theopslog/44-of-mcp-servers-changed-their-tool-contract-in-36-hours-i3m
- ToolBench 온라인 도구의 약 55.6%가 불안정해 결과가 재현되지 않았습니다. (2차) https://arxiv.org/abs/2403.07714
- 결함 에이전트가 섞였을 때 계층 구조는 성능이 5.5%만 떨어졌습니다. 검사 단계(Inspector)를 두면 오류를 최대 96.4% 복구했습니다. [프리프린트] https://arxiv.org/abs/2408.00989
- 헤징: p95가 지나면 다시 보내는 방식으로 p99.9가 1,800ms에서 74ms로 줄었고, 추가 요청은 2%였습니다. [심사, CACM 2013] (2차) https://research.google/pubs/pub40801/

## 3. 여러 출처 합성
- 표본 투표는 에이전트 수에 따라 성능이 오릅니다. 15개를 모으면 13B 모델이 70B 수준이 됩니다. [심사, TMLR 2024] https://arxiv.org/abs/2402.05120
- MoA는 AlpacaEval 2.0 길이 보정 승률 65.1%로 GPT-4o 57.5%보다 높았습니다. 다만 개방형 선호 평가이고 사실 과제가 아닙니다. [심사, ICLR 2025] https://arxiv.org/abs/2406.04692
- 출처 충돌 458개 질의 분류: 오래된 정보가 원인이면 최신을 따르고, 의견 차이면 여러 견해를 함께 보여 줍니다. [프리프린트] https://arxiv.org/abs/2506.08500
- MADAM-RAG(출처별 토론): 모호한 질의에서 최대 +11.40%, 잘못된 정보 거르기에서 최대 +15.80%p였습니다. [심사, COLM 2025] https://arxiv.org/abs/2504.13079
- 시사점: 사실·수치 칸은 결정적 규칙(다수결, 최신 우선, 출처 신뢰도)으로 합칩니다. LLM 합성은 개방형 문장 칸에만 씁니다.

## 4. 외부 도구 조합의 보안
- AgentDojo: 방어가 없을 때 표적 공격 성공률 57.7%, Tool filter(과제마다 도구 고정)로는 6.8%(유용성 73.1%). https://arxiv.org/abs/2406.13352
- InjecAgent: GPT-4 ReAct 24%, 해킹 문구를 붙이면 47%. [심사, ACL 2024 Findings] https://arxiv.org/abs/2403.02691
- Spotlighting(외부 데이터 표시·인코딩): 공격 성공률 50% 초과 → 2% 미만. [프리프린트] https://arxiv.org/abs/2403.14720
- CaMeL: 제어 흐름은 신뢰 질의로만 만들고 도구 출력은 데이터로만 다룹니다. AgentDojo 77%를 보안을 증명하며 풀었습니다(방어 없이 84%). [프리프린트] https://arxiv.org/abs/2503.18813
- MCP 서버 1,899개: 일반 취약점 7.2%, tool poisoning 5.5%. [프리프린트] https://arxiv.org/abs/2506.13538
- 도구 정의 서명·버전 고정(ETDI). 클라이언트 7개 중 5개가 정의 검증이 부족했습니다. https://arxiv.org/abs/2506.01333, https://arxiv.org/abs/2603.22489
- 우리 구조와의 관계: 목걸이는 정의 파일이 자리마다 도구를 고정하고(Tool filter), 합성은 결정적 규칙이라 도구 출력이 제어 흐름을 바꾸지 못합니다(CaMeL의 데이터 취급). 그래도 출력 주입 시험을 관문에 둡니다.

## 5. 카탈로그에서 워크플로우 자동 생성 (알려진 목록 밖)
- FlowScout(그래프 탐색, 실행 피드백): AFlow 등보다 도구 호출 정확성 최소 +92.69%, 실행 품질 최소 +17.66%. [프리프린트, 2026-08] https://arxiv.org/abs/2608.10039
- MermaidFlow(정적 검증 가능한 그래프 + 진화 탐색) https://arxiv.org/abs/2505.22967
- FlowReasoner(질의별 워크플로우 메타 에이전트): o1-mini 대비 +10.52%. [프리프린트] https://arxiv.org/abs/2504.15257
- ToolChain*(A*): +3.1%·+3.5%, 시간은 1/7.35·1/2.31. https://arxiv.org/abs/2310.13227
- 통과한 워크플로우 하나당 후보를 몇 개 평가했는지는 초록에서 찾지 못했습니다. 우리 공정이 후보 수와 통과율을 직접 기록합니다.
