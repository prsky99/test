사용자 요청: "우리 서비스에 대한 SWAT 분석을 논문과 SNS검색을 통해 진행해줘."

근거: 내부 지표(11-14 기준), 논문 조사(arXiv·학회 2024~2026), 시장·SNS 조사(공식 발표, HN, DEV, 업계 자료).
- 외부 수치는 측정 주체마다 다릅니다. 판매사가 직접 낸 수치는 신뢰도가 낮습니다.

## S. 강점

1. **"실제로 되는지"를 재서 추천합니다.**
   - 우리는 헬스체크, 시험 호출, 품질 등급, 실제 과제 채점(24/30)을 합니다.
   - 공개 MCP 목록의 절반 이상이 무효하거나 가치가 낮습니다. 유효 8,401/17,630, MCP.so 검증 통과 43.4%입니다(Measurement Study of MCP Ecosystem, arXiv 2509.25292).
   - 원격 서버의 핸드셰이크 성공은 55%뿐입니다(Digital Applied, 2026-11-05).
   - 이런 시장에서 걸러 주는 일 자체가 가치입니다.
2. **검색 품질이 에이전트 성공을 좌우한다는 근거와 맞습니다.**
   - 도구 검색 최고 모델도 nDCG@10이 33.83입니다(ToolRet, ACL 2025 Findings).
   - 미리 골라 주면 선택 정확도가 13.6%에서 43.1%로 오릅니다(RAG-MCP, arXiv 2505.03275).
   - 실제 MCP 서버에서는 최신 모델도 절반 넘게 실패합니다(MCP-Universe 43.7%, LiveMCPBench v2 30~50%).
3. **프로토콜 셋을 한곳에서 다룹니다.**
   - A2A 39만 개 규모, MCP, x402(연결 확인만)를 다룹니다. 에이전트 395,451개 중 연결 가능 307,211개입니다.
   - A2A 명세에는 레지스트리 API가 없고, A2A 디렉터리는 400개 수준입니다. 경쟁이 적은 쪽을 이미 덮고 있습니다.
4. **추천에서 실행까지 이어집니다.**
   - 읽기 전용 중계 게이트웨이와 엣지 Worker가 있습니다. 실행 도구 차단, 결제 금지, 원인 코드를 갖췄습니다.
   - A2A 대화 안에서 바로 실행하는 기능은 보안 검토를 통과했고 배포 대기 중입니다.
5. **외부 신뢰 신호를 얻었습니다.**
   - 공식 MCP Registry에 게시했습니다.
   - Glama에 자동 등재됐습니다(Healthy, 24시간 가동 100%, TDQS A 3.6/5).
   - mcpservers.org는 심사 중입니다.
6. **비용 구조가 가볍습니다.** 지출 0이고, 무료 플랜과 로컬 모델(맥미니)을 씁니다. 버티는 힘이 큽니다.

## W. 약점

1. **외부 이용이 거의 없습니다.**
   - 사람 방문자는 49명에서 27명으로 줄었습니다(11-09~11-13).
   - 외부 실행 성공(북극성)은 하루 0~2건입니다.
   - 접속 대부분은 디렉터리 점검 봇입니다.
   - 구글 "agent concierge" 검색은 평균 11위로 1쪽 밖입니다.
2. **속도가 목표에 못 미칩니다.**
   - 차선 목표(3/5/3초) 회차 통과율은 16%이고, 최종 목표는 0%입니다.
   - 추천 서버 시간 중앙값이 2~4초입니다.
   - 한국↔미국 엣지 경로가 1~2초를 더합니다(무료 플랜).
3. **수집 목록이 희석돼 있습니다.**
   - 한 호스트가 21만 개를 등록했고, 중복과 얇은 설명이 있습니다.
   - 도구 설명의 97.1%에 결함이 있고(MCP Tool Descriptions Are Smelly, arXiv 2602.14878), 결함이 선택 정확도를 8~12% 떨어뜨립니다(arXiv 2602.18914).
   - 자동 생성 페이지 약 1만 쪽이 사이트 품질 신호를 낮춘 것으로 판단해 검색 제외를 진행 중입니다.
4. **평가에 한계가 있습니다.**
   - Chat 정답 비교(92/110)와 채점은 자동 판정을 씁니다. LLM 판정과 사람의 일치율은 약 81%입니다(LiveMCPBench v1). 판정기 오차를 밝혀야 합니다.
   - 키 없는 시험이라, 인증이 필요한 서버 33.8%(Digital Applied)는 깊이 검증하지 못합니다.
5. **운영 자원이 작습니다.**
   - 1인 운영이고, 맥 1대가 운영 서버를 겸합니다. 시험과 리허설이 겹치면 응답 시간이 2~3배가 됩니다.
   - 수익은 0이고, 광고 상품(USDC)은 안정성 관문 뒤로 미뤘습니다.

## O. 기회

1. **독립 디렉터리 공백**
   - Smithery는 Arcade에 인수된 뒤 2026-10-31 중계를 닫았습니다.
   - PulseMCP는 2026-09-03부터 등록을 멈췄습니다.
   - "실제로 되는지 증명하는 곳"이 비었습니다.
2. **기업 허용 목록에 넣을 검증 데이터**
   - GitHub(2026-08-06 기업 허용 목록), Google Agent Registry(2026-04), AWS Agent Registry(미리보기), Windows Agent Registry가 있습니다.
   - 모두 승인을 사람이 합니다. 그 판단에 쓸 헬스·인증·변경 기록을 API와 JSON으로 줄 수 있습니다.
3. **rug pull·변조 감시 데이터**
   - 근거: CSA 보고서(2026-05-04, 2026-08-30 Deadbugz), MCPTox 공격 성공 72.8%, postmark-mcp 백도어(약 300개 조직)
   - 도구 정의 지문과 변경 이력은 오래 쌓을수록 늦게 온 경쟁자가 따라오기 어렵습니다.
4. **A2A 발견층 선점과 표준 구현**
   - A2A 지지 조직은 150곳이 넘고, 서명된 Agent Card가 v1.0에 들어갔습니다.
   - 로드맵에 "레지스트리 통합"이 있습니다.
   - 표준대로 읽히는 Agent Card를 내는 곳은 65곳 중 10곳뿐입니다(API Evangelist, 2026-07).
   - Google·Microsoft 등이 낸 ARD 명세 초안(2026-06, ai-catalog.json과 /search API)을 일찍 구현할 수 있습니다.
5. **에이전트 경제의 품질 공백**
   - Coinbase Agentic.Market(2026-04)은 승인과 품질 등급이 없습니다.
   - x402 실제 상업 거래는 하루 약 2.8만 달러로 작지만 커지는 중입니다.
   - Gartner는 2026년 기업 앱 40%에 작업별 에이전트가 들어간다고 봅니다.

## T. 위협

1. **Glama와 정면으로 겹칩니다.** Glama는 11만 개 목록, 주기적 헬스체크, TDQS 점수, 유료 게이트웨이($9~80/월)를 갖췄습니다.
2. **신뢰 점수가 흔해집니다.**
   - CraftedTrust, SpiderRating, mcp-uptime 등 무료 점수 서비스가 5개를 넘습니다.
   - 관심도 낮습니다. "1/6이 죽었다" 같은 HN 글이 2점입니다.
   - 문제의식은 넓지만 돈을 낼 신호는 약합니다.
3. **플랫폼 내장 검색과 심사 디렉터리**
   - Anthropic Tool Search(2025-11)와 OpenAI tool_search가 "고른 도구 안에서 고르기"를 모델 안으로 가져갔습니다.
   - "무엇을 설치할지"는 ChatGPT 앱 디렉터리(2025-12), Claude 커넥터 디렉터리, 기업 허용 목록이 맡습니다.
4. **악성·변조 서버를 추천하는 책임**
   - 시간차로 악성으로 바뀌는 서버(Deadbugz)는 한 번 시험해서는 못 잡습니다.
   - 레지스트리 오염이 있습니다(탈취 가능 212개와 304개, Li & Gao arXiv 2510.16558).
   - 중계된 도구 출력이 프롬프트 인젝션 경로가 될 수 있습니다(AgentDojo, InjecAgent).
   - 39만 개를 추천하는 우리에게 평판 위험입니다.
5. **수익 모델이 약합니다.**
   - 자금이 있는 Smithery도 중계를 접었습니다.
   - x402 실제 거래는 5% 미만입니다.
   - 결제 표준이 x402 Foundation과 AP2(FIDO 이관)로 갈렸습니다.
   - x402 자체에 대한 공격 5가지가 실제로 가능했습니다("Five Attacks on x402", arXiv 2605.11781). USDC 결제를 켜기 전에 검토해야 합니다.
