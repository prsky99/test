# 모델 품질·동시성 개선 결과

2026-10-23 · 소스 수정·격리 검증 및 사용자 재시작 후 운영 반영 확인 완료

워크플로우 구성 오류, 도움말 오류와 동시 요청 거절 문제를 수정했습니다. 운영 프로세스는 재시작하지 않았으며 고객 데이터·설정을 변경하지 않았습니다.

## 구현한 변경

- 워크플로우: 지원되는 문서·뉴스 목표에서 종류, 순서, 명시한 2~10단계 수를 서버 규칙으로 확정합니다. 문서 전용 목표에는 뉴스 후보를 제외하고, 부정한 요청 문구를 요구사항으로 잘못 추가하지 않습니다. 단계별 구성이나 순서가 불명확하면 추가 설명을 요청합니다.
- 모델은 명확한 목표에서 짧은 영어 검색어만 생성합니다. 기술명 등 검색 주제를 유지하는지 검사하고, 서버가 현재 승인된 후보와 검증된 연결 구조를 조합합니다. 같은 종류가 반복되면 승인 후보의 기존 순서를 유지하면서 가능한 한 서로 다른 후보를 사용합니다. 생성된 그래프도 목표와 다시 대조합니다. 이것은 모델 자체의 추론 능력 향상 주장이 아니라 서비스 구조와 검증 개선입니다.
- 승인된 전체 그래프를 반환하는 기존 경로에도 에이전트 종류·순서·단계 수·첫 검색 주제 검사를 적용합니다. 승인되지 않은 도구나 리소스를 허용하지 않습니다.
- 도움말: 저장/실행 분리, 변경 검토, 결과 불확실성, 목적지 검증, 지원되는 검색 워크플로우 작성법은 검토된 공개 문서로 직접 응답합니다. 모델 생성이라고 표시하지 않으며 기존 세션·권한·컨텍스트 검사를 유지합니다.
- 일반 사용자 정의 생성은 관련 문서를 선별해 전달하고 필수 answer/documents/changes 스키마, 중복·허용 문서 검사를 강제합니다. 두 문장·256토큰으로 요청을 줄이고 최대 대기 20초와 기존 동시 제한 2개를 유지합니다. 결과는 계속 미검증 안내이며 변경은 별도 제안·적용 동의가 필요합니다.
- 공개 워크플로우 작성 안내를 보완하고 과거 비공개 상태를 설명하던 문장을 현재 동작에 맞게 수정했습니다. 관리 화면에서 문서 기반 응답과 모델 응답을 구분합니다.
- 워크플로우 생성은 프로세스별 동시 실행 4개, 실행·대기를 합한 수용 16개로 제한합니다. 대기는 기존 전체 60초 예산에 포함하고 시작/응답 후 권한을 재확인합니다. 대기 중 시간 초과 요청은 로컬 취소하며, 이미 전송된 원격 요청을 취소했다고 주장하지 않습니다. 완료 전 실제 실행 슬롯도 반환하지 않습니다.

- 실제 격리 AppFactory 16개 동시: 완료 2/16 → 16/16, 실제 모델 요청 최대 4개, 완료 p95 4.383초·최대 4.3865초. 승인 대기 한도 16개를 넘는 요청의 거절과 대기 중 권한 변경 차단도 별도 검사했습니다.
- 네 가지 기존 도움말 시나리오 8건: 품질 기준 1/8 → 8/8. 16개 동시 문서 안내도 16/16 통과, p95 0.022초, 모델 호출 0회. 실제 생성 없이 근거 문서를 반환하는 경로이므로 모델 성능 수치로 해석하면 안 됩니다.

## 운영 반영

사용자의 `agentcon restart`로 프론트엔드와 어드민 모두 `web-20261023-154509-8d78` 릴리스로 교체됐습니다. 역할별 교체 명령은 다음과 같습니다.

```sh
./agentcon restart frontend
./agentcon restart admin
```

이 수정의 반영에 jobs·execution 교체는 필요하지 않습니다. 실행 지시 없이 운영 서버를 재시작하지 않는 AGENTS.md 규칙에 따라 직접 재시작하지 않았습니다. 재시작 후 두 역할의 인증된 내부 readiness가 ready=true인 것을 확인했습니다. 공개 홈 HTTP 200, 비로그인 워크스페이스 HTTP 303, 맥미니 모델 healthy 및 실행·대기 0개를 확인했습니다. 배포된 런타임 변경 파일 9개는 검증한 소스 해시와 모두 일치합니다.

도움말 문서 개정으로 기존에 준비해 둔 도움말 변경 제안은 재검토가 필요할 수 있습니다. 저장된 워크플로우와 실행 기록을 삭제하거나 수정하지는 않았습니다.

## 범위와 한계

지원되는 명확한 문서·뉴스 검색 목표와 문서 안내를 개선했습니다. 임의 업무에 대한 범용 자연어 실행 엔진은 아닙니다. 위 품질 수치는 제한된 합성 목표의 판정이며 일반 정확도 보증이 아닙니다. 작은 반복·캐시 영향 표본으로 장시간 안정성이나 모델 자체의 속도 향상률을 판단하지 않았습니다. 운영 로그인 세션이나 외부 유료 에이전트 실행·크레딧 사용은 하지 않았습니다. 기존 intent/lead/RAG 어댑터는 현재 공개 Chat 경로와 별개이며 이번 핵심 수정 대상이 아닙니다.
