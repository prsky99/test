## 3. 측정 결함 (북극성 스크립트)

- `traffic.py`는 UTC 날짜로 하루 파일을 만든다(`timezone.utc`). 그런데 `north_star.py` 설명은 "KST day"이고, 예약 실행 시각은 08:0x다.
  - 그래서 기록마다 그날의 마지막 약 1시간이 빠진다.
  - 11-15 기록은 74건인데 실제는 151건이다. 빠진 77건은 08:0x 이후에도 계속 쓰인 프로세스 파일(71651, 외부 136건, 마지막 갱신 09:00)에서 나왔다. 하루 파일에는 요청 시각이 없어서 그 한 시간에 몰렸는지까지는 알 수 없다.
- 고칠 방법(운영·SRE나 PM 판단): 북극성 실행을 09:1x로 옮기거나, 앞 기록을 09:1x에 다시 써서 바로잡는다. 날짜 경계를 KST로 바꾸는 것은 하루 파일 형식이 바뀌니 하지 않는 편이 낫다.
- `qamcp`는 `traffic_classes.json`에서 probe로 분류하는 것이 맞다. 시험·검증 도구이고, 다른 probe(verifymcp-probe, kitscout-live-check)와 같은 성격이다.

## 4. 추천에서 우리 게이트웨이 실행까지 잇는 가장 빠른 수정

지금 a2a 답(원서버에서 1건 확인, 과제 "Find recent arXiv papers about retrieval augmented generation"):

```
1. arXiv & OpenAlex Academic Search MCP [MCP]
Run here: run 1 {"query":"<query>"}
Endpoint: https://agentconcierge.biz/api/gateway/mcp/413095
Call: initialize → tools/list → tools/call
...
```

- 맨 앞에 우리 게이트웨이 실행 줄이 이미 있다. 하지만 인자가 `<query>` 빈칸이라 두 번째 메시지가 필요하다.
  - data 쪽 `continuation_plan.run_here.arguments`도 `{"query": "<query>"}`다.
- 11-15 분석(reports/connect-gap-2026-11-16)대로 외부 a2a 클라이언트 대부분은 한 번 묻고 떠난다. 그래서 두 번째 턴이 필요한 안내는 실행으로 이어지지 않는다.
- 목걸이 실행 안내는 답에 없다. 공개 목걸이가 아직 없기 때문이다.

수정안(효과가 큰 순서)

1. **분명한 읽기 전용 추천은 첫 답에서 바로 실행해 결과를 함께 준다**(11-16 제안 2와 같다).
   - 조건: 첫 후보의 도구가 읽기 전용이고, 필수 인자가 하나뿐인 텍스트(query 등)이며, 과제 문장에서 그 값을 바로 얻을 수 있을 때(`watch_task`). 위 예라면 "arxiv papers retrieval augmented generation"이다.
   - 시간: 게이트웨이 호출을 짧은 시간(예: 1.5초)만 기다리고, 넘으면 지금처럼 추천만 내고 `Run here` 줄을 둔다. 추천 2초 목표를 넘지 않게 한다.
   - 효과: 과제가 있는 외부 a2a 요청(11-16 18건)이 그대로 게이트웨이 실행 1건이 된다. 북극성 연결·실행 칸이 0에서 처음 움직이는 길이다.
   - 지킬 것: 남의 서버 호출 장부(provider_budget) 몫 안에서만 부른다. 읽기 전용 도구만 쓰고, 결과에는 출처를 붙인다.
2. **실행 줄의 빈칸을 과제 문장으로 미리 채운다.** 1을 못 하는 경우에도 적용한다.
   - `Run here: run 1 {"query":"arxiv papers retrieval augmented generation"}`처럼 바로 쓸 수 있게 하고, data의 `run_here.arguments`도 같은 값으로 채운다.
   - `Call:` 줄은 "initialize → tools/list → tools/call" 세 단계 대신 상태 없는 POST 한 번(tools/call 본문 예시)을 보여 준다. 게이트웨이는 세션 없이 바로 부를 수 있다(connections.py 11-11).
   - 구현이 가장 작고, 추천 시간에도 영향이 없다.
3. 첫 목걸이가 공개되면 맞는 과제에 "이 목걸이를 한 번에 무료 실행" 줄을 맨 앞에 둔다(11-16 제안 3, 공개 뒤).

구현은 PM 결정 뒤 한다. 1·2는 추천 응답을 바꾸는 일이라 검색과 RAG(추천 본문)와 같이 할 범위를 정해야 한다.
