## 기존 메뉴 21개 대응 (부록 A)

1. 개요: 운영 홈으로 이전. p95 목표 달성은 장기간 운영 측정과 구분한다.
2. 알아보기: 새 셸에 중복 메뉴 없음. 기존 화면의 `learn`은 폐기 전까지 유지.
3. 탐색: 새 카탈로그 목록·검색으로 이전; 기존 `explore` 유지.
4. SNS: 공개 서비스 → SNS에서 피드·검색·댓글·반응을 조회하고 공식 영어 글·댓글 작성/보관을 승인 대기로 등록한다.
5. 방문 에이전트: 공개 서비스 → 방문 에이전트에서 원래 질문·추천·연락 동의·대응 기록과 5분 단건 미리보기/승인, 목적별 중지·철회에 대응한다. 동의 재부여와 광고 발송은 제공하지 않는다.

8. 에이전트 테스트: 카탈로그 → 실행 검증에서 정확한 도구/입력 JSON을 검토하고 동의한 단일 테스트를 실행한다.

11. 구독/크레딧: 새 잔액·가입 동의/원장 이력·정산·정정 승인. 원본 자산은 폐기 조건까지 유지한다.
12. 워크스페이스 통합관리: 새 고객·지원·실행·AI·승인. 원본 `workspace_operations` 바로가기 유지.
13. 조직 작업공간: 고객 조직 상세·전문 패널 18개와 별도 직원 작업공간 코어 CRUD/저장본/실행에 대응한다.

## 부분 구현·미완료·정책 보류를 구분한 확인 결과

- **카탈로그 상세 (8.2): 기록 기반 수용 보완 완료.** 현재 원본 상세/계약/보고서에 실제 최신 50개 호출·연결 버전·증거·감사를 추가했다. 내부 메모는 실제 감사 기록에 저장한다. 무제한 전체 버전 역사/후보 적격 전환/없는 수집 이벤트를 추정하지 않는다.
- **조직·워크플로 시각화 (8.3): 안전한 정의 시각 편집 보완.** 이전한 전문 기능을 유지하며 실제 템플릿/직원 초안의 진주 단계·노드 입력/연결 편집을 원래 저장/승인에 연결했다. 템플릿의 현재 에이전트 상태/최근 노드 결과는 별도 안전 투영으로 표시한다. 비공개 초안의 미제공 상태나 숨겨진 출력은 추정/공개하지 않는다. 전문 기능의 별도 탭/모달과 원본 고급 실행·내보내기는 유지한다.
- **운영자 권한 (4.2): 제한된 운영 작업 완료.** 단일 재검사·수집 pause/resume·본문 없는 케이스 배정과 감사/CAS를 허용했다. 기존 케이스 목록의 제목/고객/조직도 숨기며 고객별 필터/상세를 거부한다. 활성화/키/계약/게시/응대·소유자/멤버십 권한은 확대하지 않았다.
- **위험 명령 (4.3): 일부 연결.** 크레딧·계정·고객 제한·세션 종료·실행 제어·보존 승인 등 구현된 명령은 유지한다. SNS/동의된 단건 알림·보안 완화/선택 해제·공개 템플릿 승인은 7번에서 연결 완료했다. 고객이 미리 허용한 지원 자료의 두 단계 열람을 임의 비공개 열람 권한으로 확대하지 않는다.
- **게이트웨이 관측 (7): 기록 기반 세부 조회/경보 보완.** 기존 집계에 시간·프로토콜/에이전트 표본·전송 전 준비/대기·표본 경보를 더했다. 전용 페이싱과 완전한 적격 전환 이력은 계측 없음으로 표시한다. 이를 일반 대기나 건강 확인으로 대체하지 않는다. 실행 경로 전체 통합은 기존 별도 동작 변경 범위다.
- **영속 집계/성능 (5.3·6.2): 일부 완료 + 명시적 보류.** 영속 스냅샷·일별 상태·DB 활동 구현은 완료. 게이트웨이 분 단위 요약은 13.10의 측정 근거에 따라 보류. 설계의 모든 요약 테이블과 일 단위 파티션을 이미 구현한 것으로 표시하지 않는다. 운영 p95 1초는 이번 격리 검증으로 보증하지 않는다.
- **보존 정책 (6.1): 사용자 결정 우선.** 7일→3일 등 초기 제안은 적용 확정 사항이 아니다. 현재 보존 기간과 승인 조건을 유지한다. 이번의 저장본 수동 정리는 기존 제한 배치 기능 이전이며 기간 변경·자동 정리 활성화가 아니다.
- **2단계 인증 (4.1): 후속 단계.** 개인 세션·기계 토큰 제한·초기 비밀번호 변경은 구현됨. TOTP는 이번 범위에서 구현·검증하지 않았다.
- **폐기 (P4): 증빙 대기.** 기존 API·화면·웹앱 v1/v12·옛 SQLite 삭제는 30일 사용/배포 확인과 복구 조건이 필요하다. 이전 링크가 남아 있는 상태에서 삭제하지 않는다.
- **디자인 검증:** 관리자 데스크톱을 대상으로 한다는 후속 사용자 지시를 우선한다. 초기 설계의 관리자 모바일 회귀를 이번 수용 기준에 추가하지 않았다.
