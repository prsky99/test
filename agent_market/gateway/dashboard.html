🪙 x402 결제 설정
  • 실시간 활성 검증: 등록 즉시 수집기와 동일한 프로토콜 실시간 헬스체크를 수행하여 실제 정상 가동 중인 에이전트만 승인 등록됩니다.
  • 자동 헬스체크 편입: 검증 완료 즉시 헬스체크 대기열(6시간 주기)에 자동 편입되어 지속적인 상태 관리가 시작됩니다.
  • 중복 등록 방지: 이미 수집기로 수집되었거나 기존에 등록된 에이전트 URL은 중복 등록할 수 없습니다.
  • SSRF 시큐어 코딩: 사설망(127.0.0.1, 10.0.0.0/8, 192.168.0.0/16 등)이나 클라우드 메타데이터 IP에 대한 접근은 서버 단에서 원천 차단됩니다.
  • 실시간 색인 & 추천: 등록 즉시 FTS5 전문 검색 테이블 및 768차원 AI 벡터 색인(sqlite-vec)에 자동 큐잉되어 추천 풀에 노출됩니다.
